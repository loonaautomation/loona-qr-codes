3단계로 QR 코드를 대량으로 만들기

  1. 목록 준비하기 — 줄마다 코드 하나예요. 내용을 먼저 두세요 (링크나 어떤 텍스트). 그 코드 아래에 캡션이 인쇄되길 원하면 쉼표와 짧은 라벨을 더하세요. 예를 들어 테이블 번호, 선반 이름, 학생 이름이에요. 또는 같은 배치의 .csv 파일을 업로드하세요.

  3. 시트를 인쇄하거나 PDF로 저장하세요 인쇄 버튼으로 (라벨과 내용이 각 코드와 함께 인쇄돼요), 또는 개별 코드를 PNG 파일로 다운로드하세요. 대량으로 인쇄하기 전에, 인쇄된 시트에서 코드 몇 개를 테스트 스캔하세요 — 이상적으로는 저희 스캐너 페이지로요 —

이 대량 QR 코드 생성기 소개

단일 코드 생성기는 테이블 텐트 마흔 개, 학급 세트의 로그인 코드, 가게 전체의 선반 라벨, 모든 손님의 행사 패스가 필요해질 때까지는 괜찮아요. 그것을 하나씩 만드는 것 — 입력, 생성, 다운로드, 이름 변경, 반복 — 은 한 시간을 낭비하고 혼동을 부르게 됩니다. 이 도구는 회원님이 이미 가진 목록(스프레드시트, 메모 파일, CSV 내보내기)을 한 번에, 회원님의 목록과 같은 순서로, 완성되고 라벨이 붙은 코드 시트로 바꿔요. 그래서 시트의 코드 17번이 파일의 17번째 줄이에요.

모든 코드는 일반적인 정적 Loona QR 코드예요. 내용이 패턴 자체 안에 있고, 중간에 Loona 서버, 단축 링크, 계정이 없어요. 그래서 여기서 만든 대량 코드가 절대 만료되지 않고 나중에 끌 수 없어요. 그리고 목록이 비공개로 유지되는 이유예요. 생성이 전적으로 브라우저에서 일어나니까요.

대량 QR 코드의 주요 활용법

  • 레스토랑과 카페 테이블 텐트 — 테이블마다 메뉴 코드 하나, 테이블 번호로 라벨
  • 교실 세트 — 학생마다 워크시트, 포트폴리오, 로그인 페이지로 연결되는 코드 하나
  • 각 위치나 품목을 그 기록에 연결하는 선반, 창고, 보관실 라벨
  • 손님마다 코드가 있는 행사 패스, 방문자 배지, 컨퍼런스 유인물
  • 제품군 — 모델당 코드 하나로 그 설명서, 보증, 재주문 페이지로 연결
  • 위치마다 자체 추적 링크를 받는 포스터 캠페인 (줄마다 다른 ?utm_source=를 더하세요)

인쇄 규칙은 모든 QR 코드와 같아요. 강한 대비를 유지하고(밝은 배경에 어두운 코드), 시트를 자를 때 각 코드 주변의 흰색 퀴엣 존을 남기고, 휴대폰 스캔용으로 약 2 cm보다 작게 인쇄하지 마세요. 작은 128 px 설정에서는 화면을 믿지 말고 종이에서 인쇄 크기를 확인하세요. 인쇄 미리 보기가 실제 시트를 보여 줘요.

자주 묻는 질문

이 대량 QR 코드 생성기는 무료인가요?

네. Loona의 대량 QR 코드 생성기는 완전히 무료예요. 가입 없음, 워터마크 없음, 만드는 배치 수에 제한이 없고, 개인 또는 상업 용도로 쓸 수 있어요.

한 번에 QR 코드를 몇 개 만들 수 있나요?

한 배치에 최대 코드 100개예요. 그 상한은 브라우저를 빠르게, 인쇄 가능한 시트를 다루기 쉽게 유지해요. 더 많은 코드에는 그저 다른 배치를 실행하세요. 빈 줄은 건너뛰고 중복 줄은 유지돼요. 그래서 같은 줄 두 개는 같은 코드 사본 두 개를 줘요.

목록이나 CSV는 어떤 형식이어야 하나요?

줄마다 코드 하나예요. 각 줄은 내용만(링크나 텍스트)이거나 내용,쉼표,라벨이에요. 예를 들어 https://example.com/menu,Table 4 menu예요. 라벨은 시트의 각 코드 아래에 인쇄돼요. 표준 CSV 따옴표가 작동해요. 내용이나 라벨 자체에 쉼표가 있으면 필드를 큰따옴표로 감싸세요. 목록을 붙여 넣거나 .csv나 .txt 파일을 업로드할 수 있고, 파일은 회원님 기기에서만 읽혀요.

제 대량 QR 코드는 만료되나요?

아니요. Loona는 정적 QR 코드를 만들어요. 각 코드의 내용이 서버에 저장되거나 유료 리디렉션 뒤에 숨지 않고 패턴 안에 직접 인코딩돼요. 인쇄된 코드는 목적지가 활성 상태인 한 계속 작동해요.

이 대량 페이지에서 제 목록이 비공개로 유지되나요?

네. 생성은 JavaScript를 써서 브라우저에서 100% 일어나요. 회원님의 목록과 모든 CSV 파일은 로컬로 읽히고 어떤 서버에도 절대 전송되거나 저장되지 않아요.

작동 방식

페이지는 작은 CSV 파서로 회원님의 목록을 줄 단위로 읽어요. 따옴표로 감싼 필드를 이해하니까, “Smith, John” 같은 라벨이 온전히 살아남아요. 각 줄에 대해 Loona의 단일 코드 페이지와 같은 생성기 라이브러리로 정적 QR 코드 하나를 만들고, 목록 순서대로 코드를 격자에 배치하고, 각 코드 아래에 라벨과 내용을 인쇄해서, 인쇄된 시트를 한눈에 원본 목록과 대조할 수 있어요. 아무것도 최적화로 사라지거나 줄여지지 않아요. 각 줄의 정확한 텍스트가 인코딩되는 것이고, 시트의 어떤 코드든 Loona 스캐너로 스캔해서 증명할 수 있어요.

방법: 목록을 준비하세요 (줄마다 내용 또는 내용,라벨) → 생성하세요 → 라벨이 붙은 시트를 확인하세요 → 인쇄하거나 PDF로 저장하세요, 또는 단일 PNG를 다운로드하세요 → 대량으로 인쇄하기 전에 테스트 스캔하세요.

예시

교사가 학생 28명 각자에게 그 학생의 읽기 페이지로 연결되는 코드가 필요해요. 학급 스프레드시트에서 링크와 학생 이름 두 열을 내보내 이 페이지에 붙여 넣고 시트를 생성해요. 인쇄된 코드마다 아래에 학생 이름이 있어서, 시트를 잘라 올바른 아이에게 올바른 코드를 건넬 수 있고, 코드 하나를 잃으면 세트 전체를 다시 하지 않고 그 줄만 단일 PNG로 다시 인쇄해요.

자주 묻는 질문

대량 목록에 WiFi 정보나 연락처 카드를 넣을 수 있나요?

한 줄짜리 단순한 내용이 가장 잘 작동해요. 링크와 짧은 텍스트예요. WiFi 페이로드(WIFI:T:WPA;S:…;P:…;;)는 한 줄이라서 대량 생성할 수 있어요. 쉼표는 비밀번호를 설정한 경우 그 안에만 들어간다는 점에 유의하세요. 그렇다면 필드 전체를 따옴표로 감싸세요. 전체 vCard 같은 여러 줄 내용은 한 줄에 하나씩 표현할 수 없어요. 그런 것에는 전용 vCard 생성기를 하나씩 쓰세요.

제 CSV에 헤더 행이 있어요. 어떻게 되나요?

헤더는 헤더 텍스트를 담은 코드가 될 거예요. 라벨이 붙은 시트에서 쉽게 알아볼 수 있어요. 생성 전에 헤더 줄을 지우세요. 첫 줄이 회원님의 첫 실제 코드여야 해요.

왜 코드 100개 제한이 있나요?

각 코드는 브라우저에서 그려져요. 백 개쯤을 넘으면 느린 휴대폰과 노트북이 버거워하기 시작하고 인쇄 시트 한 장을 확인하기 어려워져요. 큰 작업을 100개 단위 일괄로 나누면 생성이 즉시 유지되고 교정이 현실적이 돼요.

모든 코드를 별도 파일로 한 번에 다운로드할 수 있나요?

시트의 각 코드에는 자체 PNG 다운로드 버튼이 있고, 인쇄 버튼은 라벨이 붙은 전체 시트를 PDF 하나로 저장해요. 라벨이 코드와 함께 가니까, 라벨과 유인물에는 보통 그쪽이 더 유용한 결과물이에요. 브라우저는 페이지가 많은 파일을 한 번에 조용히 저장하는 것을 막아요. 그래서 중간에 실패할 “파일 100개 다운로드” 버튼은 의도적으로 없어요.

한 줄이 실패했거나 이상해 보여요. 배치를 다시 해야 하나요?

아니요. 그 줄을 고치고 다시 생성하세요. 생성은 금방이에요. 아니면 맞는 단일 코드 생성기로 그 코드 하나만 만들어 따로 인쇄하세요. 시트 순서는 항상 회원님의 목록 순서와 일치하니까, 교체본의 이웃을 찾기 쉬워요.
