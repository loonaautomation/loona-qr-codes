작동 방식

이 생성기는 QR 패턴 안에 웹 주소 하나를 저장해요: 양식에 입력한 온라인 이력서나 포트폴리오로의 링크예요. 시작을 생략하면 도구가 https://를 회원님을 위해 더해요. 그래서 “ayeshakhan.design”과 “https://ayeshakhan.design” 모두 같은 작동하는 코드를 만들어요. 누군가 스캔하면, 그들의 휴대폰은 그저 브라우저에서 그 주소를 열어요. 사이에 Loona 페이지나 리디렉션이 없어요. 그러니 그 링크에 살아 있는 것이 정확히 방문자가 보는 것이에요.

예시

프리랜서 디자이너 Ayesha Khan이 온라인 포트폴리오 주소를 양식에 붙여 넣고, PNG를 다운로드해 인쇄한 이력서 위쪽과 명함 뒷면에 배치해요. 취업 박람회에서 채용 담당자가 긴 웹 주소를 입력하는 대신 코드를 스캔하면, 그녀의 포트폴리오가 몇 초 만에 그의 휴대폰에서 열려요 — 북마크해 두고 나중에 제대로 살펴볼 수 있어요.

모든 공개 웹 주소가 작동해요. 개인 포트폴리오 웹사이트, LinkedIn 프로필, Behance나 GitHub 페이지, 온라인에 저장된 PDF 이력서예요. 고용주가 열길 원하는 전체 링크를 붙여 넣으세요.

PDF 이력서로의 링크가 아주 길어요. 코드가 여전히 스캔될까요?

네. 긴 링크는 QR 패턴을 더 조밀하게 만들어요. 그러니 조금 더 크게 인쇄하고(최소 너비 2.5–3 cm) 인쇄본을 한 번 테스트 스캔하세요. 더 짧은 개인 도메인이나 프로필 링크가 있으면, 그것은 더 쉽게 스캔돼요.

왜 제 Google Drive 이력서 링크는 방문자에게 접근을 요청하라고 하나요?

그것은 QR 문제가 아니라 Drive 공유 설정이에요. 코드를 생성하기 전에 파일을 “링크가 있는 모든 사용자가 볼 수 있음”으로 설정하세요. 그렇지 않으면 모든 방문자가 권한 벽에 부딪혀요.

이력서와 포트폴리오에 같은 코드를 사용할 수 있나요?

코드 하나는 링크 하나를 담아요. 흔한 방법은 LinkedIn 프로필이나 개인 사이트처럼, 그 자체가 이력서와 포트폴리오 양쪽으로 이어지는 단일 페이지에 연결하는 거예요.

새 주소로 포트폴리오를 다시 만들었어요. 오래된 인쇄 코드가 따라오나요?

아니요. 정적 QR은 인코딩된 주소를 항상 열어요. 이전 주소가 새 주소로 리디렉션하면 코드는 계속 작동해요. 이전 페이지가 그저 삭제됐으면 새 코드를 생성해 인쇄하세요.
