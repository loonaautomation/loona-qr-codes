이 Data Matrix 소개

Data Matrix(ISO/IEC 16022, ECC 200)는 산업과 의료의 2D 코드예요. 손톱만 한 정사각형에 실제 데이터를 저장해요. 가로 몇 밀리미터예요. Reed–Solomon 오류 정정 덕분에 심볼의 최대 약 25%가 손상돼도 여전히 읽혀요. GS1 DataMatrix는 EU와 미국 전역에서 의약품과 의료 기기의 의무 코드(UDI)이고, 전자제품 제작사는 부품에 직접 레이저로 새겨요.

QR과 달리 모서리에 장식용 파인더 정사각형이 없어요. L자형 단색 테두리와 번갈아 나오는 모듈의 클록 트랙이 스캐너에게 데이터가 어디에 사는지 알려 줘요.

주요 활용법

  • 의약품 및 의료 기기 팩 (GS1/UDI)
  • 레이저로 새긴 전자제품과 엔진 부품
  • 항공우주 부품 추적
  • QR이 들어가지 않는 작은 라벨

결정이 내려지는 바로 그곳에 코드를 두세요. 테이블, 카운터, 포장, 초대장, 화면에요. 그리고 사람들에게 “스캔해서 열기”나 “스캔해서 결제하기” 같은 짧은 안내 한 줄을 주세요. 오래된 휴대폰 카메라가 빠르게 읽도록 코드를 최소 2 cm 너비로, 흰색의 조용한 테두리와 강한 대비로 인쇄하세요. 거리에서 스캔하는 포스터에는 1024 px 크기를 쓰고 더 크게 인쇄하세요. 좋은 기준은 스캔 거리의 대략 십분의 일이에요.

작동 방식

인코딩은 내장된 bwip-js 라이브러리(라벨 소프트웨어가 신뢰하는 인코더 BWIPP의 브라우저 포트)에서 실행돼요. 다른 껍질을 쓴 QR이 아니라 진정한 ECC 200 심볼을 만들어요. 용량은 10×10 심볼의 몇 자에서 영숫자 약 2,335자까지이며, 가장 큰 것은 144×144 심볼이에요.

예시

PCB 제작 업체가 각 보드에 LOT-8841;EXP-2027-05 방식의 추적 데이터를 담은 Data Matrix를 5 mm 크기로 새겨요. 십 년 뒤 기술자가 보드를 스캔하면 전체 생산 기록이 열려요.

자주 묻는 질문

이 Data Matrix 생성기는 무료인가요?

네. Loona의 Data Matrix 생성기는 완전히 무료예요. 가입 없음, 워터마크 없음, 만드는 코드 수에 제한이 없고, 개인 또는 상업 용도로 쓸 수 있어요.

제 QR 코드는 만료되나요?

아니요. Loona는 정적 QR 코드를 만들어요. 회원님의 정보가 서버에 저장되거나 유료 리디렉션 뒤에 숨지 않고 QR 패턴 자체에 직접 인코딩돼요. 오늘 인쇄한 코드는 목적지 자체가 활성 상태인 한 계속 작동할 거예요.

이 Data Matrix 페이지에서 제 정보가 비공개로 유지되나요?

네. 생성은 JavaScript를 써서 브라우저에서 100% 일어나요. 입력하는 어떤 것도 어떤 서버에 전송되거나 저장되지 않아요.

Data Matrix와 QR 코드 중 어느 것인가요?

Data Matrix는 크기가 아주 작을 때, 표면이 부품이나 팩일 때, 또는 산업 규칙(제약 UDI, GS1 의료)이 지정할 때예요. QR은 일반 대중이 스캔해야 할 때예요. 모든 휴대폰 카메라가 QR을 기본으로 읽지만, Data Matrix는 제대로 된 스캐너 앱이 필요한 경우가 많아요.

휴대폰 카메라가 Data Matrix를 스캔할 수 있나요?

많은 최신 휴대폰과 대부분 전용 스캐너 앱은 할 수 있어요. 일부 기본 카메라 앱은 못 해요. 소비자를 향한 용도에는 QR을 선호하세요.
