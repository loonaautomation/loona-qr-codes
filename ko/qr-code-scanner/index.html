무료 QR 코드 및 바코드 스캐너

카메라를 QR 코드나 바코드에 향하게 하거나, 사진이나 스크린샷을 넣으세요. 코드는 바로 여기, 회원님 기기에서 디코딩돼요. 가입 없음, 설치할 앱 없음, 스캔하는 것은 아무것도 업로드되지 않아요. 여러 코드 이미지를 한 번에 일괄 디코딩하고 결과를 CSV 파일로 내보낼 수도 있어요.

카메라로 스캔

라이브 카메라 스캔은 Chrome, Edge, 대부분 Android 브라우저에 내장된 빠른 BarcodeDetector를 쓰고, QR 코드와 흔한 바코드(EAN-13, UPC-A, Code 128, Code 39 등, 브라우저에 따라 달라요)를 읽어요.

개인정보: 카메라 프레임은 이 기기에서만 처리되고 브라우저를 절대 떠나지 않아요. 동영상은 녹화, 전송, 저장되지 않아요.

이미지에서 스캔

사진을 업로드하거나, 여기에 이미지 파일을 놓거나, 스크린샷을 붙여 넣으세요(Ctrl+V / Cmd+V). 이미지의 QR 코드는 jsQR로, 이미지의 바코드는 ZXing으로 디코딩돼요 — EAN-13, UPC-A, Code 128, Code 39가 포함돼요.

    3단계로 QR 코드나 바코드 스캔하기
    

    1. 카메라 또는 이미지를 선택하세요. Chrome, Edge, Android에서는 “카메라 스캔 시작”을 누르고, 카메라 접근을 허용한 뒤, 코드를 프레임 안에 두세요. Safari와 Firefox를 포함한 어떤 브라우저에서든, 대신 사진을 업로드하거나, 이미지를 끌어다 놓거나, 스크린샷을 붙여 넣을 수 있어요.
      2. 

    2. 디코딩을 잠시 기다리세요. 스캐너는 회원님 기기에서 패턴을 읽고 디코딩된 유형, 형식, 원본 내용을 보여 줘요. 사진에서는, 코드의 선명하고 가깝고 밝은 이미지가 가장 빠르게 스캔돼요.
    3. 스마트 액션을 쓰세요. 디코딩된 링크를 열거나, WiFi 네트워크 이름과 비밀번호를 드러내거나, vCard 코드에서 연락처 카드(.vcf)를 다운로드하거나, 번호로 전화하거나, 한 번 눌러 원본 텍스트를 복사하세요. 모든 스캔은 이 세션 동안 페이지 내 기록에 더해져요.
    

    이 QR 코드 및 바코드 스캐너 소개
    

    대부분의 QR 사이트는 그저 만들기 코드예요. 이 페이지는 반대의 일을 해요: 그것들을 읽어요. 인쇄된 코드에 읽을 수 있는 라벨이 없을 때, 동료가 안에 든 링크 대신 코드의 스크린샷을 보낼 때, 큰 인쇄 작업 전에 회원님 본인의 인쇄 코드 중 하나가 실제로 무엇을 담고 있는지 확인하고 싶을 때, 또는 제품 바코드 번호를 사진에서 읽어 내야 할 때 필요한 것이에요.
    

    두 가지 방식으로 작동해요. 카메라 모드는 최신 Chromium 브라우저에 내장된 BarcodeDetector 인터페이스를 써요. 휴대폰 시스템이 쓰는 것과 같은 빠르고 하드웨어 친화적인 감지예요. QR 코드와 흔한 일차원 바코드를 알려 줘요. 이미지 모드는 완전히 자체 완결적이에요. 오픈소스 jsQR 라이브러리가 이미지의 픽셀에서 QR 코드를 디코딩하고, 오픈소스 ZXing 라이브러리가 같은 픽셀에서 바코드(그리고 jsQR이 놓친 모든 QR 코드)를 디코딩해요. 둘 다 전적으로 브라우저에서 실행돼요. 그래서 이 스캐너는 낯선 사람의 서버에 절대 업로드하고 싶지 않은 민감한 코드(WiFi 비밀번호, 결제 코드, 비공개 링크)에서도 계속 작동해요.
    

    이 스캐너의 주요 활용법
    • 대량으로 인쇄하기 전에 자신의 인쇄 QR 코드를 확인하세요
    • 누군가 보낸 스크린샷이나 사진 속 QR 코드 안에 숨은 링크 열기
    • WiFi QR 코드 이미지에서 WiFi 네트워크 이름과 비밀번호를 복구하고 있어요
    • 명함 QR 코드에서 vCard 연락처를 .vcf 파일로 저장하기
    • 제품과 라벨 사진에서 EAN-13, UPC-A, Code 128, Code 39 바코드 번호를 읽어요
    • 생성한 바코드가 의도한 바로 그 번호로 다시 스캔되는지 확인하고 있어요
    • 인쇄된 시트 전체나 코드 사진 폴더를 일괄 확인하고, 모든 결과를 CSV로 내보내요
    • geo: 위치 코드 뒤의 좌표나, Bitcoin이나 Ethereum 결제 코드 뒤의 주소를, 행동하기 전에 보고 있어요
    

    놀라지 않게 솔직한 한계예요. 카메라 스캔은 Safari와 Firefox가 아직 제공하지 않은 브라우저 기능에 의존해요. 그래서 그 브라우저에서는 이미지 모드만 쓸 수 있어요. 페이지는 이를 감지해 조용히 실패하는 대신 분명히 알려 줘요. 그리고 어떤 디코더도 사진에서 너무 작거나, 흐리거나, 찢어지거나, 대비가 너무 낮게 인쇄된 코드는 읽을 수 없어요. 사진을 더 가까이, 정면으로, 좋은 조명에서 다시 찍으면 실패한 스캔 대부분이 고쳐져요.
    

    자주 묻는 질문
    이 QR 코드 및 바코드 스캐너는 무료인가요?
    네. Loona의 스캐너는 완전히 무료예요. 가입 없음, 워터마크 없음, 스캔하는 코드 수에 제한이 없고, 개인 또는 상업 용도로 쓸 수 있어요.
    이 스캐너 페이지에서 제 카메라 영상이나 사진이 비공개로 유지되나요?
    네. 모든 것이 회원님 본인의 기기에서, 브라우저 안에서 디코딩돼요. 카메라 프레임은 어디에도 전송되지 않고 업로드된 이미지는 서버에 절대 전송되지 않아요. 파일은 로컬로 읽히고, 로컬로 디코딩되고, 스캔 기록은 이 페이지의 메모리에만 유지되며 탭을 닫으면 사라져요.
    왜 제 브라우저에서 카메라 스캔이 작동하지 않나요?
    라이브 카메라 스캔은 Chrome, Edge, 대부분 Android 브라우저에 내장된 BarcodeDetector 기술을 써요. Safari와 Firefox는 아직 포함하지 않아요. 그래서 그 브라우저에서는 카메라 버튼이 대신 이미지 업로드를 사용하라는 메시지로 바뀌어요. 사진이나 스크린샷을 업로드하는 것은 모든 최신 브라우저에서 작동해요.
    이 스캐너가 사진에서 바코드를 읽을 수 있나요?
    네. 업로드 모드는 jsQR 라이브러리로 이미지에서 QR 코드를, ZXing 라이브러리로 이미지에서 바코드를 디코딩해요 — EAN-13, UPC-A, Code 128, Code 39가 포함돼요 — 그리고 jsQR이 놓친, ZXing이 찾은 QR 코드도요. 사진에서 아주 작거나, 흐리거나, 손상되거나, 대비가 낮은 코드는 여전히 실패할 수 있어요. 더 선명하고 가까운 사진이 보통 그것을 고쳐요.
    이 스캐너는 어떤 유형의 코드를 읽을 수 있나요?
    카메라 스캔(지원되는 경우)은 QR 코드와 브라우저의 BarcodeDetector가 제공하는 바코드 형식을 읽어요. 보통 EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar, ITF예요. 이미지 업로드는 QR 코드와 EAN-13, UPC-A, Code 128, Code 39 바코드를 읽고, 디코딩된 유형, 원시 내용, 링크 열기나 연락처 저장 같은 스마트 동작을 보여 줘요.

    스캔해서 전체 연락처 카드를 휴대폰에 저장하세요.
    

    작동 방식
    

    QR 코드나 바코드는 텍스트를 밝고 어두운 모듈로 인코딩한 패턴일 뿐이에요. 디코딩은 생성의 반대예요. 이미지에서 패턴을 찾고, 모듈을 측정하고, 코드 자체의 중복성을 이용해 오류를 정정하고, 비트를 다시 문자로 바꿔요. jsQR은 세 개의 찾기 정사각형 위치를 파악하고 격자를 샘플링해서 QR 코드에 이 작업을 해요. ZXing은 바를 가로지르는 픽셀 행을 스캔하고 너비를 EAN, UPC, Code 128, Code 39 규칙과 대조해서 바코드에 이 작업을 하며, 소매 바코드의 마지막 체크 숫자 검증도 포함해요. 카메라 모드에서는 브라우저 자체의 BarcodeDetector가 코드가 발견될 때까지 라이브 영상 프레임에서 같은 작업을 계속 수행해요. 일괄 모드에서는 같은 두 이미지 디코더가 파일마다 한 번씩 실행되고, 파일명, 형식, 유형, 디코딩된 텍스트 등 모든 결과가 CSV로 내보낼 수 있는 표에 수집돼요.
    

    방법: 카메라 또는 이미지를 선택하세요 → 기기 내 디코더가 패턴을 읽게 하세요 → 유형, 형식, 원본 내용을 확인하세요 → 스마트 액션을 쓰세요 (열기, 복사, 연락처 저장) → 세션 기록에서 언제든 스캔을 다시 찾으세요.
    

    예시
    

    가게 주인이 Loona 바코드 생성기로 새 제품의 EAN-13 바코드를 생성하고 교정을 인쇄해요. 라벨 천 장을 주문하기 전에 휴대폰으로 교정을 촬영해 여기에 업로드하면, 스캐너가 ZXing으로 바코드를 다시 읽어요. 형식 EAN-13, 입력한 그대로의 번호, 체크 숫자 포함이에요. 그녀는 또 채팅에서 공급사의 WiFi QR 코드 스크린샷을 복사해 이 페이지에 붙여 넣어요. jsQR이 네트워크 이름과 비밀번호를 그녀가 카메라 없는 노트북에 입력할 수 있는 일반 텍스트로 드러내요.
    

    자주 묻는 질문
    

    같은 휴대폰에서 스크린샷의 코드를 스캔할 수 있나요?
    

    네. 스크린샷을 사진 앱에 저장하거나 공유한 뒤, 여기서 이미지 업로드를 써서 그 스크린샷을 고르세요. 컴퓨터에서는 이미지를 복사해 Ctrl+V(Mac에서는 Cmd+V)로 이 페이지에 붙여 넣으면 돼요 — 파일을 저장할 필요가 없어요.
    

    결과가 WIFI:T:WPA;S:…처럼 보여요 — 무슨 뜻인가요?
    

    그것은 WiFi QR 코드 안의 표준 원본 형식이에요: T는 보안 유형, S는 네트워크 이름(SSID), P는 비밀번호예요. 이 페이지는 그 세 값을 원본 내용 위에 따로도 보여 주니까, 직접 골라낼 필요가 없어요.
    

    스캔한 연락처를 제 휴대폰에 어떻게 추가하나요?
    

    스캔이 vCard이면, “연락처 다운로드(.vcf)” 동작이 나타나요. 파일을 다운로드하고 여세요. 휴대폰과 컴퓨터가 이름, 조직, 전화, 이메일, 웹사이트가 이미 채워진 연락처로 저장하라고 제안해요.
    

    왜 제 사진이 디코딩되지 않았나요?
