關於此 Data Matrix

Data Matrix (ISO/IEC 16022, ECC 200) 是工業和醫療的 2D 碼：它將真實資料儲存在指甲大小的正方形中 — 幾毫米寬 — 由於 Reed–Solomon 糾錯，即使符號損壞高達約 25%，仍可讀取。GS1 DataMatrix 是歐盟和美國藥品和醫療器械（UDI）上強制使用的條碼，電子產品製造商將其直接鐳射蝕刻到零件上。

與二維碼不同，它在角落沒有裝飾性的定位方塊 — L 形的實心邊框加上交替模組的時鐘軌道告訴掃描器資料所在的位置。

最佳用途

  • 藥品和醫療器械包裝 (GS1/UDI)
  • 鐳射蝕刻的電子產品和發動機零件
  • 航空航天零部件跟蹤
  • 二維碼放不下的小標籤

將二維碼恰好放在做出決定的地方 — 桌子上、櫃檯上、包裝上、請柬上或螢幕上 — 並給人們一行簡短的說明，如“掃碼開啟”或“掃碼付款”。列印二維碼至少 2 cm 寬，帶有安靜的白色邊框和強烈的對比，以便較舊的手機攝像頭可以快速讀取它們；對於從遠處掃描的海報，請使用 1024 px 尺寸並列印得更大 — 一個好的參考是大約掃描距離的十分之一。

工作原理

編碼在內建的 bwip-js 庫（BWIPP 的瀏覽器移植版，標籤軟體信任的編碼器）上執行，產生真正的 ECC 200 符號 — 而不是換了皮膚的二維碼。容量從 10×10 符號中的幾個字元，到 144×144 時約 2,335 個字母數字字元。

例項

一家 PCB 製造商在每塊板上蝕刻一個 Data Matrix，其中包含 LOT-8841;EXP-2027-05 樣式的可追溯資料，大小 5 mm。十年後，技術人員掃描該板，完整的生產記錄開啟。

Data Matrix 還是二維碼 — 哪一個？

當尺寸非常小、表面是零件或包裝，或行業規則（製藥 UDI、GS1 醫療）指定它時，使用 Data Matrix。當普通公眾必須掃描它時使用二維碼 — 每部手機攝像頭都能原生讀取二維碼，而 Data Matrix 通常需要專門的掃描器應用。

手機攝像頭可以掃描 Data Matrix 嗎？

許多較新的手機和大多數專用掃描器應用可以；一些自帶相機應用不能。對於面向消費者的用途，優先選擇二維碼。
