    關於此二維碼和條形碼掃描器
    

    大多數二維碼網站只 製作 二維碼。此頁面做相反的工作：它讀取它們。當列印的二維碼沒有可讀標籤時，當同事向您傳送二維碼的截圖而不是其中的連結時，當您想在大批次列印之前檢查您自己的列印二維碼實際包含什麼時，或當產品條形碼號碼必須從照片中讀取時，這正是您需要的。
    

    它以兩種方式工作。攝像頭模式使用內建於現代 Chromium 瀏覽器的 BarcodeDetector 介面 — 與您的手機系統使用的快速、硬體友好的檢測相同 — 並報告二維碼和常見的一維條形碼。圖片模式完全自包含：開源 jsQR 庫從您的圖片畫素中解碼二維碼，開源 ZXing 庫從相同的畫素中解碼條形碼（以及 jsQR 遺漏的任何二維碼）。兩者都完全在您的瀏覽器中執行，這就是為什麼此掃描器可以繼續處理敏感條碼 — WiFi 密碼、付款碼、私人連結 — 這些您永遠不想上傳到陌生人伺服器的東西。

    工作原理
    

    二維碼或條形碼只是一個將文字編碼為淺色和深色模組的圖案。解碼是生成的逆過程：在圖片中找到圖案，測量模組，使用條碼內建的冗餘糾正錯誤，並將位元轉化回字元。jsQR 透過定位三個定位方塊並取樣網格來為二維碼做這件事；ZXing 透過掃描條紋上的畫素行並將寬度與 EAN、UPC、Code 128 或 Code 39 規則匹配來為條形碼做這件事，包括驗證零售條形碼的最後校驗位。在攝像頭模式下，您的瀏覽器自己的 BarcodeDetector 在實時影片幀上持續執行相同的工作，直到找到條碼。在批次模式下，相同的兩個圖片解碼器對每個檔案執行一次，每個結果 — 檔名、格式、型別和解碼文字 — 都被收集到一個您可以匯出為 CSV 的表中。
    

    方法： 選擇攝像頭或圖片 → 讓裝置上的解碼器讀取圖案 → 檢查型別、格式和原始內容 → 使用智慧操作（開啟、複製、儲存聯絡人）→ 隨時在會話歷史中找到該掃描。

    常見問題
    

    我可以從同一手機上的截圖掃描二維碼嗎？
    

    是的。將截圖儲存或分享到您的照片應用，然後使用此處的圖片上傳並選擇該截圖。在計算機上，只需複製圖片並用 Ctrl+V（或 Mac 上的 Cmd+V）貼上到此頁面 — 無需儲存檔案。
    

    結果看起來像 WIFI:T:WPA;S:… — 那是什麼意思？
    

    那是 WiFi 二維碼內部的標準原始格式：T 是安全型別，S 是網路名稱 (SSID)，P 是密碼。此頁面還在原始內容上方單獨顯示這三個值，因此您不必自己挑選它們。
    

    我如何將掃描的聯絡人新增到我的手機？
    

    當掃描是 vCard 時，出現“下載聯絡人 (.vcf)”操作。下載檔案並開啟它 — 手機和電腦提供將其儲存為聯絡人，姓名、組織、電話、電子郵件和網站已填寫。
    

    為什麼我的照片沒有解碼？
    

    通常的原因是二維碼在一張大照片中很小、模糊、眩光、撕裂或低對比度的列印件，或截圖在二維碼周圍裁剪得太緊（解碼器需要二維碼周圍的白色靜區）。寬鬆裁剪，近距離、正面重新拍照，然後再試一次。
    

    我應該信任在公共場合找到的二維碼嗎？
    

    先在這裡掃描，而不是用自動開啟結果的應用：此頁面只 顯示 向您展示解碼的內容，從不自己開啟任何東西。在點選“開啟連結”之前，檢查連結是否真的指向其標籤承諾的地方 — 這一個習慣可以擊敗大多數貼紙覆蓋真實二維碼的詐騙。
