關於此 Code 39

Code 39 (USS Code 39, Code 3 of 9) 是仍在日常使用的最古老的字母數字條形碼 — 開發於 1974 年，靠幾十年前指定它的汽車、國防、醫療和政府標籤得以存續。每個字元寬九個元素（五條條紋、四條空格，其中三條是寬的），這使它能容忍較差的列印，但相對於它攜帶的資料來說較長。

它的字母表很小：大寫字母 A–Z、數字和一些符號。它是自校驗的（單個錯誤字元很少能驗證透過），並且可以在接收系統期望的地方新增可選的模 43 校驗位。

最佳用途

  • 汽車和國防傳統標籤
  • 姓名胸牌和身份證
  • 圖書館書籍（舊系統）
  • 工業箱和工具庫

將二維碼恰好放在做出決定的地方 — 桌子上、櫃檯上、包裝上、請柬上或螢幕上 — 並給人們一行簡短的說明，如“掃碼開啟”或“掃碼付款”。列印二維碼至少 2 cm 寬，帶有安靜的白色邊框和強烈的對比，以便較舊的手機攝像頭可以快速讀取它們；對於從遠處掃描的海報，請使用 1024 px 尺寸並列印得更大 — 一個好的參考是大約掃描距離的十分之一。

工作原理

該生成器自動將您的文字大寫，並拒絕 Code 39 字母表之外的字元，指明規則，而不是讓編碼器靜默失敗。星號是開始/停止字元，由編碼器新增 — 永遠不要自己輸入它。

為什麼我的小寫文字改變了？

Code 39 的標準字母表中沒有小寫字母，因此編碼器會轉換為大寫字母。如果大小寫重要，請改用 Code 128。

Code 39 需要校驗位嗎？

不 — 它在設計上是自校驗的。模 43 校驗位存在於要求它的系統中，但大多數 Code 39 標籤列印時沒有它。
