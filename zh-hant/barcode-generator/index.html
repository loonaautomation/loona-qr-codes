關於條形碼和五種型別

條形碼將短程式碼轉化為掃描器在幾分之一秒內讀取的條紋圖案。不同的工作使用不同的條形碼型別（稱為符號系統），選擇正確的很重要：商店收銀臺期望 EAN-13 或 UPC-A，倉庫對 Code 128 滿意，運輸紙箱使用 ITF-14。

  • Code 128 — 通用主力。編碼字母、數字和標點，幾乎任何長度，並保持緊湊。最適合庫存標籤、資產標籤、圖書館和身份證，以及任何型別的內部跟蹤。
  • Code 39 — 較舊、更簡單的標準。僅大寫字母、數字和符號 - . $ / + % 和空格。得到較舊掃描器的廣泛支援；常用於軍事、汽車和簡單資產標籤。
  • EAN-13 — 北美以外的零售標準。恰好 13 位數字：您的 12 位數字加上計算的校驗位。產品號碼必須向 GS1 註冊才能用於零售銷售（請參閱下面的常見問題）。
  • UPC-A — 美國和加拿大的零售標準。恰好 12 位數字：您的 11 位數字加上校驗位，也透過 GS1 頒發用於零售。
  • ITF-14 — 運輸紙箱標準。恰好 14 位數字（13 加校驗位），大尺寸列印在箱子上，因此整個紙箱無需開啟即可掃描。

關於零售型別的一個誠實警告：此生成器產生一個 結構正確 任何掃描器都可以讀取的條形碼，這正是庫房、貨架、學校和辦公室庫存、活動通行證和內部標籤所需要的。但如果條形碼將在商店收銀臺或線上市場被掃描，號碼本身必須正式屬於您 — 在您的公司下向 GS1 註冊。在零售號碼上發明的風險是將另一家公司的產品程式碼列印在您的商品上。

此條形碼生成器的最佳用途

  • 庫存和庫房標籤
  • 學校、辦公室和車間裝置的資產標籤

無論您選擇哪種型別，掃描規則都相同：將條形碼以合理的尺寸列印（手持掃描器至少約 3 cm 寬），在兩側保持清晰的空白邊距 — 靜區 — 並且永遠不要拉伸或壓縮圖片，因為那會扭曲掃描器測量的條紋寬度。SVG 檔案無失真縮放，是列印的最安全選擇；高度寬裕的 PNG 適合螢幕和辦公室印表機。

常見問題解答

此條形碼生成器是免費的嗎？

是的。Loona 的條形碼生成器是完全免費的，無需註冊，無水印，無您建立條形碼數量的限制，用於個人或商業用途。

我可以在我在商店出售的產品上使用生成的 EAN-13 或 UPC 條形碼嗎？

條形碼圖片在結構上是正確的並且可以掃描，但零售條形碼必須註冊：商店和市場要求使用 GS1（官方組織）在您自己的公司字首下頒發的號碼。您在這裡編造的號碼可能會與別人的產品衝突。對於庫存、資產、貨架和內部使用，生成的條形碼沒有問題；對於零售銷售，請先向 GS1 註冊。

什麼是校驗位，我需要計算它嗎？

EAN-13、UPC-A 和 ITF-14 以根據其他數字計算的校驗位結尾，因此掃描器可以檢測誤讀。您不需要計算它：輸入不帶校驗位的數字（EAN-13 為 12 位，UPC-A 為 11 位，ITF-14 為 13 位），本生成器會新增它。如果您輸入完整數字，生成器會驗證校驗位並告訴您它是否錯誤。

我的資訊在此條形碼頁面上私密嗎？

是的。條形碼 100% 在您的瀏覽器中使用 JavaScript 繪製。您輸入的任何東西都不會傳送到或儲存在任何伺服器上。

常見問題

條形碼和二維碼有什麼區別？

條形碼是一維的：它儲存一個短程式碼（通常只是數字或簡短的 ID），資料庫然後查詢它。二維碼是二維的，可以儲存更多 — 完整的連結、WiFi 密碼或聯絡人卡片 — 並由手機攝像頭讀取。如果涉及掃描槍或收銀臺，請使用條形碼；如果涉及手機攝像頭，二維碼通常更好。

為什麼我的 EAN-13 號碼被拒絕？

要麼它包含數字以外的內容，要麼其長度不是 12 或 13 位數字，要麼第 13 位數字與計算的校驗位不匹配。預覽下方的訊息會告訴您校驗位應該是哪個數字，以便您發現輸入錯誤。

我可以更改條形碼的顏色嗎？

是的 — 條紋顏色和背景在預覽上方。掃描器讀取對比度，而不是顏色本身，因此深色條紋（黑色、深藍色、深綠色）在白色或淺色背景上效果最好。避免紅色條紋：許多鐳射掃描器使用紅光，無法看到它們。

PNG 還是 SVG — 我應該下載哪個？

對於任何將專業列印或放大的內容，請選擇 SVG，因為它可以縮放到任何尺寸而不會模糊。對於文件、電子表格、幻燈片和快速辦公列印，請選擇 PNG。

一個條形碼可以儲存長訊息或網頁連結嗎？

不太好。條形碼是為短程式碼設計的；長連結會使 Code 128 極其密集，許多掃描器難以處理。對於連結和更長的內容，請改用我們的二維碼生成器之一 — 這正是二維碼被髮明的原因。
