About this bulk QR code generator

Single-code generators are fine until you need forty table tents, a class set of login codes, shelf labels for a whole shop, or an event pass for every guest. Making those one at a time — type, generate, download, rename, repeat — wastes an hour and invites mix-ups. This tool turns the list you already have (in a spreadsheet, a notes file or a CSV export) into a finished, labelled sheet of codes in one pass, in the same order as your list, so code number 17 on the sheet is line 17 of your file.

Every code is a normal static Loona QR code: the content sits inside the pattern itself, with no Loona server, short link or account in between. That is why bulk codes made here never expire and cannot be switched off later — and why your list stays private, because the generation happens entirely in your browser.

Best uses of bulk QR codes

  • Restaurant and cafe table tents — one menu code per table, labelled by table number
  • Classroom sets — one code per student linking to their worksheet, portfolio or login page
  • Shelf, stock-room and warehouse labels linking each location or item to its record
  • Event passes, visitor badges and conference handouts with a code per guest
  • Product ranges — one code per model linking to its manual, warranty or reorder page
  • Poster campaigns where each location gets its own trackable link (add a different ?utm_source= per line)

Printing rules are the same as for any QR code: keep strong contrast (dark codes on a light background), leave the white quiet zone around each code when you cut the sheet apart, and do not print codes smaller than about 2 cm wide for phone scanning. On the compact 128 px setting, check the printed size on paper rather than trusting the screen — the print preview shows the true sheet.

Frequently Asked Questions

Is this bulk QR code generator free?

Yes. Loona's bulk QR code generator is completely free with no signup, no watermark and no limit on how many batches you create, for personal or commercial use.

How many QR codes can I create at once?

Up to 100 codes in one batch. That cap keeps your browser fast and the printable sheet manageable; for more codes, simply run another batch. Empty lines are skipped and duplicate lines are kept, so two identical lines give you two copies of the same code.

What format should my list or CSV be in?

One code per line. Each line is either just the content (a link or text) or content,comma,label — for example https://example.com/menu,Table 4 menu. Labels are printed under each code on the sheet. Standard CSV quoting works: wrap a field in double quotes if the content or label itself contains a comma. You can paste the list or upload a .csv or .txt file, which is read on your device only.

Will my bulk QR codes expire?

No. Loona creates static QR codes: each code's content is encoded directly inside its pattern, not stored on a server or hidden behind a paid redirect. Printed codes keep working as long as their destinations stay active.

Is my list private on this bulk page?

Yes. Generation happens 100% in your browser using JavaScript. Your list and any CSV file are read locally and are never sent to or stored on any server.

How it works

The page reads your list line by line with a small CSV parser that understands quoted fields, so a label like “Smith, John” survives intact. For each line it builds one static QR code with the same generator library as Loona's single-code pages, lays the codes out in a grid in list order, and prints each label and content under its code so a printed sheet can be checked against the original list at a glance. Frequently asked questions

Can I put WiFi details or contact cards in a bulk list?

Plain one-line contents work best: links and short texts. A WiFi payload (WIFI:T:WPA;S:…;P:…;;) is a single line, so it can be bulk-generated — note it contains commas only inside the password if you set one; quote the whole field if so. Multi-line contents such as full vCards cannot be expressed one-per-line; use the dedicated vCard generator for those, one at a time.

My CSV has a header row. What happens?

The header would become a code containing the header text, which is easy to spot on the labelled sheet. Delete the header line before generating — the first line should be your first real code.

Why is there a 100-code limit?

Each code is drawn in your browser; beyond about a hundred, slower phones and laptops start to lag and a single printed sheet becomes hard to check. Splitting a big job into batches of 100 keeps generation instant and proof-reading realistic.

Can I download all codes as separate files at once?

Each code on the sheet has its own PNG download button, and the print button saves the complete labelled sheet as one PDF — which is usually the more useful artefact for labels and handouts, because the labels travel with the codes. Browsers restrict pages from silently saving many files at once, so there is deliberately no “download 100 files” button that would fail halfway.

One line failed or looks wrong. Do I redo the batch?

No. Fix the line, regenerate — generation takes a second — or make just that one code with the matching single-code generator and print it separately. The sheet order always matches your list order, so finding the replacement's neighbours is easy.
