About this Code 39

Code 39 (USS Code 39, Code 3 of 9) is the oldest alphanumeric barcode still in daily use — developed in 1974 and kept alive by automotive, defence, healthcare and government labels that specified it decades ago. Each character is nine elements wide (five bars, four spaces, three of them wide), which makes it tolerant of poor printing but long for the data it carries.

Its alphabet is small: capitals A–Z, digits and a few symbols. It is self-checking (a single bad character rarely validates), and an optional modulo-43 check digit can be added where the receiving system expects one.

Best uses

  • Automotive and defence legacy labels
  • Name badges and ID cards
  • Library books (older systems)
  • Industrial bins and tool cribs

Put the code exactly where the decision is made — on the table, the counter, the packaging, the invitation or the screen — and give people one short line of instruction such as “Scan to open” or “Scan to pay”. Print codes at least 2 cm wide with a quiet white border and strong contrast so older phone cameras read them quickly; for posters scanned from a distance, use the 1024 px size and print bigger — a good guide is roughly one tenth of the scanning distance.

How it works

The generator upper-cases your text automatically and rejects characters outside the Code 39 alphabet, naming the rule instead of letting the encoder fail silently. An asterisk is the start/stop character and is added by the encoder — never type it yourself.

Is my information private on this Code 39 page?

Yes. Generation happens 100% in your browser using JavaScript. Nothing you enter is sent to or stored on any server.

Why did my lower-case text change?

Code 39 has no lower-case letters in its standard alphabet, so encoders convert to capitals. If case matters, use Code 128 instead.

Does Code 39 need a check digit?

No — it is self-checking by design. A modulo-43 check digit exists for systems that ask for it, but most Code 39 labels are printed without one.
