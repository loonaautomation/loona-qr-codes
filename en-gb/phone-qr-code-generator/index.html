How it works

You enter a phone number, and the generator encodes it as a tel: link — tel: followed by your number, with spaces removed. When someone scans the code, their phone recognises the call link and displays the number with a Call option; one more tap and the phone dials. For safety, phones never auto-dial from a QR code: the person always sees the number first and confirms the call themselves.

Worked example

A plumber has his van signwritten with a large QR and the words “Scan to call”. He enters his number in full international format, +92 300 1234567, and prints the code on both sides of the van. A homeowner with a burst pipe scans it from across the street, taps Call on the prompt, and is speaking to him within seconds — instead of walking over to read eleven digits and typing them in by hand.

Frequently asked questions

Should I include my country code?

Yes — enter the full international format, such as +92 for Pakistan or +1 for the US. The number then works for scanners from any country, and phones can dial or save it correctly without guessing.

Does scanning call the number immediately?

No. Scanning shows the number and a call prompt, and the person taps to dial. Phones are designed this way so that a QR code can never place a call without the owner’s action.

Does the scanner need internet or a special app?

No internet is needed — the number is inside the pattern itself, and any camera app that reads QR codes can offer the call. The caller only needs ordinary phone signal to place it.

Can I use a landline or a helpline number?

Yes — any dialable number works, including landlines, toll-free numbers and helplines. The code simply presents the number ready to call.

What if I change my number later?

The printed code keeps the old number, so generate a new code and replace the prints. For expensive signage and vehicle work, it is worth using a number you plan to keep for a long time.

Can people save my number from the code instead of calling?

Many phones offer an “add to contacts” option alongside the call prompt after scanning a tel: code — and at minimum, the number is on screen to copy or write down.
