À propos de ce Paiement Bitcoin Cash

Les codes de paiement Bitcoin Cash utilisent le schéma d’URI bitcoincash: avec des paramètres de style BIP-21. Les portefeuilles lisent l’adresse (CashAddr q…/p… ou format hérité) ainsi que le montant et le libellé facultatifs, et présentent un paiement prêt à confirmer — conçu pour les paiements petits, rapides et à frais réduits pour lesquels le BCH est utilisé.

Comme pour tout code crypto : vérifiez l’adresse dans votre portefeuille avant d’imprimer, et testez le scan. Les adresses BCH et BTC ne sont pas interchangeables — un code sur cette page est réservé aux portefeuilles Bitcoin Cash uniquement.

Meilleures utilisations

  • Paiements BCH au détail
  • Codes de secours pour le paiement en ligne
  • Dons
  • Transferts et personne à personne

Mettez le code exactement là où la décision est prise — sur la table, le comptoir, l’emballage, l’invitation ou l’écran — et donnez aux gens une courte phrase d’instruction comme « Scannez pour ouvrir » ou « Scannez pour payer ». Imprimez les codes à au moins 2 cm de large avec une bordure blanche silencieuse et un fort contraste pour que les caméras de téléphones plus anciens les lisent rapidement ; pour les affiches scannées à distance, utilisez la taille 1024 px et imprimez plus grand — un bon repère est environ un dixième de la distance de scan.

Comment ça fonctionne

La charge utile est bitcoincash:ADDRESS?amount=…&label=…, en préservant le préfixe si votre adresse l’inclut déjà.

Exemple travaillé

Un café d’une ville favorable au BCH imprime un code de comptoir pour son café à 0.01 BCH. Les habitués scannent et paient en moins de dix secondes, avec des frais d’une fraction de centime.

Questions fréquemment posées

Ce générateur Paiement Bitcoin Cash est-il gratuit ?

Oui. Le générateur Paiement Bitcoin Cash de Loona est entièrement gratuit sans inscription, sans filigrane et sans limite sur le nombre de codes que vous créez, pour un usage personnel ou commercial.

Mon code QR expirera-t-il ?

Non. Loona crée des codes QR statiques : vos informations sont encodées directement dans le motif QR lui-même, pas stockées sur un serveur ni cachées derrière une redirection payante. Un code que vous imprimez aujourd’hui continuera de fonctionner tant que la destination elle-même reste active.

Mes informations sont-elles privées sur cette page Paiement Bitcoin Cash ?

Oui. La génération se fait à 100% dans votre navigateur en JavaScript. Rien de ce que vous saisissez n’est envoyé ni stocké sur un serveur.

CashAddr ou legacy — lequel dois-je utiliser ?

Les deux sont acceptés ; les portefeuilles comprennent les deux. CashAddr (commençant par q ou p, souvent affiché avec le préfixe bitcoincash:) est le défaut moderne et réduit les confusions BTC/BCH.

Un portefeuille Bitcoin (BTC) peut-il payer ce code ?

Non — il rejetterait le schéma ou le format d’adresse. Pour le BTC, utilisez le Générateur de code QR Bitcoin.
