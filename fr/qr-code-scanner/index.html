    À propos de ce scanner de codes QR et de codes-barres
    

    La plupart des sites QR seulement faire codes. Cette page fait le travail inverse : elle les lit. C’est ce dont vous avez besoin quand un code imprimé n’a aucune étiquette lisible, quand un collègue vous envoie une capture d’écran d’un code au lieu du lien qu’il contient, quand vous voulez vérifier ce qu’un de vos propres codes imprimés contient réellement avant un gros tirage, ou quand un numéro de code-barres de produit doit être lu depuis une photo.
    

    Il fonctionne de deux façons. Le mode caméra utilise l’interface BarcodeDetector intégrée aux navigateurs Chromium modernes — la même détection rapide et adaptée au matériel que le système de votre téléphone utilise — et signale les codes QR et les codes-barres unidimensionnels courants. Le mode image est entièrement autonome : la bibliothèque open-source jsQR décode les codes QR depuis les pixels de votre image, et la bibliothèque open-source ZXing décode les codes-barres (et tout code QR que jsQR a manqué) depuis les mêmes pixels. Les deux s’exécutent entièrement dans votre navigateur, c’est pourquoi ce scanner continue de fonctionner avec des codes sensibles — mots de passe WiFi, codes de paiement, liens privés — que vous ne voudriez jamais téléverser sur le serveur d’un inconnu.

    Comment ça fonctionne
    

    Un code QR ou un code-barres n’est qu’un motif qui encode du texte sous forme de modules clairs et sombres. Le décodage est l’inverse de la génération : trouver le motif dans l’image, mesurer les modules, corriger les erreurs grâce à la redondance intégrée du code, et reconvertir les bits en caractères. jsQR fait cela pour les codes QR en localisant les trois carrés de repérage et en échantillonnant la grille ; ZXing le fait pour les codes-barres en scannant des rangées de pixels à travers les barres et en comparant les largeurs aux règles EAN, UPC, Code 128 ou Code 39, y compris la vérification du dernier chiffre de contrôle des codes-barres de détail. En mode caméra, le BarcodeDetector de votre propre navigateur effectue le même travail en continu sur les images vidéo en direct jusqu’à ce qu’un code soit trouvé. En mode lot, les deux mêmes décodeurs d’image s’exécutent une fois par fichier et chaque résultat — nom de fichier, format, type et texte décodé — est rassemblé dans un tableau que vous pouvez exporter en CSV.
    

    La méthode : choisissez caméra ou image → laissez le décodeur sur l’appareil lire le motif → vérifiez le type, le format et le contenu brut → utilisez l’action intelligente (ouvrir, copier, enregistrer le contact) → retrouvez le scan à tout moment dans l’historique de la session.

    Questions fréquemment posées
    

    Puis-je scanner un code depuis une capture d’écran sur le même téléphone ?
    

    Oui. Enregistrez ou partagez la capture d’écran dans votre application photos, puis utilisez le téléversement d’image ici et choisissez cette capture. Sur un ordinateur, copiez simplement l’image et collez-la dans cette page avec Ctrl+V (ou Cmd+V sur un Mac) — aucun enregistrement de fichier nécessaire.
    

    Le résultat ressemble à WIFI:T:WPA;S:… — qu’est-ce que cela signifie ?
    

    C’est le format brut standard dans un code QR WiFi : T est le type de sécurité, S est le nom du réseau (SSID) et P est le mot de passe. Cette page affiche aussi ces trois valeurs séparément au-dessus du contenu brut, pour que vous n’ayez pas à les extraire vous-même.
    

    Comment ajouter un contact scanné à mon téléphone ?
    

    Quand un scan est une vCard, une action « Télécharger le contact (.vcf) » apparaît. Téléchargez le fichier et ouvrez-le — les téléphones et ordinateurs proposent de l’enregistrer comme un contact avec le nom, l’organisation, le téléphone, l’e-mail et le site web déjà remplis.
    

    Pourquoi ma photo ne s’est-elle pas décodée ?
    

    Les causes habituelles sont un code minuscule dans une grande photo, le flou, l’éblouissement, une impression déchirée ou à faible contraste, ou une capture d’écran rognée trop serrée autour du code (les décodeurs ont besoin de la zone de silence blanche autour d’un code). Rognez largement, reprenez la photo de plus près et de face, et réessayez.
    

    Dois-je faire confiance à un code QR trouvé en public ?
    

    Scannez-le ici d’abord plutôt qu’avec une application qui ouvre les résultats automatiquement : cette page seulement affiche vous le contenu décodé et n’ouvre jamais rien tout seul. Vérifiez qu’un lien mène vraiment là où son étiquette le promet avant d’appuyer sur “Open link” — cette seule habitude déjoue la plupart des arnaques d’autocollant sur un vrai code.
