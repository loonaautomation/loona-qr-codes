À propos de ce Solana Pay

Solana Pay est une spécification formelle (pas juste une habitude de portefeuille) : une URL solana: dont les paramètres de requête — montant, libellé, message, mémo, et une référence pour le suivi des commandes — disent au portefeuille exactement quoi présenter. Les boutiques l’utilisent pour les codes de point de vente où le mémo ou la référence lie le paiement à une commande dans leur système.

Ce générateur compose les paramètres de base. Si le système de votre boutique rapproche par clés de référence, générez plutôt les codes depuis votre système — un code statique imprimé convient le mieux aux articles à prix fixe et aux dons.

Meilleures utilisations

  • Articles à prix fixe au point de vente
  • Dons avec un mémo
  • Billets d’événements et merchandising
  • Paiements de créateurs

Mettez le code exactement là où la décision est prise — sur la table, le comptoir, l’emballage, l’invitation ou l’écran — et donnez aux gens une courte phrase d’instruction comme « Scannez pour ouvrir » ou « Scannez pour payer ». Imprimez les codes à au moins 2 cm de large avec une bordure blanche silencieuse et un fort contraste pour que les caméras de téléphones plus anciens les lisent rapidement ; pour les affiches scannées à distance, utilisez la taille 1024 px et imprimez plus grand — un bon repère est environ un dixième de la distance de scan.

Comment ça fonctionne

Charge utile : solana:RECIPIENT?amount=…&label=…&message=…&memo=…, encodée en URL selon la spécification Solana Pay, pour que les portefeuilles conformes affichent le libellé et le message à la confirmation.

Exemple travaillé

Un stand de merchandising vend une affiche pour 1.5 SOL. Le mémo du code indique « POSTER-STD », pour que le vendeur associe le paiement on-chain au produit sans rien demander à personne.

Questions fréquemment posées

Ce générateur Solana Pay est-il gratuit ?

Oui. Le générateur Solana Pay de Loona est entièrement gratuit sans inscription, sans filigrane et sans limite sur le nombre de codes que vous créez, pour un usage personnel ou commercial.

Mon code QR expirera-t-il ?

Non. Loona crée des codes QR statiques : vos informations sont encodées directement dans le motif QR lui-même, pas stockées sur un serveur ni cachées derrière une redirection payante. Un code que vous imprimez aujourd’hui continuera de fonctionner tant que la destination elle-même reste active.

Mes informations sont-elles privées sur cette page Solana Pay ?

Oui. La génération se fait à 100% dans votre navigateur en JavaScript. Rien de ce que vous saisissez n’est envoyé ni stocké sur un serveur.

Quelle est la différence entre message et mémo ?

Le message n’est montré au payeur que dans le portefeuille. Le mémo est inscrit dans la transaction on-chain — visible en permanence, donc gardez-le factuel et sans données personnelles.

Puis-je accepter l’USDC sur Solana avec ceci ?

Les paiements de tokens ajoutent un paramètre spl-token nommant le mint. Cette page construit des demandes SOL natives ; pour l’USDC, générez le code depuis votre processeur de paiement pour que l’adresse du mint soit exacte.
