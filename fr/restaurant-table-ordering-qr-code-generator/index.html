À propos de cette Commande à table de restaurant

La commande à table fonctionne quand le scan arrive exactement où l’invité s’y attend : le menu, avec la commande intégrée — pas la page d’accueil du restaurant, pas un PDF de 2022. Associez un code par table (les liens de table de votre plateforme de commande) à des chevalets qui disent ce qui se passe ensuite : « Scannez, commandez, payez — nous l’apportons à la Table 12. »

Les liens spécifiques à une table comptent : ils disent à la cuisine où la nourriture va. Générez un code par table à partir des liens de votre plateforme, imprimez-les à l’identique sauf la destination, et gardez un code de menu générique à la porte pour la file.

Meilleures utilisations

  • Cartes chevalets de table
  • Comptoir et vitrine pour les commandes à emporter
  • Tables de jardin et de terrasse
  • Portes de service d’étage d’hôtel

Mettez le code exactement là où la décision est prise — sur la table, le comptoir, l’emballage, l’invitation ou l’écran — et donnez aux gens une courte phrase d’instruction comme « Scannez pour ouvrir » ou « Scannez pour payer ». Imprimez les codes à au moins 2 cm de large avec une bordure blanche silencieuse et un fort contraste pour que les caméras de téléphones plus anciens les lisent rapidement ; pour les affiches scannées à distance, utilisez la taille 1024 px et imprimez plus grand — un bon repère est environ un dixième de la distance de scan.

Comment ça fonctionne

Un QR URL statique vers le lien de table de votre plateforme de commande. La plateforme gère la commande et le paiement ; ce générateur crée la porte imprimée, gratuitement et sans expiration.

Exemple travaillé

Un café de 14 tables imprime des chevalets de table en une soirée. En un mois, un tiers des commandes du déjeuner en semaine arrivent via les codes, et l’unique file à la caisse disparaît.

Questions fréquemment posées

Ce générateur Commande à table de restaurant est-il gratuit ?

Oui. Le générateur Commande à table de restaurant de Loona est entièrement gratuit sans inscription, sans filigrane et sans limite sur le nombre de codes que vous créez, pour un usage personnel ou commercial.

Mon code QR expirera-t-il ?

Non. Loona crée des codes QR statiques : vos informations sont encodées directement dans le motif QR lui-même, pas stockées sur un serveur ni cachées derrière une redirection payante. Un code que vous imprimez aujourd’hui continuera de fonctionner tant que la destination elle-même reste active.

Mes informations sont-elles privées sur cette page Commande à table de restaurant ?

Oui. La génération se fait à 100% dans votre navigateur en JavaScript. Rien de ce que vous saisissez n’est envoyé ni stocké sur un serveur.

Un code pour toutes les tables ou un par table ?

Par table pour la commande (la cuisine a besoin de l’identité de la table). Un seul code partagé suffit pour un menu en consultation seule.

Et si les invités préfèrent un serveur ?

Gardez les deux. Les codes de table suppriment l’attente pour les invités qui veulent de la rapidité ; ils ne suppriment pas l’option humaine.
