Comment ça fonctionne

Ce générateur de code QR de localisation en ligne transforme un lieu en un lien Google Maps standard et stocke ce lien dans le code QR. Il y a deux façons de le faire. Saisissez le nom du lieu ou l’adresse exactement comme il apparaît sur Google Maps, et le générateur construit un lien de recherche Maps pour lui (de la forme google.com/maps/search/?api=1&query=Your+Place). Ou saisissez la latitude et la longitude, et le générateur construit un lien geo: contenant ces coordonnées exactes. Quand un visiteur scanne le code, le lieu s’ouvre dans Google Maps — ou dans le navigateur ou l’application de cartes par défaut du téléphone — avec les itinéraires à une touche. Tout est créé dans votre navigateur ; le code contient le lien lui-même, pas une redirection par un serveur.

Exemple travaillé

Une boulangerie ouvre une nouvelle succursale et veut que les clients la trouvent sans appels demandant l’itinéraire. La propriétaire saisit le nom et le quartier de la boutique, exactement comme l’entreprise figure sur Google Maps, dans le champ “Nom du lieu ou adresse”. Le générateur crée un code QR contenant le lien Maps de la boulangerie. Elle l’imprime sur des flyers et en colle un dans la vitrine. Un client scanne le code, Google Maps s’ouvre sur la boulangerie, il touche “Itinéraire”, et il y va directement. C’est tout ce qu’il faut pour convertir un emplacement sur carte en code QR — en moins d’une minute, sans application à installer.

Un code QR de localisation expire-t-il ?

Non. Le code stocke le lien Maps ou les coordonnées elles-mêmes, donc il n’y a aucun serveur ni redirection qui puisse être désactivé. Si votre entreprise déménage, générez simplement un nouveau code pour la nouvelle adresse.

Dois-je saisir un nom de lieu ou une latitude et une longitude ?

Le nom du lieu ou l’adresse est l’option la plus facile et convient le mieux à une entreprise listée sur Google Maps. Les coordonnées sont meilleures quand l’endroit n’a aucune fiche — un terrain, une porte de ferme, un point de livraison — ou quand vous avez besoin d’un emplacement exact plutôt que d’une zone générale.

Comment rendre la localisation aussi précise que possible ?

Ouvrez Google Maps, appuyez longuement sur l’entrée exacte de votre lieu pour déposer une épingle, et copiez les coordonnées affichées (par exemple 31.5204, 74.3587) dans les champs latitude et longitude. Les visiteurs sont alors guidés jusqu’à la porte elle-même, pas seulement jusqu’à la bonne rue ou au milieu d’un grand bâtiment.

Les gens ont-ils besoin de l’application Google Maps pour le scanner ?

Non. N’importe quelle caméra de téléphone peut lire le code. Le lien s’ouvre dans Google Maps si l’application est installée, et sinon dans le navigateur ou l’application de cartes par défaut du téléphone — les itinéraires sont disponibles dans les deux cas.

Oui, c’est l’un des usages les plus populaires. Les invités scannent le code sur la carte et obtiennent les itinéraires vers le lieu. Incluez le nom du lieu plus la ville dans le champ du lieu pour que Maps trouve le bon — beaucoup de lieux partagent des noms similaires.
