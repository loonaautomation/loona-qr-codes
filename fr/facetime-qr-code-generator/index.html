À propos de ce FaceTime

Les liens FaceTime utilisent le schéma facetime: : scannez le code sur un iPhone, iPad ou Mac et l’appel vers cet e-mail ou numéro Apple ID démarre. L’usage redoutable est la carte de contact imprimée — sur le réfrigérateur, dans le pack de soins, au bureau d’assistance — où la personne qui appelle ne devrait pas avoir à trouver des contacts, épeler des noms ni se souvenir de quoi que ce soit.

La limite évidente est Apple uniquement : les appareils Android et Windows n’ont aucun gestionnaire FaceTime. Pour les publics mixtes, imprimez un code WhatsApp à côté — les deux ensemble couvrent effectivement tout le monde.

Meilleures utilisations

  • Cartes de contact familiales
  • Packs de soins et de soutien
  • Services d’assistance de l’écosystème Apple
  • Cartes de vente et de consultation

Mettez le code exactement là où la décision est prise — sur la table, le comptoir, l’emballage, l’invitation ou l’écran — et donnez aux gens une courte phrase d’instruction comme « Scannez pour ouvrir » ou « Scannez pour payer ». Imprimez les codes à au moins 2 cm de large avec une bordure blanche silencieuse et un fort contraste pour que les caméras de téléphones plus anciens les lisent rapidement ; pour les affiches scannées à distance, utilisez la taille 1024 px et imprimez plus grand — un bon repère est environ un dixième de la distance de scan.

Comment ça fonctionne

La charge utile est facetime:CONTACT — le schéma enregistré que les appareils Apple gèrent nativement. Rien d’autre n’est nécessaire ; l’appareil récepteur résout le contact.

Exemple travaillé

Une fille imprime une carte de réfrigérateur pour son père à l’étranger : un grand code, « Scannez pour appeler Ayesha ». Les appels du dimanche n’ont plus besoin d’un SMS de rappel d’abord.

Questions fréquemment posées

Ce générateur FaceTime est-il gratuit ?

Oui. Le générateur FaceTime de Loona est entièrement gratuit sans inscription, sans filigrane et sans limite sur le nombre de codes que vous créez, pour un usage personnel ou commercial.

Mon code QR expirera-t-il ?

Non. Loona crée des codes QR statiques : vos informations sont encodées directement dans le motif QR lui-même, pas stockées sur un serveur ni cachées derrière une redirection payante. Un code que vous imprimez aujourd’hui continuera de fonctionner tant que la destination elle-même reste active.

Mes informations sont-elles privées sur cette page FaceTime ?

Oui. La génération se fait à 100% dans votre navigateur en JavaScript. Rien de ce que vous saisissez n’est envoyé ni stocké sur un serveur.

Vidéo ou audio ?

Le schéma facetime: démarre un appel vidéo par défaut. Pour l’audio uniquement, Apple utilise facetime-audio: — si c’est ce qu’il vous faut, générez un code texte avec le schéma audio ou utilisez le générateur téléphonique.

Puis-je utiliser un lien web FaceTime plutôt ?

Les liens FaceTime partageables d’Apple (depuis l’application) fonctionnent aussi sur le web — collez un tel lien dans le générateur d’URL pour un code qui l’ouvre.
