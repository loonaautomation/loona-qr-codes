Comment ça fonctionne

Vous saisissez un numéro de téléphone, et le générateur l’encode comme un lien tel: — tel: suivi de votre numéro, espaces supprimés. Quand quelqu’un scanne le code, son téléphone reconnaît le lien d’appel et affiche le numéro avec une option Appeler ; un toucher de plus et le téléphone compose. Par sécurité, les téléphones ne composent jamais automatiquement depuis un code QR : la personne voit toujours le numéro d’abord et confirme l’appel elle-même.

Exemple travaillé

Un plombier fait peindre sur son fourgon un grand QR avec les mots “Scannez pour appeler”. Il saisit son numéro au format international complet, +92 300 1234567, et imprime le code des deux côtés du fourgon. Un propriétaire dont un tuyau a éclaté le scanne depuis l’autre côté de la rue, touche Appeler sur l’invite, et lui parle en quelques secondes — au lieu de traverser pour lire onze chiffres et les saisir à la main.

Questions fréquemment posées

Dois-je inclure mon indicatif de pays ?

Oui — saisissez le format international complet, comme +92 pour le Pakistan ou +1 pour les États-Unis. Le numéro fonctionne alors pour les scanneurs de n’importe quel pays, et les téléphones peuvent le composer ou l’enregistrer correctement sans deviner.

Le scan appelle-t-il le numéro immédiatement ?

Non. Le scan affiche le numéro et une invite d’appel, et la personne touche pour composer. Les téléphones sont conçus ainsi pour qu’un code QR ne puisse jamais passer un appel sans l’action du propriétaire.

Le scanneur a-t-il besoin d’internet ou d’une application spéciale ?

Aucun internet n’est nécessaire — le numéro est dans le motif lui-même, et toute application caméra qui lit les codes QR peut proposer l’appel. L’appelant a seulement besoin d’un signal téléphonique ordinaire pour le passer.

Puis-je utiliser un numéro fixe ou un numéro d’assistance ?

Oui — tout numéro composable fonctionne, y compris les numéros fixes, les numéros gratuits et les lignes d’assistance. Le code présente simplement le numéro prêt à appeler.

Et si je change de numéro plus tard ?

Le code imprimé garde l’ancien numéro, donc générez un nouveau code et remplacez les impressions. Pour la signalétique et le travail sur véhicules coûteux, il vaut la peine d’utiliser un numéro que vous prévoyez de garder longtemps.

Les gens peuvent-ils enregistrer mon numéro depuis le code au lieu d’appeler ?

Beaucoup de téléphones proposent une option « ajouter aux contacts » à côté de l’invite d’appel après le scan d’un code tel: — et au minimum, le numéro est à l’écran pour être copié ou noté.
