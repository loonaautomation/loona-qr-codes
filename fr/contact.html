Contacter Loona QR Codes

Questions, corrections ou un type de QR que vous souhaiteriez que Loona ait ? Nous aimerions vous entendre.

Parce que Loona est un petit projet gratuit de Loona Automation, la voie de contact la plus rapide est GitHub : ouvrez une Issue sur le Dépôt GitHub de Loona QR Codes avec votre question ou suggestion, et incluez le nom de la page de générateur que vous utilisiez. Vous pouvez aussi voir d’autres projets Loona sur la Profil GitHub de Loona Automation.

Vous préférez l’e-mail ? Vous pouvez aussi nous écrire directement à loonaautomation@gmail.com — veuillez mentionner le nom de la page de générateur que vous utilisiez.

Merci de ne jamais envoyer de mots de passe, clés privées, phrases de récupération ou documents personnels sensibles en nous contactant — Loona n’en a jamais besoin, ni pour le support ni pour générer un code QR.

Loona QR Codes — Générateur de codes QR gratuit — Sans expiration, sans inscription, sans filigrane. Chaque code QR est généré en privé dans votre navigateur ; rien n’est téléversé sur un serveur, les codes n’expirent jamais et il n’y a aucun filigrane.
