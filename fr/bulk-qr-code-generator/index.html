Comment créer des codes QR en masse en 3 étapes

  1. Préparez votre liste — un code par ligne. Mettez le contenu d’abord (un lien ou n’importe quel texte) ; ajoutez une virgule et une courte étiquette si vous voulez une légende imprimée sous ce code, par exemple pour les numéros de table, les noms d’étagères ou les noms d’élèves. Ou téléversez un fichier .csv avec la même disposition.
  2. Cliquez sur Générer et vérifiez la feuille. Jusqu’à 100 codes sont créés à la fois, dans votre ordre exact, doublons inclus. Choisissez une taille de code plus grande pour les étiquettes qui seront scannées de plus loin.
  3. Imprimez la feuille ou enregistrez-la en PDF avec le bouton d’impression (les étiquettes et contenus s’impriment avec chaque code), ou téléchargez les codes individuels en fichiers PNG. Testez quelques codes de la feuille imprimée — idéalement avec notre page scanner — avant d’imprimer en quantité.

À propos de ce générateur de codes QR en masse

Les générateurs de code unique conviennent jusqu’à ce qu’il vous faille quarante chevalets de table, un jeu de codes de connexion de classe, des étiquettes d’étagère pour toute une boutique, ou un pass d’événement pour chaque invité. Les créer un par un — saisir, générer, télécharger, renommer, répéter — gaspille une heure et invite les confusions. Cet outil transforme la liste que vous avez déjà (dans un tableur, un fichier de notes ou un export CSV) en une feuille de codes finie et étiquetée en un seul passage, dans le même ordre que votre liste, pour que le code numéro 17 de la feuille soit la ligne 17 de votre fichier.

Chaque code est un code QR Loona statique normal : le contenu se trouve dans le motif lui-même, sans serveur Loona, lien court ni compte entre les deux. C’est pourquoi les codes en masse créés ici n’expirent jamais et ne peuvent pas être désactivés plus tard — et pourquoi votre liste reste privée, car la génération se fait entièrement dans votre navigateur.

Meilleures utilisations des codes QR en masse

  • Chevalets de table de restaurants et cafés — un code de menu par table, étiqueté par numéro de table
  • Jeux de classe — un code par élève menant à sa fiche, son portfolio ou sa page de connexion
  • Étiquettes d’étagères, de réserve et d’entrepôt reliant chaque emplacement ou article à sa fiche
  • Pass d’événements, badges visiteurs et documents de conférence avec un code par invité
  • Gammes de produits — un code par modèle menant à son manuel, sa garantie ou sa page de réassort
  • Campagnes d’affiches où chaque emplacement reçoit son propre lien traçable (ajoutez un ?utm_source= différent par ligne)

Les règles d’impression sont les mêmes que pour tout code QR : gardez un fort contraste (codes foncés sur fond clair), laissez la zone de silence blanche autour de chaque code quand vous découpez la feuille, et n’imprimez pas de codes plus petits qu’environ 2 cm de large pour le scan téléphonique. Sur le réglage compact 128 px, vérifiez la taille imprimée sur papier plutôt que de vous fier à l’écran — l’aperçu d’impression montre la vraie feuille.

Questions fréquemment posées

Ce générateur de codes QR en masse est-il gratuit ?

Oui. Le générateur de codes QR en masse de Loona est entièrement gratuit sans inscription, sans filigrane et sans limite sur le nombre de lots que vous créez, pour un usage personnel ou commercial.

Combien de codes QR puis-je créer à la fois ?

Jusqu’à 100 codes en un seul lot. Ce plafond garde votre navigateur rapide et la feuille imprimable gérable ; pour plus de codes, lancez simplement un autre lot. Les lignes vides sont ignorées et les lignes en double sont gardées, donc deux lignes identiques vous donnent deux copies du même code.

Quel format ma liste ou mon CSV devrait-il avoir ?

Un code par ligne. Chaque ligne est soit juste le contenu (un lien ou un texte) soit contenu,virgule,libellé — par exemple https://example.com/menu,Menu table 4. Les libellés sont imprimés sous chaque code sur la feuille. Les guillemets CSV standard fonctionnent : encadrez un champ de guillemets doubles si le contenu ou le libellé lui-même contient une virgule. Vous pouvez coller la liste ou téléverser un fichier .csv ou .txt, qui n’est lu que sur votre appareil.

Mes codes QR en masse expireront-ils ?

Non. Loona crée des codes QR statiques : le contenu de chaque code est encodé directement dans son motif, pas stocké sur un serveur ni caché derrière une redirection payante. Les codes imprimés continuent de fonctionner tant que leurs destinations restent actives.

Ma liste est-elle privée sur cette page en masse ?

Oui. La génération se fait à 100% dans votre navigateur en JavaScript. Votre liste et tout fichier CSV sont lus localement et ne sont jamais envoyés ni stockés sur un serveur.

Comment ça fonctionne

La page lit votre liste ligne par ligne avec un petit analyseur CSV qui comprend les champs entre guillemets, pour qu’un libellé comme « Smith, John » survive intact. Pour chaque ligne, elle construit un code QR statique avec la même bibliothèque de générateur que les pages de code unique de Loona, dispose les codes en grille dans l’ordre de la liste, et imprime chaque libellé et contenu sous son code pour qu’une feuille imprimée puisse être vérifiée contre la liste originale d’un coup d’œil. Rien n’est optimisé ni raccourci : le texte exact de chaque ligne est ce qui est encodé, ce que vous pouvez prouver en scannant n’importe quel code de la feuille avec le scanner Loona.

La méthode : préparez la liste (content ou content,label par ligne) → générez → vérifiez la feuille étiquetée → imprimez-la ou enregistrez-la en PDF, ou téléchargez des PNG individuels → testez le scan avant d’imprimer en quantité.

Exemple travaillé

Une enseignante a besoin d’un code pour chacun de ses 28 élèves menant à la page de lecture de cet élève. Elle exporte deux colonnes de son tableur de classe — le lien et le nom de l’élève — les colle dans cette page, et génère la feuille. Chaque code imprimé porte le nom de l’élève en dessous, pour qu’elle puisse découper la feuille et donner le bon code au bon enfant, et quand un code est perdu, elle réimprime juste cette ligne en un seul PNG au lieu de refaire tout le jeu.

Questions fréquemment posées

Puis-je mettre des détails WiFi ou des cartes de contact dans une liste en masse ?

Les contenus simples sur une ligne fonctionnent le mieux : liens et textes courts. Une charge utile WiFi (WIFI:T:WPA;S:…;P:…;;) tient sur une seule ligne, donc elle peut être générée en masse — notez qu’elle ne contient des virgules que dans le mot de passe si vous en définissez un ; mettez alors tout le champ entre guillemets. Les contenus multi-lignes comme les vCards complètes ne peuvent pas s’exprimer un par ligne ; utilisez le générateur vCard dédié pour ceux-là, un à la fois.

Mon CSV a une ligne d’en-tête. Que se passe-t-il ?

L’en-tête deviendrait un code contenant le texte d’en-tête, ce qui est facile à repérer sur la feuille étiquetée. Supprimez la ligne d’en-tête avant de générer — la première ligne devrait être votre premier vrai code.

Pourquoi y a-t-il une limite de 100 codes ?

Chaque code est dessiné dans votre navigateur ; au-delà d’une centaine environ, les téléphones et ordinateurs portables plus lents commencent à ramer et une seule feuille imprimée devient difficile à vérifier. Diviser un gros travail en lots de 100 garde la génération instantanée et la relecture réaliste.

Puis-je télécharger tous les codes en fichiers séparés à la fois ?

Chaque code de la feuille a son propre bouton de téléchargement PNG, et le bouton d’impression enregistre la feuille étiquetée complète en un seul PDF — ce qui est généralement l’artefact le plus utile pour les étiquettes et les documents, car les étiquettes voyagent avec les codes. Les navigateurs empêchent les pages d’enregistrer silencieusement de nombreux fichiers à la fois, il n’y a donc délibérément aucun bouton « télécharger 100 fichiers » qui échouerait à mi-chemin.

Une ligne a échoué ou semble erronée. Dois-je refaire le lot ?

Non. Corrigez la ligne, régénérez — la génération prend une seconde — ou créez juste ce code avec le générateur de code unique correspondant et imprimez-le séparément. L’ordre de la feuille correspond toujours à l’ordre de votre liste, donc trouver les voisins du remplacement est facile.
