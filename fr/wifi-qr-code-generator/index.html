À propos de ce code QR WiFi

Un QR WiFi stocke le nom et le mot de passe de votre réseau au format WIFI standard, pour qu’un téléphone rejoigne le réseau dès qu’il le scanne.

Un restaurant garde un QR WiFi sur chaque table ; les clients scannent une fois et sont en ligne, le personnel n’est jamais interrompu pour le mot de passe. C’est exactement le problème que résout un code QR WiFi : il supprime la saisie, la recherche et les erreurs, et les remplace par un seul scan d’environ deux secondes. Sur Loona, le code est généré localement dans votre navigateur comme un QR statique, ce qui signifie que les données vivent dans le motif lui-même. Il n’y a aucun serveur Loona au milieu, aucun lien court qui puisse être désactivé, et aucune période d’essai après laquelle vos documents imprimés cesseraient de fonctionner — un problème fréquent et coûteux sur de nombreux sites de codes QR dits gratuits.

Comment ça fonctionne

Le code stocke les détails de votre réseau au format WIFI standard que les téléphones comprennent : le type de sécurité (WPA pour la plupart des routeurs modernes), le nom de votre réseau (SSID) exactement comme le routeur le diffuse, et le mot de passe — sous la forme WIFI:T:WPA;S:YourNetwork;P:YourPassword;;. Si vous choisissez “nopass” pour un réseau ouvert, aucun mot de passe n’est stocké du tout. Au scan, un téléphone compatible reconnaît le format et propose de rejoindre le réseau, pour que les invités se connectent sans rien saisir.

Exemple travaillé

Un petit café utilise le nom de réseau BeanScene_Guest avec le mot de passe WPA coffee2026 sur son routeur invité. Le code est imprimé sur une carte au comptoir indiquant “Scannez pour le WiFi gratuit”. Une cliente le scanne, son téléphone affiche “Rejoindre BeanScene_Guest ?”, elle touche Rejoindre, et elle est en ligne — le personnel n’a pas épelé un mot de passe de toute la journée.

Questions fréquemment posées

Est-il sûr d’afficher mon mot de passe WiFi en code QR ?

Soyez conscient de ce qu’est le code : quiconque le scanne — ou le photographie — peut extraire le mot de passe réel du motif, car le mot de passe y est stocké en texte lisible. C’est très bien pour un réseau invité que vous êtes heureux de partager, mais n’affichez pas un code pour votre réseau privé de maison ou de bureau là où des personnes non fiables peuvent le voir, et changez le mot de passe invité si un code a été partagé trop largement.

Chaque téléphone se connectera-t-il automatiquement après le scan ?

La plupart des téléphones modernes le feront : les téléphones Android récents et les iPhones affichent une invite de connexion à ce réseau lors du scan. Certains téléphones plus anciens et quelques applications scanner affichent simplement le nom du réseau et le mot de passe en texte, que l’invité saisit alors manuellement — toujours plus rapide que de demander au comptoir, mais pas en une touche.

Le nom de mon réseau a des majuscules et des espaces. Est-ce important ?

Oui — le SSID doit correspondre exactement au nom diffusé par le routeur, y compris les majuscules et les espaces, sinon les téléphones chercheront un réseau qui n’existe pas. Copiez-le caractère par caractère depuis l’étiquette ou la page de paramètres de votre routeur.

Et si mon WiFi n’a aucun mot de passe ?

Choisissez “nopass” comme type de sécurité et laissez le mot de passe vide. Le code indique alors aux téléphones que le réseau est ouvert, et les invités rejoignent sans aucune étape de mot de passe.

J’ai changé le mot de passe de mon routeur. Ai-je besoin d’un nouveau code ?

Oui. L’ancien mot de passe est figé dans le motif imprimé, donc les scans proposeront le mauvais mot de passe et échoueront à se connecter. Générez un code frais avec le nouveau mot de passe — beaucoup de cafés changent à la fois le mot de passe invité et le code imprimé tous les quelques mois.
