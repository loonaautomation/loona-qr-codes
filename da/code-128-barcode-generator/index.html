Om denne Code 128

Code 128 (ISO/IEC 15417) er verdens generelle stregkode med høj tæthed: den pakker bogstaver, tal og tegnsætning ind i den smalleste bredde af enhver 1D-symbologi, hvilket er grunden til, at den dominerer forsendelsesetiketter (som GS1-128), lagerreoler, aktivmærker og bibliotekssystemer.

Den virker i tre tegnundersæt — A (store bogstaver + kontrolkoder), B (fuld ASCII med blandede store og små bogstaver) og C (cifferpar med dobbelt tæthed) — og en god koder skifter undersæt automatisk for at holde symbolet kort. Hvert Code 128-symbol bærer en indbygget modulo-103-kontrolsum, så scannere afviser beskadigede læsninger i stedet for at gætte.

Bedste anvendelser

  • Lager- og lageretiketter
  • Forsendelses- og palleetiketter (GS1-128)
  • Mærker til aktiver og udstyr
  • Biblioteks- og arkivgenstande

Sæt koden præcis der, hvor beslutningen træffes — på bordet, disken, emballagen, invitationen eller skærmen — og giv folk én kort vejledningslinje som “Scan for at åbne” eller “Scan for at betale”. Tryk koder mindst 2 cm brede med en stille hvid kant og stærk kontrast, så ældre telefonkameraer læser dem hurtigt; til plakater, der scannes på afstand, skal du bruge størrelsen 1024 px og trykke større — en god vejledning er omtrent en tiendedel af scanningsafstanden.

Sådan virker det

Når du skriver, vælger koderen automatisk undersætblandingen: lange ciferserier komprimeres med undersæt C (to cifre pr. tegn), hvilket er grunden til, at et serienummer på 20 cifre giver en overraskende kort stregkode.

Gennemarbejdet eksempel

Et værksted mærker hver kundeenhed med Code 128-mærker, der koder jobnummeret, f.eks. INV-2026-0042. Ved indtjekning og afsendelse scannes mærket — ingen skrivning, ingen ombyttede cifre — og jobhistorikken åbner med det samme.

Ofte stillede spørgsmål

Er denne Code 128-generator gratis?

Ja. Loonas Code 128-generator er helt gratis uden tilmelding, uden vandmærke og uden grænse for, hvor mange koder du opretter, til personlig eller kommerciel brug.

Vil min QR-kode udløbe?

Nej. Loona opretter statiske QR-koder: dine oplysninger kodes direkte inde i selve QR-mønsteret, ikke gemt på en server eller skjult bag en betalt omdirigering. En kode, du trykker i dag, bliver ved med at virke, så længe selve destinationen forbliver aktiv.

Er mine oplysninger private på denne Code 128-side?

Ja. Generering sker 100% i din browser ved hjælp af JavaScript. Intet, du indtaster, sendes til eller gemmes på nogen server.

Code 128 vs Code 39 — hvad skal jeg bruge?

Code 128 til næsten alt moderne: den er tættere, understøtter små bogstaver og tegnsætning og har en obligatorisk kontrolsum. Code 39 overlever hovedsagelig, hvor gamle scannere eller en brancheregel (nogle etiketter til bilindustri og forsvar) kræver den.

Kan Code 128 kode små bogstaver?

Ja — undersæt B dækker hele det trykbare ASCII-interval, herunder små bogstaver, og denne generator skifter undersæt automatisk.
