In every case the rule is the same: put the QR code exactly where the decision is made — on the table, the counter, the packaging, the invitation or the screen — and give people one short line of instruction such as “Scan to connect” or “Scan to pay”. How it works

The code stores your meeting link exactly as you paste it — this tool is for any meeting service, not just Zoom: a Zoom join link, a Google Meet link or a Microsoft Teams link all work, and if you forget the https:// at the start it is added for you. An online tutor uses the same recurring Zoom link for her Saturday class and prints this code at the top of the printed timetable she gives every student. Frequently asked questions

Does this work for Google Meet and Teams too?

Yes. The generator simply encodes whatever meeting link you paste, from any service. Zoom, Google Meet, Microsoft Teams, Webex and others all provide shareable join links, and any of them can go into the code.

Should I use a recurring meeting link or a fresh one each time?

For anything printed, always use a recurring (or personal) meeting link that stays the same. A one-off link created for a single meeting will stop working afterwards, while a recurring link lets one printed code serve all term or all season.

My meeting has a passcode. Will scanners still need it?

If your join link has the passcode embedded in it (Zoom links with a “pwd” part in the address work this way), scanners go straight in with no typing. If your meeting uses a separate passcode, print it as plain text next to the code.

What if a student scans on a laptop-less phone without the Zoom app?

The link opens in their browser, where Zoom offers a “join from browser” option or prompts them to install the free app. Either way they reach the same meeting from the same code.

Can I put the code in slides and documents instead of printing it?

Absolutely. The downloaded PNG can be dropped into slides, PDFs, emails and group descriptions. A code on the title slide of every class deck means latecomers can join quietly without interrupting.
