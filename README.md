## Step A — GitHub par repo banana aur files upload karna (asan alfaz)
1. Apne account **loonaautomation** (https://github.com/loonaautomation) se github.com par login karo.
2. Upar right side `+` → **New repository**. Naam bilkul ye rakho: `loona-qr-codes`. Public rakho, phir **Create repository**.
3. Is folder (`loona-qr-codes`) ki **saari files aur folders** upload karo: repository page par **Add file → Upload files**, files drag-drop karo, phir **Commit changes**.
   - Dhyaan: files repo ke bilkul root me honi chahiye — `index.html` seedha root me, uske andar ek aur `loona-qr-codes` folder NAHI hona chahiye.

## Step B — GitHub Pages ON karna
1. Repo → **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: `main`, Folder: `/ (root)` → **Save**.
3. 1-3 minute baad tumhari site live hogi is address par: `https://loonaautomation.github.io/loona-qr-codes/`

## Step C — URL check (kuch badalna nahi hai)
Website ke andar (sitemap.xml, har page ki canonical, robots.txt) yehi address `https://loonaautomation.github.io/loona-qr-codes/` pehle se laga hua hai. Tumhe kuch change nahi karna — bas repo ka naam `loona-qr-codes` hi rakhna hai. Agar kabhi repo ka naam ya custom domain badlo to mujhe (Muse ko) bata dena, main naya address laga dun ga.

## Step D — Google Search Console me listing
1. search.google.com/search-console → **Add property** → URL prefix me ye dalo: `https://loonaautomation.github.io/loona-qr-codes/`
2. Ownership verify karo (GitHub Pages ke liye HTML tag wala tareeqa asan hai: tag ko `index.html` ke `<head>` me paste karke site dubara upload karo, phir Verify dabao).
3. Console → **Sitemaps** → `sitemap.xml` likh kar **Submit**.
4. Google kuch din me pages ko ek-ek karke index karega — har page alag search me aa sakega.

## Step E — Earning / AdSense (baad me)
- Pehle traffic aane do. Jab Search Console me impressions/clicks aana shuru ho jayein aur roz ke visitors ban jayein, tab Google AdSense ke liye apply karna — yehi sahi waqt hota hai.
- Agar aage chal kar serious earning chahiye to ek custom domain (misal loonaqrcodes.com) khareed kar GitHub Pages se connect kar sakte ho — ye optional hai, shuru me free GitHub Pages URL hi kaafi hai.
- Codes hamesha print se pehle khud scan karke test kar lena.
