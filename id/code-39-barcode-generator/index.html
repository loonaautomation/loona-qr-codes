Tentang Code 39 ini

Code 39 (USS Code 39, Code 3 of 9) adalah kode batang alfanumerik tertua yang masih digunakan setiap hari — dikembangkan pada 1974 dan tetap hidup oleh label otomotif, pertahanan, perawatan kesehatan, dan pemerintah yang menetapkannya puluhan tahun lalu. Setiap karakter selebar sembilan elemen (lima batang, empat spasi, tiga di antaranya lebar), yang membuatnya toleran terhadap pencetakan yang buruk tetapi panjang untuk data yang dibawanya.

Alfabetnya kecil: kapital A–Z, digit, dan beberapa simbol. Ia memeriksa diri sendiri (satu karakter buruk jarang terverifikasi), dan digit pemeriksa modulo-43 opsional dapat ditambahkan di tempat sistem penerima mengharapkannya.

Penggunaan terbaik

  • Label warisan otomotif dan pertahanan
  • Lencana nama dan kartu ID
  • Buku perpustakaan (sistem lama)
  • Tempat industri dan krib alat

Letakkan kode tepat di tempat keputusan dibuat — di meja, konter, kemasan, undangan, atau layar — dan beri orang satu baris petunjuk pendek seperti “Pindai untuk membuka” atau “Pindai untuk membayar”. Cetak kode setidaknya selebar 2 cm dengan batas putih yang tenang dan kontras yang kuat agar kamera ponsel lama membacanya dengan cepat; untuk poster yang dipindai dari kejauhan, gunakan ukuran 1024 px dan cetak lebih besar — panduan yang baik adalah kira-kira sepersepuluh dari jarak pemindaian.

Cara kerjanya

Contoh yang dikerjakan

Krib alat sebuah pabrik masih menjalankan sistem Code 39 tahun 1990-an. Label papan bayangan baru dicetak dari halaman ini — PART-8841-A dan kode serupa — dan pemindai lama membacanya pada percobaan pertama.

Mengapa teks huruf kecil saya berubah?

Code 39 tidak memiliki huruf kecil dalam alfabet standarnya, sehingga enkoder mengubahnya menjadi huruf kapital. Jika huruf besar/kecil penting, gunakan Code 128 sebagai gantinya.

Apakah Code 39 membutuhkan digit pemeriksa?

Tidak — ia memeriksa diri sendiri secara desain. Digit pemeriksa modulo-43 ada untuk sistem yang memintanya, tetapi sebagian besar label Code 39 dicetak tanpanya.
