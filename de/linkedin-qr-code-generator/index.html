Über diesen LinkedIn-QR-Code

Ein LinkedIn-QR-Code öffnet Ihr berufliches Profil oder Ihre Unternehmensseite und macht Networking auf Veranstaltungen schnell und papierlos.

Auf einer Jobmesse ermöglicht der LinkedIn-QR-Code eines Absolventen auf seinem Lebenslauf Recruitern, sich zu verbinden, bevor der Tag endet. Das ist das eigentliche Problem, das ein LinkedIn-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Ja. Loonas LinkedIn-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein LinkedIn-QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst (zum Beispiel Ihre Website oder Nummer) aktiv bleibt.

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben — Passwörter, Nummern oder Links — wird an einen Server gesendet oder auf einem gespeichert.

So funktioniert es

Sie fügen die vollständige Webadresse Ihres LinkedIn-Profils oder Ihrer Unternehmensseite ein, und diese URL wird exakt wie angegeben im QR-Muster codiert. Wenn jemand den Code scannt, öffnet sich die Adresse in der LinkedIn-App, wenn er sie hat, oder in seinem Browser — und zeigt Ihr Profil oder Ihre Seite, wo er sich mit LinkedIns eigenen Schaltflächen verbinden, folgen oder Ihnen eine Nachricht senden kann. Diese Seite nimmt die vollständige URL statt eines Benutzernamens, weil LinkedIn-Adressen Ihren personalisierten Public-URL-Slug enthalten, und das Einfügen der vollständigen Adresse garantiert, dass der Code auf die richtige Person zeigt.

Ausgearbeitetes Beispiel

Ein frischer Absolvent besucht eine Jobmesse mit gedrucktem Lebenslauf, einem LinkedIn-QR-Code in der Ecke, erstellt aus seiner öffentlichen Profiladresse, https://www.linkedin.com/in/ahmed-raziq. Zwischen Gesprächen scannt ihn eine Recruiterin; sein Profil öffnet sich mit seinem Foto, Abschluss und seiner Projektarbeit, und sie sendet sofort eine Verbindungsanfrage — statt seinen Namen in die LinkedIn-Suche einzutippen und zu raten, welcher von mehreren ähnlichen Namen der richtige ist.

Häufig gestellte Fragen

Wo finde ich meine LinkedIn-Profil-URL?

Öffnen Sie LinkedIn, gehen Sie zu Ihrem Profil und kopieren Sie die Adresse aus dem Browser — sie sieht aus wie linkedin.com/in/yourname. Öffnen Sie auf dem Handy Ihr Profil, tippen Sie auf das Menü “…” und verwenden Sie die Option zum Teilen oder Link kopieren. Kopieren Sie für eine Unternehmensseite die Adresse der Seite auf dieselbe Weise.

Funktioniert dies für eine Unternehmensseite ebenso wie für ein persönliches Profil?

Ja — fügen Sie eine der beiden Adressen ein. Der Code öffnet einfach die LinkedIn-URL, die Sie ihm geben.

Verbindet uns das Scannen automatisch?

Nein. Das Scannen öffnet Ihr Profil; der Besucher tippt immer noch selbst auf Verbinden oder Folgen. LinkedIn hält dies als bewusste Handlung, und es gibt ihm auch die Chance, zuerst eine Notiz hinzuzufügen.

Warum bittet LinkedIn den Scanner manchmal, sich anzumelden?

LinkedIn begrenzt, was abgemeldete Besucher sehen und tun können. Angemeldete Mitglieder gehen direkt zu Ihrem vollständigen Profil; andere sehen möglicherweise eine öffentliche Version oder eine Anmeldeaufforderung. Dieses Verhalten ist LinkedIns, nicht das des Codes.

Meine Profil-URL enthält Zahlen oder zusätzliche Wörter. Ist das ein Problem?

Nein — fügen Sie die Adresse exakt so ein, wie sie ist, mit Zahlen und allem. Wenn Sie ein saubereres Code-Ziel bevorzugen, können Sie die Adresse zuerst in LinkedIns öffentlichen Profileinstellungen personalisieren und dann den Code aus der neuen Adresse erzeugen.

Wo drucken Menschen normalerweise einen LinkedIn-QR-Code?

Auf Lebensläufen, Konferenz-Namensschildern, Visitenkarten und Unternehmensstand-Displays — überall dort, wo eine professionelle Vorstellung persönlich geschieht.
