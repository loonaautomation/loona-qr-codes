Über dieses Interleaved 2 of 5

Interleaved 2 of 5 (ITF) ist ein kompakter numerischer Barcode: Zwei Ziffern teilen sich jede Zeichenposition — eine in den Balken, eine in den Lücken —, was die Länge eines einfachen Code 25-Symbols halbiert. Er ist seit den 1960er Jahren das Arbeitstier von Lagerhaltung, Vertrieb und Ticketing.

Seine eine Falle ist die Länge: Weil sich Ziffern paaren, kann eine ungerade Anzahl nicht codiert werden — die klassische Lösung ist eine führende Null. ITF hat keine eingebaute Prüfziffer im allgemeinen Gebrauch, daher fügen viele Systeme eine Modulo-10-Ziffer per Konvention hinzu (ITF-14 ist die formalisierte Ausnahme).

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Interleaved 2 of 5-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Warum wurde eine Null zu meiner Nummer hinzugefügt?

ITF codiert Ziffernpaare; eine Zahl mit ungerader Länge kann sich nicht paaren. Eine führende Null ist die Standardauffüllung — stimmen Sie mit Ihrem System ab, ob es den aufgefüllten oder den rohen Wert erwartet.

Ist ITF dasselbe wie ITF-14?

ITF-14 ist ITF, festgelegt auf genau 14 Ziffern mit einer GS1-Prüfziffer und Verpackungsregeln. Einfaches ITF ist jede gerade Länge ohne formale Prüfziffer.
