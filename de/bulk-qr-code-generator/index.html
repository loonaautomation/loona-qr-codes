Fügen Sie eine Liste mit Links oder Texten ein — oder laden Sie eine CSV-Datei hoch — und erhalten Sie bis zu 100 beschriftete QR-Codes auf einem druckbaren Blatt. Keine Anmeldung, kein Wasserzeichen, und Ihre Codes laufen niemals ab.

Tipp: Verwenden Sie Drucken, um das ganze Blatt als PDF zu speichern, oder laden Sie jeden einzelnen Code als PNG mit seiner eigenen Schaltfläche herunter. Überprüfen Sie das Blatt vor einer großen Druckauflage mit unserem QR-Code- & Barcode-Scanner.

So erstellen Sie QR-Codes im Stapel in 3 Schritten

  1. Bereiten Sie Ihre Liste vor — ein Code pro Zeile. Setzen Sie den Inhalt zuerst (einen Link oder beliebigen Text); fügen Sie ein Komma und eine kurze Bezeichnung hinzu, wenn Sie eine Beschriftung unter diesem Code gedruckt haben möchten, zum Beispiel für Tischnummern, Regalbezeichnungen oder Schülernamen. Oder laden Sie eine .csv-Datei mit demselben Aufbau hoch.
  2. Klicken Sie auf Erzeugen und überprüfen Sie das Blatt. Bis zu 100 Codes werden auf einmal erstellt, in Ihrer exakten Reihenfolge, Duplikate eingeschlossen. Wählen Sie eine größere Codegröße für Etiketten, die aus größerer Entfernung gescannt werden.
  3. Drucken Sie das Blatt oder speichern Sie es als PDF mit der Druck-Schaltfläche (Bezeichnungen und Inhalte drucken mit jedem Code), oder laden Sie einzelne Codes als PNG-Dateien herunter. Scannen Sie einige Codes vom gedruckten Blatt zum Testen — idealerweise mit unserer Scanner-Seite — bevor Sie in Menge drucken.

Über diesen Stapel-QR-Code-Generator

Einzel-Code-Generatoren sind in Ordnung, bis Sie vierzig Tischaufsteller, einen Klassensatz Login-Codes, Regaletiketten für ein ganzes Geschäft oder einen Event-Pass für jeden Gast brauchen. Diese einzeln zu erstellen — tippen, erzeugen, herunterladen, umbenennen, wiederholen — verschwendet eine Stunde und lädt zu Verwechslungen ein. Dieses Tool verwandelt die Liste, die Sie bereits haben (in einer Tabelle, einer Notizdatei oder einem CSV-Export), in einem Durchgang in ein fertiges, beschriftetes Blatt mit Codes, in derselben Reihenfolge wie Ihre Liste, sodass Code Nummer 17 auf dem Blatt Zeile 17 Ihrer Datei ist.

Jeder Code ist ein normaler statischer Loona-QR-Code: Der Inhalt sitzt im Muster selbst, ohne Loona-Server, Kurzlink oder Konto dazwischen. Deshalb laufen hier erstellte Stapel-Codes niemals ab und können später nicht abgeschaltet werden — und deshalb bleibt Ihre Liste privat, weil die Erzeugung vollständig in Ihrem Browser geschieht.

Beste Verwendungen von Stapel-QR-Codes

  • Restaurant- und Café-Tischaufsteller — ein Speisekarten-Code pro Tisch, beschriftet nach Tischnummer
  • Klassenzimmer-Sätze — ein Code pro Schüler, der auf sein Arbeitsblatt, Portfolio oder seine Login-Seite verlinkt
  • Regal-, Lagerraum- und Lageretiketten, die jeden Standort oder Artikel mit seinem Datensatz verlinken
  • Event-Pässe, Besucherausweise und Konferenz-Handouts mit einem Code pro Gast
  • Produktreihen — ein Code pro Modell, der auf sein Handbuch, seine Garantie oder Nachbestellseite verlinkt
  • Plakatkampagnen, bei denen jeder Standort seinen eigenen verfolgbaren Link erhält (fügen Sie ein anderes ?utm_source= pro Zeile hinzu)

Die Druckregeln sind dieselben wie für jeden QR-Code: Halten Sie starken Kontrast (dunkle Codes auf hellem Hintergrund), lassen Sie die weiße Ruhezone um jeden Code, wenn Sie das Blatt zerschneiden, und drucken Sie Codes nicht kleiner als etwa 2 cm breit für das Telefon-Scannen. Überprüfen Sie bei der kompakten Einstellung 128 px die gedruckte Größe auf Papier, statt dem Bildschirm zu vertrauen — die Druckvorschau zeigt das echte Blatt.

Häufig gestellte Fragen

Ist dieser Stapel-QR-Code-Generator kostenlos?

Ja. Loonas Stapel-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Stapel Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Wie viele QR-Codes kann ich auf einmal erstellen?

Bis zu 100 Codes in einem Stapel. Diese Obergrenze hält Ihren Browser schnell und das druckbare Blatt handhabbar; führen Sie für mehr Codes einfach einen weiteren Stapel aus. Leere Zeilen werden übersprungen und doppelte Zeilen werden behalten, sodass zwei identische Zeilen Ihnen zwei Kopien desselben Codes geben.

In welchem Format sollte meine Liste oder CSV-Datei sein?

Ein Code pro Zeile. Jede Zeile ist entweder nur der Inhalt (ein Link oder Text) oder Inhalt,Komma,Bezeichnung — zum Beispiel https://example.com/menu,Table 4 menu. Bezeichnungen werden unter jeden Code auf dem Blatt gedruckt. Standard-CSV-Quoting funktioniert: Wickeln Sie ein Feld in doppelte Anführungszeichen, wenn der Inhalt oder die Bezeichnung selbst ein Komma enthält. Sie können die Liste einfügen oder eine .csv- oder .txt-Datei hochladen, die nur auf Ihrem Gerät gelesen wird.

Laufen meine Stapel-QR-Codes ab?

Nein. Loona erstellt statische QR-Codes: Der Inhalt jedes Codes ist direkt in seinem Muster codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Gedruckte Codes funktionieren, solange ihre Ziele aktiv bleiben.

Ist meine Liste auf dieser Stapelseite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Ihre Liste und jede CSV-Datei werden lokal gelesen und niemals an einen Server gesendet oder auf einem gespeichert.

So funktioniert es

Nichts wird optimiert oder gekürzt: Der exakte Text jeder Zeile ist das, was codiert wird, was Sie beweisen können, indem Sie jeden Code auf dem Blatt mit dem Loona-Scanner scannen.

Eine Lehrerin braucht für jeden ihrer 28 Schüler einen Code, der auf die Leseseite dieses Schülers verlinkt. Sie exportiert zwei Spalten aus ihrer Klassentabelle — den Link und den Namen des Schülers —, fügt sie auf dieser Seite ein und erzeugt das Blatt. Häufig gestellte Fragen

Kann ich WLAN-Details oder Kontaktkarten in eine Stapelliste einfügen?

Einfache einzeilige Inhalte funktionieren am besten: Links und kurze Texte. Eine WLAN-Nutzlast (WIFI:T:WPA;S:…;P:…;;) ist eine einzelne Zeile, sodass sie im Stapel erzeugt werden kann — beachten Sie, dass sie Kommas nur innerhalb des Passworts enthält, wenn Sie eines festlegen; setzen Sie das ganze Feld in Anführungszeichen, wenn dem so ist. Mehrzeilige Inhalte wie vollständige vCards können nicht eine pro Zeile ausgedrückt werden; verwenden Sie dafür den dedizierten vCard-Generator, einen nach dem anderen.

Meine CSV-Datei hat eine Kopfzeile. Was passiert?

Die Kopfzeile würde zu einem Code werden, der den Kopfzeilentext enthält, was auf dem beschrifteten Blatt leicht zu erkennen ist. Löschen Sie die Kopfzeile vor dem Erzeugen — die erste Zeile sollte Ihr erster echter Code sein.

Warum gibt es ein Limit von 100 Codes?

Jeder Code wird in Ihrem Browser gezeichnet; jenseits von etwa hundert beginnen langsamere Telefone und Laptops zu verzögern, und ein einzelnes gedrucktes Blatt wird schwer zu prüfen. Das Aufteilen einer großen Aufgabe in Stapel von 100 hält die Erzeugung sofortig und das Korrekturlesen realistisch.

Kann ich alle Codes auf einmal als separate Dateien herunterladen?

Jeder Code auf dem Blatt hat seine eigene PNG-Download-Schaltfläche, und die Druck-Schaltfläche speichert das vollständige beschriftete Blatt als eine PDF — was normalerweise das nützlichere Artefakt für Etiketten und Handouts ist, weil die Beschriftungen mit den Codes reisen. Browser beschränken Seiten darin, still viele Dateien auf einmal zu speichern, daher gibt es absichtlich keine Schaltfläche „100 Dateien herunterladen“, die auf halbem Weg fehlschlagen würde.

Eine Zeile ist fehlgeschlagen oder sieht falsch aus. Wiederhole ich den Stapel?

Nein. Korrigieren Sie die Zeile, erzeugen Sie neu — die Erzeugung dauert eine Sekunde — oder erstellen Sie nur diesen einen Code mit dem passenden Einzel-Code-Generator und drucken Sie ihn separat. Die Blattreihenfolge entspricht immer Ihrer Listenreihenfolge, sodass das Finden der Nachbarn des Ersatzes leicht ist.
