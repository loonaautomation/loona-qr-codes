Über diesen Google-Bewertungs-QR-Code

Ein Google-Bewertungs-QR-Code öffnet Ihr Bewertungsformular für Ihr Unternehmen direkt. Bewertungen verbessern Ihr Ranking auf Google Maps und in der Suche, und im richtigen Moment zu fragen ist alles.

Ein Salon hält einen Bewertungs-QR-Code an der Zahltheke bereit; eine zufriedene Kundin hinterlässt 5 Sterne, bevor sie hinausgeht. Das ist das eigentliche Problem, das ein Google-Bewertungs-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines Google-Bewertungs-QR-Codes

  • Restaurants, Cafés und Salons an der Theke
  • Kliniken, Werkstätten und Dienstleistungsunternehmen
  • Hotels und Gästehäuser beim Checkout
  • Jedes lokale Unternehmen, das auf Google Maps lebt

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Sie können Loona-QR-Codes frei für kommerzielle Arbeit verwenden — Speisekarten, Visitenkarten, Kundenprojekte, Verpackungen und Beschilderungen — ohne erforderliche Namensnennung. Weil die Erzeugung privat und offline-fähig ist, sobald die Seite geladen hat, verlassen sensible Details wie WLAN-Passwörter und Zahlungsnummern niemals Ihr Gerät. Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

Ja. Loonas Google-Bewertungs-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein Google-Bewertungs-QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst (zum Beispiel Ihre Website oder Nummer) aktiv bleibt.

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben — Passwörter, Nummern oder Links — wird an einen Server gesendet oder auf einem gespeichert.

So funktioniert es

Sie fügen den Bewertungslink ein, den Google Ihrem Unternehmen gibt: Innerhalb von Google Business Profile erzeugt die Option “Ask for reviews” einen kurzen Link, der das Bewertungsformular Ihres Unternehmens direkt öffnet. Wenn ein Kunde ihn scannt, öffnet Google die Sternebewertung und Bewertungsbox für Ihr Unternehmen; der Kunde meldet sich mit seinem Google-Konto an — Google verlangt dies für alle Bewertungen — und schreibt die Bewertung. Der Code berührt die Bewertung selbst niemals; er entfernt einfach den Suchschritt, der die meisten glücklichen Kunden davon abhält, jemals eine zu hinterlassen.

Häufig gestellte Fragen

Wo genau erhalte ich meinen Bewertungslink?

Melden Sie sich im Google Unternehmensprofil an, öffnen Sie Ihr Unternehmen und wählen Sie “Ask for reviews”. Google zeigt einen kurzen Teilen-Link — kopieren Sie diesen und fügen Sie ihn hier ein. Ein normaler Google Maps-Link zu Ihrem Unternehmen ist nicht dasselbe: Er öffnet Ihr Inserat, nicht das Bewertungsformular.

Kann ich einen Code für alle meine Filialen verwenden?

Nein — jeder Standort hat seinen eigenen Bewertungslink in seinem eigenen Unternehmensprofil-Eintrag. Erzeugen Sie einen separaten Code pro Filiale, damit jede Bewertung auf dem richtigen Eintrag landet.

Warum bittet Google den Kunden, sich anzumelden?

Google akzeptiert Bewertungen nur von angemeldeten Google-Konten, was Bewertungen echt hält. Der QR-Code kann diesen Schritt nicht umgehen; er bringt den Kunden nur direkt zum Formular.

Garantiert der Code Fünf-Sterne-Bewertungen?

Nein. Er öffnet dasselbe öffentliche Bewertungsformular für alle, und jeder Kunde wählt seine eigene Bewertung und seine eigenen Worte — was auch Ihre Bewertungen innerhalb von Googles Richtlinien hält.

Wo soll ich den Bewertungs-QR-Code für die besten Ergebnisse platzieren?

Wo die Zufriedenheit ihren Höhepunkt erreicht und der Kunde noch einen Moment hat: an der Zahltheke, am Tisch nach einer Mahlzeit, am Checkout-Schreibtisch oder gedruckt auf dem Beleg. Eine kurze Zeile wie “Scan to review us on Google” macht die Bitte klar.

Was, wenn Google mir später einen neuen Bewertungslink gibt?

Der Code enthält den Link, den Sie eingefügt haben. Wenn sich Ihr Bewertungslink ändert, erzeugen Sie einen neuen Code aus dem neuen Link und tauschen Sie die Drucke aus; der alte Code zeigt weiter auf die alte Adresse.
