Über diesen PayPal-QR-Code

Ein PayPal-QR-Code öffnet Ihre PayPal.me-Seite, optional mit bereits festgelegtem Betrag, sodass Mandanten und Kunden bezahlen können, ohne nach Details fragen zu müssen.

Das ist das eigentliche Problem, das ein PayPal-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Häufig gestellte Fragen

Ist dieser PayPal-QR-Code-Generator kostenlos?

Ja. Loonas PayPal-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein PayPal-QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst (zum Beispiel Ihre Website oder Nummer) aktiv bleibt.

Wie verwende ich den PayPal-QR-Code, den ich erzeugt habe?

Füllen Sie das Formular aus, überprüfen Sie die Live-Vorschau, wählen Sie Ihre Farben und Größe und klicken Sie dann auf PNG herunterladen. Drucken Sie ihn aus oder teilen Sie ihn digital, und scannen Sie ihn immer einmal mit Ihrem eigenen Telefon zum Testen, bevor Sie in großer Menge drucken.

Sind meine Informationen auf dieser PayPal-QR-Code-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben — Passwörter, Nummern oder Links — wird an einen Server gesendet oder auf einem gespeichert.

Häufig gestellte Fragen

In welcher Währung ist der Betrag?

Der Link trägt eine einfache Zahl ohne Währungssymbol. PayPal präsentiert sie in der Währung Ihres PayPal.Me-Kontos und zeigt dem Zahler den Betrag — und jede Umrechnung —, bevor er bestätigt, prüfen Sie also, ob Ihre PayPal.Me-Seite die Währung zeigt, die Sie erwarten.

Braucht der Zahler ein PayPal-Konto?

In den meisten Fällen ja — PayPal.Me-Zahlungen werden von einem PayPal-Konto gesendet, und die Seite führt den Zahler durch Anmeldung oder Registrierung. Die genauen Optionen variieren je nach Land.

Ich habe meinen vollständigen PayPal.Me-Link statt des Benutzernamens eingefügt. Funktioniert es trotzdem?

Ja. Der Generator erkennt vollständige paypal.me-Links und reduziert sie auf nur den Benutzernamen, bevor er Ihren Code baut.

Kann ich den Betrag leer lassen?

Ja — das Feld ist optional. Ohne einen Betrag öffnet sich Ihre PayPal.Me-Seite, und der Zahler gibt die Summe selbst ein, was zu Trinkgeldern, Spenden und variablen Rechnungen passt.

Kann ich den Betrag nach dem Drucken ändern?

Nein — ein Betrag, den Sie festlegen, wird Teil des codierten Links. Erzeugen Sie einen neuen Code für einen anderen Betrag oder drucken Sie die Version ohne Betrag, wenn Zahlungen variieren.

Gibt es Gebühren für den Empfang von Geld auf diesem Weg?

PayPals Standardgebühren für den Empfang von Zahlungen können anfallen, abhängig von der Zahlungsart und den beteiligten Ländern. Der QR-Code selbst fügt keine Gebühr hinzu, und Loona berechnet nichts.
