Über diesen WhatsApp-QR-Code

Ein WhatsApp-QR-Code öffnet einen Chat mit Ihrer Nummer in WhatsApp über den offiziellen wa.me-Link und kann sogar die erste Nachricht vorausfüllen.

Ein Bekleidungsgeschäft druckt einen WhatsApp-QR-Code auf seine Einkaufstüten; Kunden scannen und fragen sofort nach neuer Ware. Das ist das eigentliche Problem, das ein WhatsApp-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines WhatsApp-QR-Codes

  • Geschäfte, die Bestellungen auf WhatsApp annehmen

  • Social-Media-Bios und gedruckte Anzeigen

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

So funktioniert es

Das Tool erstellt einen WhatsApp-Click-to-Chat-Link: https://wa.me/ gefolgt von Ihrer Nummer im internationalen Format — nur die Ziffern bleiben erhalten, sodass Leerzeichen, Bindestriche und ein führendes + automatisch entfernt werden — plus Ihre vorausgefüllte Nachricht, wenn Sie eine hinzufügen, angehängt als Eröffnungstext. Beim Scannen öffnet WhatsApp einen Chat mit Ihnen und der bereits eingetippten Nachricht; der Besucher drückt nur auf Senden. Er muss Ihre Nummer niemals zuerst speichern.

Eine Hausbäckerei gibt ihre Bestellnummer, 923001234567, mit der Nachricht “Hello, I want to order a cake” ein und druckt den Code auf ihre Preiskarten und Lieferboxen. Eine Kundin scannt ihn, WhatsApp öffnet sich mit dem fertigen Satz, sie fügt Geschmack und Datum hinzu, und das Bestellgespräch hat in unter zehn Sekunden begonnen.

Häufig gestellte Fragen

Warum muss die Nummer die Landesvorwahl enthalten?

Der wa.me-Link funktioniert nur mit einer vollständigen internationalen Nummer, weil WhatsApp wissen muss, zu welchem Land das Konto gehört. Für Pakistan bedeutet das, mit 92 zu beginnen und die erste 0 der lokalen Nummer wegzulassen — zum Beispiel wird 0300 1234567 zu 923001234567.

Wird die vorausgefüllte Nachricht automatisch gesendet?

Nein. Er erscheint im Tippfeld des Besuchers, bereit für ihn zum Bearbeiten oder Senden. Nichts wird jemals gesendet, ohne dass die Person auf Senden drückt, und sie kann Details hinzufügen — wie einen Produktnamen oder eine Lieferadresse —, bevor sie sendet.

Was, wenn die scannende Person WhatsApp nicht installiert hat?

Der wa.me-Link öffnet sich in ihrem Browser und bietet an, zu WhatsApp weiterzugehen — auf einem Computer öffnet er WhatsApp Web oder die Desktop-App. Um tatsächlich zu chatten, brauchen sie ein WhatsApp-Konto, aber sie brauchen Ihre Nummer niemals in ihren Kontakten gespeichert.

Kann ich verschiedene Codes für verschiedene Produkte erstellen?

Ja, und es ist ein cleverer Trick: Erzeugen Sie einen Code pro Produkt mit einer anderen vorausgefüllten Nachricht wie “I want the chocolate cake” oder “I want the dinner deal”. Jeder gedruckte Code startet dann den Chat und teilt Ihnen bereits mit, was der Kunde möchte.

Ich habe eine neue WhatsApp-Nummer. Kann ich meine gedruckten Codes weiter verwenden?

Nein. Die Nummer ist im Link, den der Code enthält, sodass Codes, die für die alte Nummer gedruckt wurden, weiter versuchen werden, Chats zu ihr zu öffnen. Erzeugen Sie neue Codes für die neue Nummer und ersetzen Sie die Drucke, die Sie erreichen können.
