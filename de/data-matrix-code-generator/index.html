Über diese Data Matrix

Data Matrix (ISO/IEC 16022, ECC 200) ist der 2D-Code von Industrie und Gesundheitswesen: Er speichert echte Daten auf einem fingernagelgroßen Quadrat — wenige Millimeter breit — und liest sich noch mit bis zu etwa 25 % beschädigtem Symbol, dank Reed–Solomon-Fehlerkorrektur. GS1 DataMatrix ist der vorgeschriebene Code auf Arzneimitteln und Medizinprodukten in der gesamten EU und den USA (UDI), und Elektronikhersteller lasern ihn direkt auf Teile.

Anders als QR hat er keine dekorativen Suchquadrate in den Ecken — ein L-förmiger massiver Rand plus eine Taktspur aus abwechselnden Modulen sagen dem Scanner, wo die Daten leben.

Beste Verwendungen

  • Arzneimittel- und Medizinprodukte-Packungen (GS1/UDI)
  • Lasergravierte Elektronik und Motorteile
  • Verfolgung von Luft- und Raumfahrtkomponenten
  • Kleine Etiketten, wo QR nicht passt

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

So funktioniert es

Die Codierung läuft auf der mitgelieferten bwip-js-Bibliothek (dem Browser-Port von BWIPP, dem Encoder, dem Etikettensoftware vertraut) und erzeugt echte ECC 200-Symbole — keinen QR-Code mit anderer Haut. Die Kapazität reicht von wenigen Zeichen in einem 10×10-Symbol bis zu ~2,335 alphanumerischen Zeichen bei 144×144.

Ausgearbeitetes Beispiel

Ein Leiterplattenhersteller ätzt jede Platine mit einer Data Matrix, die Rückverfolgbarkeitsdaten im Stil LOT-8841;EXP-2027-05 auf 5 mm enthält. Zehn Jahre später scannt ein Techniker die Platine, und der vollständige Produktionsdatensatz öffnet sich.

Häufig gestellte Fragen

Ist dieser Data Matrix-Generator kostenlos?

Ja. Loonas Data Matrix-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Data Matrix-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Data Matrix oder QR-Code — welcher?

Data Matrix, wenn die Größe winzig ist, die Oberfläche ein Teil oder eine Packung ist oder eine Branchenregel (Pharma-UDI, GS1-Gesundheitswesen) ihn benennt. QR-Code, wenn die breite Öffentlichkeit ihn scannen muss — jede Telefonkamera liest QR nativ, während Data Matrix oft eine richtige Scanner-App braucht.

Können Telefonkameras Data Matrix scannen?

Viele neuere Telefone und die meisten dedizierten Scanner-Apps können es; einige Standard-Kamera-Apps können es nicht. Bevorzugen Sie für verbraucherorientierte Verwendungen QR-Codes.
