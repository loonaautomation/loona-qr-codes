Über diesen Speisekarten-QR-Code für Restaurants

Ein Speisekarten-QR-Code ermöglicht Gästen, Ihre vollständige Speisekarte auf ihrem eigenen Telefon zu öffnen: hygienisch, immer aktuell und kostenlos zu ändern, wann immer sich Preise ändern.

Ein Café aktualisiert die Preise auf seiner Speisekartenseite einmal; jeder Tisch-QR-Code zeigt sofort die neue Speisekarte, ganz ohne Nachdruck. Das ist das eigentliche Problem, das ein Speisekarten-QR-Code für Restaurants löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines Speisekarten-QR-Codes für Restaurants

  • Restaurants, Cafés und Food Trucks
  • Tischaufsteller und Fensteraufkleber
  • Takeaway- und Lieferspeisekarten
  • Hotel-Zimmerservice-Speisekarten

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Sie können Loona-QR-Codes frei für kommerzielle Arbeit verwenden — Speisekarten, Visitenkarten, Kundenprojekte, Verpackungen und Beschilderungen — ohne erforderliche Namensnennung. Weil die Erzeugung privat und offline-fähig ist, sobald die Seite geladen hat, verlassen sensible Details wie WLAN-Passwörter und Zahlungsnummern niemals Ihr Gerät. Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

Häufig gestellte Fragen

Ist eine Webseiten-Speisekarte oder eine PDF-Speisekarte besser?

Eine Webseite lädt normalerweise schneller, liest sich auf kleinen Telefonbildschirmen besser und lässt sich leichter bearbeiten. Eine PDF funktioniert gut, wenn das das ist, was Sie haben — halten Sie die Datei nur klein, damit sie schnell öffnet, und behalten Sie sie beim Aktualisieren unter demselben Link.

Brauchen Gäste eine App oder Internet, um die Speisekarte zu sehen?

Sie brauchen eine Telefonkamera — inzwischen in fast alle Telefone eingebaut — und eine Internetverbindung, um die Seite zu laden. Keine spezielle App, kein Konto oder keine Anmeldung ist beteiligt.

Ein Code für jeden Tisch oder ein anderer Code pro Tisch?

Ein Code genügt: Derselbe Link kann auf jeden Tischaufsteller, das Fenster und Takeaway-Tüten gedruckt werden. Codes pro Tisch werden nur von Bestellsystemen benötigt, die einzelne Tische verfolgen, was ein einfacher Speisekarten-Link nicht tut.

Wie groß soll der Tisch-Code gedruckt werden?

Etwa 3–4 cm breit, mit einem klaren weißen Rand und einer kurzen Zeile wie “Scan for the menu”. Die Tischentfernung ist kurz, sodass eine bescheidene Größe sofort scannt — und testen Sie sie mit Ihrem eigenen Telefon unter der Beleuchtung Ihres Restaurants, bevor Sie den vollständigen Satz drucken.

Was ist mit Gästen ohne Smartphones?

Behalten Sie einige gedruckte Speisekarten an der Theke als Backup. Viele Restaurants führen beides: QR-Codes auf den Tischen für Geschwindigkeit und Papierkopien für jeden, der sie bevorzugt.

Kann ich stattdessen auf eine Liefer- oder Bestellseite verlinken?

Ja — das Formular akzeptiert jeden speisekartenähnlichen Link, also funktioniert auch eine Seite, die Ihre Speisekarte mit Online-Bestellung kombiniert. Stellen Sie nur sicher, dass die Seite sich auf einem Telefon gut öffnet.
