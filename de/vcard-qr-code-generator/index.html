Über diesen vCard-Kontakt-QR-Code

Ein vCard-QR-Code trägt Ihren Namen, Ihr Telefon, Ihre E-Mail, Ihr Unternehmen und Ihre Adresse im universellen vCard-Format, sodass das Scannen Sie mit einem Tipp als Kontakt speichert.

Ein Freelancer gibt einen vCard-QR-Code statt einer Papierkarte; der Kunde scannt, und seine Nummer ist für immer gespeichert. Das ist das eigentliche Problem, das ein vCard-Kontakt-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines vCard-Kontakt-QR-Codes

  • Visitenkarten und Besuchskarten
  • E-Mail-Signaturen und Angebote
  • Event-Namensschilder und Konferenzen
  • Ladentheken, damit Kunden Ihre Nummer speichern

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Sie können Loona-QR-Codes frei für kommerzielle Arbeit verwenden — Speisekarten, Visitenkarten, Kundenprojekte, Verpackungen und Beschilderungen — ohne erforderliche Namensnennung. Weil die Erzeugung privat und offline-fähig ist, sobald die Seite geladen hat, verlassen sensible Details wie WLAN-Passwörter und Zahlungsnummern niemals Ihr Gerät. Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

So funktioniert es

Der Code speichert eine vollständige digitale Kontaktkarte im Standard-vCard-Format (VCF 3.0): zuerst Ihren vollständigen Namen, dann die optionalen Felder, die Sie ausfüllen — Unternehmen, Berufsbezeichnung, Mobilnummer, E-Mail, Website und Adresse. Leere Felder werden einfach weggelassen. Wenn ein Telefon ihn scannt, bietet die Kontakte-App an, die Karte als neuen Kontakt zu speichern, mit allem bereits ausgefüllt, sodass niemand einen einzigen Buchstaben tippen muss.

Ausgearbeitetes Beispiel

Ein Immobilienmakler füllt jedes Feld aus — Name, Agentur, Titel “Senior Property Consultant”, Mobiltelefon, E-Mail, Website und Büroadresse — und druckt den Code auf seine Visitenkarten und Verkaufsschilder. Eine Kundin scannt ihn bei einer Besichtigung, tippt auf Speichern und hat den vollständigen Kontakt des Maklers, korrekt geschrieben, in ihrem Telefon, bevor sie wegfährt.

Häufig gestellte Fragen

Welche Felder sind erforderlich und welche optional?

Nur der vollständige Name ist erforderlich. Unternehmen, Berufsbezeichnung, Telefon, E-Mail, Website und Adresse sind alle optional — lassen Sie eines davon leer, und diese Zeile erscheint einfach nicht im gespeicherten Kontakt.

Speichert jedes Telefon den Kontakt auf dieselbe Weise?

Ehrlich gesagt, es variiert. Die meisten modernen Android-Telefone und iPhones zeigen eine Aufforderung “add contact” mit ausgefüllten Feldern. Einige ältere Telefone oder Scanner-Apps von Drittanbietern zeigen die Karte stattdessen als Klartext an, aus dem die Details immer noch kopiert werden können. Testen Sie Ihren gedruckten Code auf zwei oder drei verschiedenen Telefonen, wenn es darauf ankommt.

Kann ich eine zweite Telefonnummer oder mein WhatsApp separat hinzufügen?

Dieses Formular hat ein einziges Telefonfeld, das als Mobilnummer gespeichert wird. Wenn WhatsApp wichtiger ist, setzen Sie diese Nummer hier ein; verwenden Sie für einen Code, der einen WhatsApp-Chat direkt öffnet, stattdessen den WhatsApp-QR-Code-Generator.

Meine Adresse ist lang. Passt sie noch?

Ja — die Adresse wird als eine Textzeile in der Karte gespeichert. Sehr lange Details jeder Art machen das Muster dichter, drucken Sie den Code also mit 3 cm oder größer und scannen Sie den Druck zum Testen, wenn Sie jedes Feld ausfüllen.

Kann ich mein Foto oder Firmenlogo in den Kontakt einfügen?

Nein. Das hier verwendete vCard-QR-Format trägt nur Textdetails, was den Code klein und schnell zu scannen hält. Ihr Foto erscheint in ihren Kontakten nur, wenn ihr Telefon es von anderswo abruft, zum Beispiel aus Ihrem E-Mail- oder Nachrichtenprofil.
