Kostenloser QR-Code-mit-Logo-Generator

Setzen Sie Ihr Logo in die Mitte eines QR-Codes — gerendert auf der höchsten Fehlerkorrekturstufe, damit er noch scannt, mit Live-Vorschau und PNG-Download in voller Größe.

Ihr QR-Code

Logo-Codes verwenden die höchste Fehlerkorrekturstufe (H — etwa 30 % des Musters können abgedeckt oder beschädigt sein). Scannen Sie vor dem Drucken immer zum Testen.

So erstellen Sie einen in 3 Schritten

  1. Geben Sie Ihre Details ein im Formular oben — nur die Felder für diesen Typ, nichts extra.
  2. Überprüfen Sie die Live-Vorschau und passen Sie die Farbe, den Hintergrund und die Größe (256, 512 oder 1024 px) an Ihre Marke oder Ihren Druck an.
  3. Klicken Sie auf PNG herunterladen, scannen Sie den Code einmal mit Ihrem Telefon zum Testen und drucken Sie ihn dann aus oder teilen Sie ihn dort, wo sich Ihre Zielgruppe befindet.

Über diesen QR-Code mit Logo

Ein Logo in der Mitte ist die eine Anpassung, die Unternehmen von einem QR-Code tatsächlich wollen — und diejenige, die ihn bei unvorsichtiger Ausführung am ehesten bricht. Es funktioniert, weil QR-Codes mit Reservekapazität gebaut sind: Bei Fehlerkorrekturstufe H können grob 30 % des Musters fehlen oder abgedeckt sein, und der Code liest sich trotzdem. Das Logo verbraucht einen Teil dieses Budgets — weshalb Größendisziplin und Testscans nicht verhandelbar sind.

Dieser Generator komponiert alles auf einer 1024-px-Leinwand in Ihrem Browser: den Code auf Stufe H, eine weiße gepolsterte Platte hinter Ihrem Logo (Logos, die direkt auf dem Muster platziert sind, scannen merklich schlechter) und Ihr Logo in der Mitte in der Größe, die Sie wählen. Nichts wird hochgeladen; Ihr Logo verlässt Ihr Gerät niemals.

Beste Verwendungen

  • Gebrandete Speisekarten und Verpackungen
  • Visitenkarten und Beschilderung
  • Event- und Konferenzmaterial
  • Produktetiketten und Aufkleber

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

So funktioniert es

Beginnen Sie konservativ: Die „kleine“ Logo-Einstellung (18 %) scannt fast überall. Mittel (22 %) eignet sich für einfache, fette Logos. Groß (26 %) verbraucht den größten Teil des sicheren Budgets — verwenden Sie es nur, nachdem Sie das Ergebnis mit mehreren Telefonen gescannt haben, einschließlich eines älteren Android-Geräts, in dem Licht, in dem es leben wird. Halten Sie den eigenen Kontrast des Logos stark und lassen Sie es niemals die drei Eckquadrate des Musters abdecken.

Ausgearbeitetes Beispiel

Ein Café fügt sein rundes Abzeichen-Logo in der mittleren Einstellung zu seinem Speisekarten-Code hinzu. Das Abzeichen sitzt auf seiner weißen Platte, der Code scannt auf jedem Telefon am Tisch, und die Speisekarte wirkt endlich wie ein Teil der Marke statt wie ein Stempel.

Häufig gestellte Fragen

Ist dieser QR-Code-mit-Logo-Generator kostenlos?

Ja. Loonas QR-Code mit Logo-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser QR-Code-mit-Logo-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Warum braucht das Logo eine weiße Platte dahinter?

Die Platte garantiert Kontrast zwischen dem Logo und den Mustermodulen und hält die Module unter dem Logobereich gleichmäßig abgedeckt, was Scanner weitaus besser handhaben als eine unruhige Logokante direkt auf dem Muster.

Mein Logo-Code hörte bei der großen Größe auf zu scannen. Was nun?

Lassen Sie eine Größe fallen, vereinfachen Sie das Logo (eine Abzeichen- oder Symbolversion scannt besser als ein detailliertes Lockup) und testen Sie erneut. Wenn es immer noch fehlschlägt, ist der Inhalt des Codes zu dicht — kürzen Sie zuerst den Link.
