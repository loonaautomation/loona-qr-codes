Über diesen Code 39

Code 39 (USS Code 39, Code 3 of 9) ist der älteste alphanumerische Barcode, der noch täglich verwendet wird — entwickelt 1974 und am Leben erhalten durch Automobil-, Verteidigungs-, Gesundheits- und Regierungsetiketten, die ihn vor Jahrzehnten festgelegt haben. Jedes Zeichen ist neun Elemente breit (fünf Balken, vier Lücken, drei davon breit), was ihn tolerant gegenüber schlechtem Druck macht, aber lang für die Daten, die er trägt.

Sein Alphabet ist klein: Großbuchstaben A–Z, Ziffern und einige Symbole. Er ist selbstprüfend (ein einzelnes falsches Zeichen validiert selten), und eine optionale Modulo-43-Prüfziffer kann hinzugefügt werden, wo das empfangende System eine erwartet.

Beste Verwendungen

  • Legacy-Etiketten für Automobil und Verteidigung
  • Namensschilder und Ausweise
  • Bibliotheksbücher (ältere Systeme)
  • Industriebehälter und Werkzeugausgaben

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

So funktioniert es

Der Generator wandelt Ihren Text automatisch in Großbuchstaben um und lehnt Zeichen außerhalb des Code 39-Alphabets ab, wobei er die Regel benennt, statt den Encoder still scheitern zu lassen. Ein Sternchen ist das Start-/Stopp-Zeichen und wird vom Encoder hinzugefügt — geben Sie es niemals selbst ein.

Häufig gestellte Fragen

Ist dieser Code 39-Generator kostenlos?

Ja. Loonas Code 39-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Code 39-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Warum hat sich mein Kleinbuchstaben-Text geändert?

Code 39 hat in seinem Standard-Alphabet keine Kleinbuchstaben, daher wandeln Encoder in Großbuchstaben um. Wenn die Groß-/Kleinschreibung wichtig ist, verwenden Sie stattdessen Code 128.

Braucht Code 39 eine Prüfziffer?

Nein — er ist von Natur aus selbstprüfend. Eine Modulo-43-Prüfziffer existiert für Systeme, die danach fragen, aber die meisten Code 39-Etiketten werden ohne eine gedruckt.
