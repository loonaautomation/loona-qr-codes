Über diesen PDF-QR-Code

Ein PDF-QR-Code verweist auf eine online gehostete PDF-Datei, sodass ein Scan ein Dokument liefert, dessen Druck für alle kostspielig oder unmöglich wäre.

Ein Elektronikgeschäft platziert einen PDF-QR-Code auf der Schachtel; das vollständige Handbuch öffnet sich auf dem Telefon des Kunden. Das ist das eigentliche Problem, das ein PDF-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines PDF-QR-Codes

  • Broschüren, Kataloge und Preislisten
  • Lebensläufe, Zertifikate und Berichte
  • Lernmaterial und E-Books
  • Handbücher und Garantiedokumente

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Sie können Loona-QR-Codes frei für kommerzielle Arbeit verwenden — Speisekarten, Visitenkarten, Kundenprojekte, Verpackungen und Beschilderungen — ohne erforderliche Namensnennung. Weil die Erzeugung privat und offline-fähig ist, sobald die Seite geladen hat, verlassen sensible Details wie WLAN-Passwörter und Zahlungsnummern niemals Ihr Gerät. Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

Ist dieser PDF-QR-Code-Generator kostenlos?

Ja. Loonas PDF-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein PDF-QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst (zum Beispiel Ihre Website oder Nummer) aktiv bleibt.

Wie verwende ich den PDF-QR-Code, den ich erzeugt habe?

Füllen Sie das Formular aus, überprüfen Sie die Live-Vorschau, wählen Sie Ihre Farben und Größe und klicken Sie dann auf PNG herunterladen. Drucken Sie ihn aus oder teilen Sie ihn digital, und scannen Sie ihn immer einmal mit Ihrem eigenen Telefon zum Testen, bevor Sie in großer Menge drucken.

Sind meine Informationen auf dieser PDF-QR-Code-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben — Passwörter, Nummern oder Links — wird an einen Server gesendet oder auf einem gespeichert.

So funktioniert es

Ein PDF-QR-Code enthält nicht — und kann nicht enthalten — die PDF-Datei selbst: Ein QR-Muster speichert eine kleine Menge Text, kein Dokument. Was dieser Generator codiert, ist der Link zu einer PDF-Datei, die Sie bereits online gestellt haben, auf Ihrer eigenen Website, bei Google Drive, Dropbox oder einem beliebigen öffentlichen Datei-Host. Sie fügen diesen Link ein, und beim Scannen öffnet sich die Adresse: Der Browser oder PDF-Viewer des Telefons lädt das Dokument, das der Leser ansehen, speichern oder teilen kann. Alles hängt davon ab, dass dieser Link aktiv und öffentlich erreichbar bleibt.

Ausgearbeitetes Beispiel

Ein Elektronikgeschäft verkauft einen Deckenventilator mit einem 40-seitigen Installationshandbuch. Sie laden die Handbuch-PDF auf ihre eigene Website hoch — https://brightappliances.com/manuals/aurora-fan-manual.pdf — und drucken einen aus diesem Link erstellten QR-Code auf die Schachtel: “Scan for the full manual”. Der Kunde scannt ihn zu Hause, die PDF öffnet sich auf seinem Telefon, und das Geschäft druckt überhaupt keine Papierhandbücher.

Häufig gestellte Fragen

Wie stelle ich meine PDF online, um einen Link zu erhalten?

Laden Sie es auf Ihre eigene Website hoch, wenn Sie eine haben, oder auf ein Cloud-Laufwerk wie Google Drive oder Dropbox und kopieren Sie dann den Freigabelink. Stellen Sie bei Drive die Freigabe der Datei auf “Anyone with the link” ein — eine private Datei zeigt Scannern eine Seite zur Zugriffsanfrage statt des Dokuments.

Was passiert, wenn ich die PDF aktualisiere?

Wenn Sie die Datei unter genau demselben Link ersetzen, liefert jeder gedruckte Code automatisch die neue Version — ideal für Preislisten und Kataloge. Wenn sich der Link selbst ändert, zeigt der alte Code auf die alte Adresse, und Sie müssen nachdrucken.

Warum öffnet sich die PDF für einige Menschen langsam?

Der Code öffnet, was auch immer sich am Link befindet, sodass eine sehr große PDF auf mobilen Daten langsam lädt. Komprimieren Sie große Dateien vor dem Hochladen — Bilder sind normalerweise der schwere Teil —, damit das Dokument innerhalb weniger Sekunden öffnet.

Öffnet sich die PDF auf dem Bildschirm oder wird sie heruntergeladen?

Das hängt vom Telefon und Browser ab: Die meisten öffnen das Dokument in einem Viewer mit Optionen zum Speichern oder Teilen, während einige es sofort herunterladen. In jedem Fall erhält der Leser die Datei von Ihrem Link.

Kann ich zählen, wie viele Personen meinen PDF-Code gescannt haben?

Der statische Code selbst meldet nichts. Wenn die PDF auf Ihrer eigenen Website gehostet wird, können Ihre Website-Statistiken Besuche dieses Links zeigen — und die Verwendung eines Links, der nur auf dem QR-Code erscheint, gibt Ihnen eine grobe Scan-Zählung.

Gibt es eine Seiten- oder Größenbegrenzung für die PDF?

Nicht von der QR-Seite — der Code enthält nur den Link. Etwaige Limits gehören zu Ihrem Hosting, halten Sie die Datei also so klein, wie sie lesbar bleibt, und testen Sie den Link auf einem Telefon vor dem Drucken.
