Über diesen Telefonanruf-QR-Code

Ein Telefon-QR-Code verwendet einen tel-Link, sodass das Scannen Ihre Nummer mit einem einzigen Tipp anrufbereit anzeigt.

Ein Klempner platziert einen Telefon-QR-Code auf seinem Transporter; jeder, der ihn sieht, kann ihn anrufen, ohne die Nummer zu notieren. Das ist das eigentliche Problem, das ein Telefonanruf-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

Beste Verwendungen eines Telefonanruf-QR-Codes

  • Fahrzeuge und Lieferfahrer
  • Geschäftsschilder und Rollläden
  • Notfall- und Hilferuf-Hinweise
  • Immobilien- und Verkaufsschilder

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Sie können Loona-QR-Codes frei für kommerzielle Arbeit verwenden — Speisekarten, Visitenkarten, Kundenprojekte, Verpackungen und Beschilderungen — ohne erforderliche Namensnennung. Weil die Erzeugung privat und offline-fähig ist, sobald die Seite geladen hat, verlassen sensible Details wie WLAN-Passwörter und Zahlungsnummern niemals Ihr Gerät. Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

So funktioniert es

Sie geben eine Telefonnummer ein, und der Generator codiert sie als tel:-Link — tel: gefolgt von Ihrer Nummer, mit entfernten Leerzeichen. Wenn jemand den Code scannt, erkennt sein Telefon den Anruflink und zeigt die Nummer mit einer Anruf-Option an; ein weiterer Fingertipp und das Telefon wählt. Aus Sicherheitsgründen wählen Telefone niemals automatisch aus einem QR-Code: Die Person sieht immer zuerst die Nummer und bestätigt den Anruf selbst.

Ausgearbeitetes Beispiel

Ein Klempner lässt seinen Transporter mit einem großen QR-Code und den Worten “Scan to call” beschriften. Er gibt seine Nummer im vollständigen internationalen Format ein, +92 300 1234567, und druckt den Code auf beide Seiten des Transporters. Ein Hausbesitzer mit einem Rohrbruch scannt ihn von der anderen Straßenseite, tippt bei der Aufforderung auf Anrufen und spricht innerhalb von Sekunden mit ihm — statt hinüberzugehen, um elf Ziffern zu lesen und sie von Hand einzutippen.

Häufig gestellte Fragen

Soll ich meine Landesvorwahl einfügen?

Ja — geben Sie das vollständige internationale Format ein, wie +92 für Pakistan oder +1 für die USA. Die Nummer funktioniert dann für Scanner aus jedem Land, und Telefone können sie korrekt wählen oder speichern, ohne zu raten.

Ruft das Scannen die Nummer sofort an?

Nein. Das Scannen zeigt die Nummer und eine Anrufaufforderung, und die Person tippt zum Wählen. Telefone sind so konzipiert, dass ein QR-Code niemals ohne die Handlung des Besitzers einen Anruf tätigen kann.

Braucht der Scanner Internet oder eine spezielle App?

Kein Internet nötig — die Nummer ist im Muster selbst, und jede Kamera-App, die QR-Codes liest, kann den Anruf anbieten. Der Anrufer braucht nur gewöhnliches Telefonsignal, um ihn zu tätigen.

Kann ich eine Festnetz- oder eine Hilferufnummer verwenden?

Ja — jede wählbare Nummer funktioniert, einschließlich Festnetz, gebührenfreier Nummern und Hilferufe. Der Code präsentiert die Nummer einfach anrufbereit.

Was, wenn ich meine Nummer später ändere?

Der gedruckte Code behält die alte Nummer, erzeugen Sie also einen neuen Code und ersetzen Sie die Drucke. Für teure Beschilderung und Fahrzeugbeschriftung lohnt es sich, eine Nummer zu verwenden, die Sie lange behalten wollen.

Können Personen meine Nummer aus dem Code speichern, statt anzurufen?

Viele Telefone bieten nach dem Scannen eines tel:-Codes eine Option “add to contacts” neben der Anrufaufforderung an — und die Nummer ist mindestens auf dem Bildschirm, um sie zu kopieren oder aufzuschreiben.
