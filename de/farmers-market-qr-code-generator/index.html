Über diesen Bauernmarktstand

An einem Marktstand sind Sie Kassierer, Koch und Vertriebsteam. QR-Codes übernehmen leise die sich wiederholenden Aufgaben: ein Preislisten-Code an der Standfront für Stöbernde, ein Vorbestell-Code auf der Tüte, damit der Käufer dieser Woche zum Stammkunden der nächsten Woche wird, und ein Story-Code auf dem Banner für die Menschen, die Herkunft ebenso kaufen wie Produkte.

Machen Sie alles wetterfest — laminierte Karten, kein Papier — und halten Sie Codes groß; Marktlicht ist hell, und Käufer scannen auf Armlänge mit einer Tasche in der anderen Hand.

Beste Verwendungen

  • Preisliste an der Standfront
  • Vorbestell-Link auf Tüten und Boxen
  • Farm-Story- und Herkunftsseite
  • Zahlungslink für kartenfreie Stände

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Häufig gestellte Fragen

Ist dieser Bauernmarktstand-Generator kostenlos?

Ja. Loonas Bauernmarkt-Stand-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Bauernmarktstand-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Was, wenn mein Stand keine Website hat?

Verlinken Sie auf eine kostenlose Seite, die Sie kontrollieren — ein veröffentlichtes Google Doc, eine einfache Website oder Ihren Social Shop. Der Code braucht nur eine stabile URL.

Zahlungen per QR-Code an einem Stand?

Verlinken Sie die Zahlungsseite, die Ihr Anbieter Ihnen gibt, oder verwenden Sie die UPI-/PayPal-Generatoren auf dieser Website für einen dedizierten Zahlungs-Code.
