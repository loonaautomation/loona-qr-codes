    Über diesen QR-Code- und Barcode-Scanner
    

    Die meisten QR-Sites nur erstellen Codes. Diese Seite tut die entgegengesetzte Aufgabe: Sie liest sie. Das ist, was Sie brauchen, wenn ein gedruckter Code keine lesbare Bezeichnung hat, wenn ein Kollege Ihnen einen Screenshot eines Codes statt des Links darin sendet, wenn Sie überprüfen wollen, was einer Ihrer eigenen gedruckten Codes tatsächlich enthält, vor einem großen Drucklauf, oder wenn eine Produkt-Barcode-Nummer von einem Foto abgelesen werden muss.
    

    Er funktioniert auf zwei Arten. Der Kameramodus verwendet die BarcodeDetector-Schnittstelle, die in moderne Chromium-Browser eingebaut ist — dieselbe schnelle, hardwarefreundliche Erkennung, die das System Ihres Telefons verwendet — und meldet QR-Codes und die gängigen eindimensionalen Barcodes. Der Bildmodus ist vollständig eigenständig: Die Open-Source-Bibliothek jsQR decodiert QR-Codes aus den Pixeln Ihres Bildes, und die Open-Source-Bibliothek ZXing decodiert Barcodes (und jeden QR-Code, den jsQR übersehen hat) aus denselben Pixeln. Beide laufen vollständig in Ihrem Browser, weshalb dieser Scanner mit sensiblen Codes weiter funktioniert — WLAN-Passwörter, Zahlungscodes, private Links —, die Sie niemals auf den Server eines Fremden hochladen wollen würden.
    

    Beste Verwendungen dieses Scanners
    • Überprüfung Ihrer eigenen gedruckten QR-Codes vor dem Drucken in Menge
    • Öffnen des Links, der in einem QR-Code in einem Screenshot oder Foto versteckt ist, den Ihnen jemand gesendet hat
    • Wiederherstellen eines WLAN-Netzwerknamens und Passworts aus einem WLAN-QR-Code-Bild
    • Speichern eines vCard-Kontakts aus einem Visitenkarten-QR-Code als .vcf-Datei
    • Lesen von EAN-13-, UPC-A-, Code 128- und Code 39-Barcode-Nummern aus Produkt- und Etikettenfotos
    • Überprüfen, ob ein Barcode, den Sie erzeugt haben, exakt zu der Zahl zurückscannt, die Sie beabsichtigt haben
    • Stapelprüfung eines ganzen gedruckten Blatts oder Ordners mit Codefotos, mit CSV-Export jedes Ergebnisses
    • Sehen der Koordinaten hinter einem geo:-Standort-Code oder der Adresse hinter einem Bitcoin- oder Ethereum-Zahlungs-Code, bevor Sie darauf handeln
    

    Ehrliche Grenzen, damit Sie nicht überrascht werden: Das Kamera-Scannen hängt von einer Browserfunktion ab, die Safari und Firefox noch nicht ausgeliefert haben, daher ist in diesen Browsern nur der Bildmodus verfügbar — die Seite erkennt dies und teilt es Ihnen klar mit, statt still zu scheitern. Und kein Decoder kann einen Code lesen, der im Foto zu klein, verwackelt, zerrissen oder mit zu wenig Kontrast gedruckt ist; das erneute Aufnehmen des Fotos näher, frontal und bei gutem Licht behebt die meisten fehlgeschlagenen Scans.
    

    Häufig gestellte Fragen
    Ist dieser QR-Code- und Barcode-Scanner kostenlos?
    Ja. Loonas Scanner ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie scannen, für den persönlichen oder kommerziellen Gebrauch.
    Ist mein Kameravideo oder mein Foto auf dieser Scanner-Seite privat?
    Ja. Alles wird auf Ihrem eigenen Gerät decodiert, in Ihrem Browser. Kamera-Bilder werden niemals irgendwohin gesendet, und hochgeladene Bilder werden niemals an einen Server gesendet — die Datei wird lokal gelesen, lokal decodiert, und Ihr Scan-Verlauf wird nur im Speicher dieser Seite gehalten und verschwindet, wenn Sie den Tab schließen.
    Warum funktioniert das Kamera-Scannen in meinem Browser nicht?
    Das Live-Kamera-Scannen verwendet die BarcodeDetector-Technologie, die in Chrome, Edge und die meisten Android-Browser eingebaut ist. Safari und Firefox enthalten sie noch nicht, daher wird in diesen Browsern die Kamera-Schaltfläche durch eine Nachricht ersetzt, die Sie bittet, stattdessen den Bildupload zu verwenden — das Hochladen eines Fotos oder Screenshots funktioniert in jedem modernen Browser.
    Kann dieser Scanner einen Barcode aus einem Foto lesen?
    Ja. Der Upload-Modus decodiert QR-Codes aus Bildern mit der jsQR-Bibliothek und Barcodes aus Bildern mit der ZXing-Bibliothek — einschließlich EAN-13, UPC-A, Code 128 und Code 39 — sowie QR-Codes, die ZXing findet und jsQR verpasst hat. Sehr kleine, unscharfe, beschädigte oder kontrastarme Codes in einem Foto können immer noch scheitern; ein schärferes, näheres Foto behebt es normalerweise.
    Welche Arten von Codes kann dieser Scanner lesen?
    Kamera-Scannen (wo unterstützt) liest QR-Codes plus die Barcode-Formate, die der BarcodeDetector Ihres Browsers bietet, üblicherweise EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar und ITF. Bildupload liest QR-Codes und EAN-13-, UPC-A-, Code 128- und Code 39-Barcodes und zeigt Ihnen den decodierten Typ, den Rohinhalt und intelligente Aktionen wie das Öffnen eines Links oder das Speichern eines Kontakts.

    So funktioniert es
    

    Ein QR-Code oder Barcode ist lediglich ein Muster, das Text als helle und dunkle Module codiert. Die Decodierung ist die Umkehrung der Erzeugung: das Muster im Bild finden, die Module messen, Fehler mithilfe der im Code eingebauten Redundanz korrigieren und die Bits wieder in Zeichen umwandeln. jsQR tut dies für QR-Codes, indem es die drei Suchquadrate lokalisiert und das Raster abtastet; ZXing tut dies für Barcodes, indem es Pixelzeilen über die Balken scannt und die Breiten mit den Regeln für EAN, UPC, Code 128 oder Code 39 abgleicht, einschließlich der Überprüfung der letzten Prüfziffer von Handelsbarcodes. Im Kameramodus übernimmt der eigene BarcodeDetector Ihres Browsers diese Aufgabe kontinuierlich an den Live-Videobildern, bis ein Code gefunden wird. Im Stapelmodus laufen dieselben beiden Bilddecoder einmal pro Datei, und jedes Ergebnis — Dateiname, Format, Typ und decodierter Text — wird in einer Tabelle gesammelt, die Sie als CSV exportieren können.
    

    Die Methode: wählen Sie Kamera oder Bild → lassen Sie den Decoder auf dem Gerät das Muster lesen → überprüfen Sie Typ, Format und Rohinhalt → verwenden Sie die intelligente Aktion (öffnen, kopieren, Kontakt speichern) → finden Sie den Scan jederzeit in der Sitzungs-Historie wieder.

    Häufig gestellte Fragen
    

    Kann ich einen Code aus einem Screenshot auf demselben Telefon scannen?
    

    Ja. Speichern oder teilen Sie den Screenshot in Ihre Foto-App und verwenden Sie dann den Bild-Upload hier und wählen Sie diesen Screenshot. Kopieren Sie auf einem Computer einfach das Bild und fügen Sie es mit Ctrl+V (oder Cmd+V auf einem Mac) in diese Seite ein — kein Dateispeichern nötig.
    

    Das Ergebnis sieht aus wie WIFI:T:WPA;S:… — was bedeutet das?
    

    Das ist das Standard-Rohformat in einem WLAN-QR-Code: T ist der Sicherheitstyp, S ist der Netzwerkname (SSID) und P ist das Passwort. Diese Seite zeigt diese drei Werte auch separat über dem Rohinhalt an, sodass Sie sie nicht selbst heraussuchen müssen.
    

    Wie füge ich einen gescannten Kontakt zu meinem Telefon hinzu?
    

    Wenn ein Scan eine vCard ist, erscheint eine Aktion „Kontakt herunterladen (.vcf)“. Laden Sie die Datei herunter und öffnen Sie sie — Telefone und Computer bieten an, sie als Kontakt zu speichern, mit Name, Organisation, Telefon, E-Mail und Website bereits ausgefüllt.
    

    Warum wurde mein Foto nicht decodiert?
    

    Die üblichen Ursachen sind ein Code, der in einem großen Foto winzig ist, Unschärfe, Blendung, ein zerrissener oder kontrastarmer Druck oder ein Screenshot, der zu eng um den Code beschnitten ist (Decoder brauchen die weiße Ruhezone um einen Code). Schneiden Sie großzügig zu, nehmen Sie das Foto näher und frontal erneut auf und versuchen Sie es erneut.
    

    Soll ich einem QR-Code vertrauen, den ich öffentlich gefunden habe?
    

    Scannen Sie ihn zuerst hier statt mit einer App, die Ergebnisse automatisch öffnet: Diese Seite nur zeigt Ihnen den decodierten Inhalt und öffnet niemals etwas von selbst. Überprüfen Sie, ob ein Link wirklich dorthin führt, wo seine Bezeichnung verspricht, bevor Sie auf „Open link“ tippen — diese eine Gewohnheit besiegt die meisten Aufkleber-über-einem-echten-Code-Betrügereien.
