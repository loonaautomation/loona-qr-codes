Über dieses Haustier-ID-Etikett

Gravierte Anhänger passen zu einem Namen und einer Nummer. Ein QR-Anhänger passt zum gesamten Rettungsskript: dem Namen des Haustiers, zwei Telefonnummern, dem Tierarzt, Medikamentennotizen und „Er ist freundlich, bitte halten Sie ihn sicher“. Ein Finder scannt mit jeder Telefonkamera und liest sofort Klartext — kein Konto, keine App, keine monatliche Gebühr an einen Anhänger-Dienst.

Drucken Sie den Code auf einen wasserfesten Anhänger oder Aufkleber (oder lassen Sie ihn gravieren, sobald Sie die PNG-Datei haben), halten Sie ihn bei mindestens 15 mm und setzen Sie das Wesentliche zuerst — Telefonnummern vor Biografie. Weil der Text ins Muster gebacken ist, aktualisieren Sie den Anhänger, wenn sich Ihre Nummer ändert.

Beste Verwendungen

  • Hunde- und Katzenhalsbandanhänger
  • Käfig- und Transportbox-Etiketten
  • Farm- und Arbeitstier-Anhänger
  • Temporäre Pflege- und Tierheim-Anhänger

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

So funktioniert es

Der Code codiert Ihren Text direkt (ein Klartext-QR-Code), sodass er ohne Netzwerk und ohne Dienst in der Mitte funktioniert — die Kamera des Finders zeigt ihn einfach an.

Bella die Katze rutscht zwei Straßen weiter aus ihrem Halsband. Der Finder scannt den Anhänger, ruft die erste Nummer an, und Bella ist zu Hause, bevor ihre Besitzerin wusste, dass sie weg war — kein Chip-Lesegerät, kein Tierarztbesuch nötig.

Häufig gestellte Fragen

Ist dieser Haustier-ID-Etikett-Generator kostenlos?

Ja. Loonas Tier-ID-Anhänger-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Haustier-ID-Etikett-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

QR-Anhänger oder Mikrochip?

Beides, für verschiedene Aufgaben. Ein Chip ist dauerhaft und wird bei Tierärzten und Tierheimen gelesen; ein QR-Anhänger ist von jedem sofort vor Ort lesbar. Verwenden Sie den Anhänger für Geschwindigkeit und den Chip als Rückhalt.

Ist es sicher, meine Nummer auf einen Anhänger zu setzen?

Eine Telefonnummer auf einem sichtbaren Anhänger ist der Sinn des Anhängers — dieselbe Information, die ein gravierter Anhänger zeigt. Lassen Sie Privatadressen weg; eine Telefonnummer und ein Tierarzt genügen.
