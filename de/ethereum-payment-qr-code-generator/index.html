Über diese Ethereum-Zahlung

Ein Ethereum-Zahlungs-QR-Code folgt dem EIP-681-Standard: Er trägt Ihre Adresse und, wenn Sie einen Betrag festlegen, den in Wei umgerechneten Wert (die Wallet übernimmt die Dezimalrechnung, nicht der Kunde). Der Zahler scannt, seine Wallet zeigt Adresse und Betrag zur Bestätigung, und er signiert — kein Kopieren und Einfügen einer 42-stelligen Adresse an einem Marktstand.

Überprüfen Sie die Adresse vor dem Drucken immer Zeichen für Zeichen: Krypto-Zahlungen können nicht rückgängig gemacht werden, und ein mit einer falschen Adresse gedruckter Code sendet Geld an einen nicht wiederherstellbaren Ort. Scannen Sie Ihren eigenen Code zum Testen und bestätigen Sie, dass die Adresse, die Ihre Wallet anzeigt, mit Ihrer übereinstimmt.

Beste Verwendungen

  • Geschäfts- und Stand-Krypto-Zahlungen
  • Freelancer-Rechnungen
  • Spenden in ETH

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

So funktioniert es

Die Nutzlast ist ethereum:ADDRESS?value=WEI — Ihr ETH-Betrag wird exakt in Wei umgerechnet (String-Arithmetik, keine Gleitkomma-Rundung), was die Einheit ist, die EIP-681-Wallets erwarten.

Ausgearbeitetes Beispiel

Ein Designer stellt 0.05 ETH in Rechnung. Der Code codiert ethereum:0x…?value=50000000000000000; die Wallet des Kunden öffnet sich mit vorausgefülltem Betrag und bezahlt mit zwei Tipps.

Häufig gestellte Fragen

Ist dieser Ethereum-Zahlungs-Generator kostenlos?

Ja. Loonas Ethereum-Zahlung-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Ethereum-Zahlungsseite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Warum sieht der Betrag in der Nutzlast enorm aus?

Weil EIP-681 in Wei zählt, der kleinsten ETH-Einheit: 1 ETH = 10^18 Wei. Wallets rechnen es für die Anzeige zurück — der Zahler sieht 0.05 ETH, nicht die lange Zahl.

Kann ich mit diesem Code ERC-20-Token akzeptieren?

Diese Seite erstellt einfache ETH-Zahlungsanfragen. Token-Überweisungen verwenden eine andere EIP-681-Form (Überweisungsanfragen), die die meisten Wallets inkonsistent handhaben — erhalten Sie Token stattdessen per Nur-Adresse-Code.
