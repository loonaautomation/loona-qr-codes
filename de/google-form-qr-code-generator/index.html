Über diesen Google-Formular-QR-Code

Ein Google-Formular-QR-Code öffnet Ihr Formular sofort, was die Rücklaufquoten erhöht, weil niemand einen langen Formularlink abtippen muss.

Bei einem Seminar sammelt ein Formular-QR-Code auf dem Banner Feedback vom Publikum im Raum selbst. Das ist das eigentliche Problem, das ein Google-Formular-QR-Code löst: Er beseitigt Tippen, Suchen und Fehler und ersetzt sie durch einen einzigen Scan, der etwa zwei Sekunden dauert. Bei Loona wird der Code lokal in Ihrem Browser als statischer QR-Code erzeugt, was bedeutet, dass die Daten im Muster selbst leben. Es gibt keinen Loona-Server in der Mitte, keinen Kurzlink, der abgeschaltet werden kann, und keinen Testzeitraum, nach dem Ihr gedrucktes Material nicht mehr funktioniert — ein häufiges und teures Problem bei vielen sogenannten kostenlosen QR-Websites.

  • Event-Registrierungen und Feedback

In jedem Fall ist die Regel dieselbe: Setzen Sie den QR-Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Verbinden“ oder „Scannen zum Bezahlen“. Codes sollten mindestens 2 cm breit gedruckt werden, mit einem ruhigen weißen Rand darum und starkem Kontrast zwischen der QR-Farbe und dem Hintergrund, damit ältere Telefonkameras sie schnell lesen können. Verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie den Code größer: Ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Wenn sich Ihre Informationen später ändern, denken Sie daran, dass ein statischer QR nach dem Drucken nicht bearbeitet werden kann, erzeugen Sie also einen frischen Code und ersetzen Sie den alten Druck; der Vorteil dieses Kompromisses ist ein Code, der niemals als Geisel gehalten werden, ablaufen oder aufhören kann zu funktionieren, weil ein Unternehmen geschlossen hat.

Ist dieser Google-Formular-QR-Code-Generator kostenlos?

Ja. Loonas Google-Formular-QR-Code-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein Google-Formular-QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst (zum Beispiel Ihre Website oder Nummer) aktiv bleibt.

Wie verwende ich den Google-Formular-QR-Code, den ich erzeugt habe?

Füllen Sie das Formular aus, überprüfen Sie die Live-Vorschau, wählen Sie Ihre Farben und Größe und klicken Sie dann auf PNG herunterladen. Drucken Sie ihn aus oder teilen Sie ihn digital, und scannen Sie ihn immer einmal mit Ihrem eigenen Telefon zum Testen, bevor Sie in großer Menge drucken.

Sind meine Informationen auf dieser Google-Formular-QR-Code-Seite privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben — Passwörter, Nummern oder Links — wird an einen Server gesendet oder auf einem gespeichert.

So funktioniert es

Sie fügen den Link zu Ihrem Google-Formular ein, und dieser Link wird direkt im QR-Muster codiert. Das Scannen öffnet das Formular im Browser des Besuchers, bereit zum Ausfüllen — dasselbe Formular, mit denselben Fragen und Einstellungen, das der Link überall sonst öffnet. Nichts am Formular wird vom Code kopiert oder gespeichert, und Antworten gehen zum Antworten-Tab Ihres Formulars, exakt als hätte jeder Besucher den Link von Hand getippt.

Ausgearbeitetes Beispiel

Eine Schule veranstaltet einen Tag der offenen Tür und wünscht sich Elternfeedback. Die Lehrkraft öffnet das Feedback-Formular in Google Forms, kopiert dessen Link über die Schaltfläche Senden und fügt ihn hier ein. Der QR-Code kommt auf das Eingangsbanner und die Klassenzimmertüren. Eltern scannen ihn, das Formular öffnet sich auf ihren Telefonen, sie beantworten sechs Fragen und senden ab — während die Lehrkraft beobachtet, wie sich die Antworten im Formular sammeln, statt Papierzettel auszuteilen und sie später abzutippen.

Häufig gestellte Fragen

Welchen Link soll ich einfügen — den langen oder den kurzen?

Verwenden Sie den Link von der Senden-Schaltfläche des Formulars; das Ankreuzen von “Shorten URL” dort gibt Ihnen einen kurzen forms.gle-Link. Kürzere Links machen einfachere Muster, die leichter scannen, und beide Versionen öffnen dasselbe Formular.

Warum werden einige Scanner gebeten, sich bei Google anzumelden?

Das ist die Freigabeeinstellung Ihres Formulars, nicht der QR-Code. Wenn das Formular auf Ihre Schule oder Organisation beschränkt ist, erreichen Außenstehende eine Anmeldewand. Wenn die Öffentlichkeit antworten soll, stellen Sie das Formular so ein, dass jeder mit dem Link es kann.

Kann ich erkennen, welche Antworten über den QR-Code kamen?

Der Code trägt kein Tracking, sodass Antworten wie alle anderen aussehen. Wenn Sie eine grobe Zählung brauchen, verwenden Sie eine separate Kopie des Formulars (mit eigenem Link und Code) für jeden Standort oder jedes Event.

Was passiert, wenn ich das Formular nach dem Drucken des Codes bearbeite?

Bearbeitungen sind sicher: Der Code öffnet das Live-Formular unter diesem Link, sodass geänderte oder neue Fragen automatisch erscheinen. Aber wenn Sie das Formular löschen oder sich sein Link ändert, funktioniert der gedruckte Code nicht mehr.

Kann das Formular Fragen zum Hochladen von Dateien enthalten?

Ja — der Code öffnet einfach das Formular, und Upload-Fragen funktionieren im Browser wie üblich. Beachten Sie, dass Google verlangt, dass die Befragten vor dem Hochladen von Dateien angemeldet sind.

Funktioniert dies auch für Quizze und Prüfungsformulare?

Ja. Ein Google Forms-Quiz ist immer noch ein Formular an derselben Art von Link, also öffnet derselbe Code es im Quiz-Modus mit den von Ihnen gewählten Einstellungen.
