Warum einen QR-Code auf ein Tool setzen?

Einige Loona-Tools werden jeden einzelnen Tag von denselben Menschen verwendet: Banker öffnen den Altersrechner für jeden Kunden, Lehrer verwenden die Unterrichts- und Lern-Tools wieder, Ladeninhaber prüfen Gehalts-, Steuer- und Rechnungs-Tools immer wieder. Eine lange Webadresse jedes Mal abzutippen ist langsam und fehleranfällig. Ein gedruckter QR-Code auf dem Schreibtisch oder an der Wand beseitigt all das — ein Scan, etwa zwei Sekunden, und das exakte Tool ist geöffnet und bereit. Deshalb wurde der Altersrechner-QR-Code auf unserer Startseite so beliebt, und deshalb bietet diese Seite nun denselben fertigen Code für jedes Tool im Netzwerk an: alle 955 von ihnen, von Zakat- und EMI-Rechnern bis zu PDF-Konvertern, Bildkompressoren und Gebetszeit-Tools.

Jeder Code hier ist ein statischer QR-Code: Die eigene Adresse des Tools wird direkt in das Muster geschrieben. Es gibt keinen Kurzlink, keine Weiterleitung über einen Drittanbieter-Server und kein Abonnement, das auslaufen kann — ein Code, den Sie heute drucken, kann morgen also nicht abgeschaltet werden. Wenn ein Tool jemals auf eine neue Adresse umzieht, kehren Sie einfach auf diese Seite zurück und laden Sie einen neuen Code herunter.

Drucktipps

  • Drucken Sie den Code mindestens 2 cm breit; größer für Plakate, die aus der Entfernung gescannt werden (ein guter Richtwert ist ein Zehntel der Scanentfernung).
  • Behalten Sie den weißen Rand um den Code — Telefonkameras brauchen diese Ruhezone, um ihn schnell zu lesen.
  • Die heruntergeladene PNG-Datei ist hochauflösend (880 px breit), sodass sie auf Papier, Aufklebern und Bannern scharf bleibt.
  • Scannen Sie die gedruckte Kopie immer einmal mit Ihrem eigenen Telefon zum Testen, bevor Sie in Menge drucken.

Häufig gestellte Fragen

Ist es kostenlos, einen QR-Code für ein Loona-Tool zu erstellen?

Ja. Jeder QR-Code auf dieser Seite ist völlig kostenlos — keine Anmeldung, kein Wasserzeichen und kein Limit, für den persönlichen oder kommerziellen Gebrauch.

Laufen diese QR-Codes ab?

Nein. Jeder Code ist ein statischer QR-Code, der die eigene Webadresse des Tools direkt im Muster codiert. Es gibt keine Weiterleitung und keinen Server in der Mitte, sodass ein gedruckter Code funktioniert, solange das Tool selbst online bleibt.

Kann ich diese QR-Codes drucken?

Ja. Der Download ist ein hochauflösendes PNG mit dem Namen des Tools unter dem Code gedruckt, bereit für Schreibtische, Theken, Klassenzimmer und Schaufenster. Drucken Sie es mindestens 2 cm breit und scannen Sie es einmal zum Testen, bevor Sie in Menge drucken.

Welche Tools sind enthalten?

Alle von ihnen: jedes primäre Tool und jede App im gesamten Loona-Netzwerk — Rechner, Gehalts- und Steuer-Tools, PDF-Tools, Bild-Tools, Text-Tools, Entwickler-Tools, Design- und Lern-Tools, islamische Tools, Stunden-Tools und mehr — 955 Tools und Apps in einer Liste.
