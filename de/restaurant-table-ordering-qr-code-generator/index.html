Über diese Tischbestellung im Restaurant

Tischbestellung funktioniert, wenn der Scan genau dort landet, wo der Gast es erwartet: bei der Speisekarte, mit eingebauter Bestellung — nicht auf der Startseite des Restaurants, nicht bei einer PDF von 2022. Kombinieren Sie einen Code pro Tisch (die Tischlinks Ihrer Bestellplattform) mit Tischkarten, die sagen, was als Nächstes passiert: „Scannen, bestellen, bezahlen — wir bringen es zu Tisch 12.“

Tischspezifische Links zählen: Sie sagen der Küche, wohin das Essen geht. Erzeugen Sie einen Code pro Tisch aus den Links Ihrer Plattform, drucken Sie sie identisch bis auf das Ziel und behalten Sie einen generischen Speisekarten-Code an der Tür für die Schlange.

Beste Verwendungen

  • Tischkarten
  • Theke und Fenster für Takeaway-Bestellungen
  • Garten- und Terrassentische
  • Hotel-Zimmerservice-Türen

Setzen Sie den Code genau dorthin, wo die Entscheidung getroffen wird — auf den Tisch, die Theke, die Verpackung, die Einladung oder den Bildschirm — und geben Sie den Menschen eine kurze Anweisungszeile wie „Scannen zum Öffnen“ oder „Scannen zum Bezahlen“. Drucken Sie Codes mindestens 2 cm breit mit einem ruhigen weißen Rand und starkem Kontrast, damit ältere Telefonkameras sie schnell lesen; verwenden Sie für Plakate, die aus der Entfernung gescannt werden, die Größe 1024 px und drucken Sie größer — ein guter Richtwert ist grob ein Zehntel der Scanentfernung.

Häufig gestellte Fragen

Ist dieser Tischbestellungs-Generator für Restaurants kostenlos?

Ja. Loonas Restaurant-Tischbestellung-Generator ist völlig kostenlos, ohne Anmeldung, ohne Wasserzeichen und ohne Begrenzung, wie viele Codes Sie erstellen, für den persönlichen oder kommerziellen Gebrauch.

Läuft mein QR-Code ab?

Nein. Loona erstellt statische QR-Codes: Ihre Informationen sind direkt im QR-Muster selbst codiert, nicht auf einem Server gespeichert oder hinter einer bezahlten Weiterleitung versteckt. Ein Code, den Sie heute drucken, funktioniert, solange das Ziel selbst aktiv bleibt.

Sind meine Informationen auf dieser Tischbestellungs-Seite für Restaurants privat?

Ja. Die Erzeugung geschieht zu 100 % in Ihrem Browser mit JavaScript. Nichts, was Sie eingeben, wird an einen Server gesendet oder auf einem gespeichert.

Ein Code für alle Tische oder einer pro Tisch?

Pro Tisch für die Bestellung (die Küche braucht die Tischidentität). Ein gemeinsamer Code ist für eine Nur-Ansehen-Speisekarte in Ordnung.

Was, wenn Gäste einen Kellner bevorzugen?

Behalten Sie beides. Tisch-Codes beseitigen das Anstehen für Gäste, die Geschwindigkeit wollen; sie beseitigen nicht die menschliche Option.
