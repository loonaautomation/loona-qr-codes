この PDF417 について

PDF417 (ISO/IEC 15438) は、米国の運転免許証の裏面（AAMVA 標準）、航空会社の搭乗券（元の BCBP 形式）、ID カード、出荷ラベルにある、幅広い積み重ね型バーコードです。ポータブルなデータファイルを保存します — 名前の由来です — 最大で約 1,850 文字を、強力で調整可能な Reed–Solomon 誤り訂正とともに、通常の 1D スタイルのスキャナーが行ごとに読める行に保存します。

その長方形の形状と行構造により、通常のラベルプリンターやレーザープリンターで印刷可能であり、カメラスキャンが存在するはるか前に政府がそれを採用した理由の一つです。

最適な用途

  • 運転免許証と ID カード
  • 搭乗券
  • 政府のフォームと許可証
  • レガシーな物流ラベル

コードは、決定が行われる場所に正確に置いてください — テーブル、カウンター、パッケージ、招待状、画面 — そして人々に「Scan to open」や「Scan to pay」のような短い指示を一言与えてください。コードは、静かな白い枠線と強いコントラストを持たせ、少なくとも 2 cm の幅で印刷することで、古いスマートフォンのカメラでも素早く読み取れます。距離からスキャンされるポスターについては、1024 px のサイズを使い、大きく印刷してください：良い目安は、概ねスキャン距離の十分の一です。

仕組み

標準の圧縮で、同梱の bwip-js エンコーダーを使用して生成されます。ライセンス/ID 用途では、ペイロードは発行当局のデータレイアウトに正確に従わなければなりません（米国ライセンスは AAMVA）— このジェネレーターは、与えられたテキストを順序通りにエンコードします。

実例

イベント主催者は、認定記録を一行に保持した PDF417 付きのスタッフバッジを印刷します — 名前、役割、ゾーン — ゲートのラインスキャナーで、ネットワーク検索なしに読み取れます。

よくある質問

この PDF417 生成ツールは無料ですか？

はい。Loona の PDF417 生成ツールは完全に無料であり、登録不要、透かしなし、作成できるコードの数に制限はなく、個人利用と商用利用のいずれにも対応しています。

私の QRコードに有効期限はありますか？

いいえ。Loona は静的QRコードを作成します：あなたの情報は QR パターン自体に直接エンコードされ、サーバーに保存されたり、有料のリダイレクトの後ろに隠れたりしません。今日印刷したコードは、宛先自体が有効な限り機能し続けます。

この PDF417 ページで私の情報はプライベートですか？

はい。生成は JavaScript を使用してブラウザ内で 100% 行われます。入力したものは、どのサーバーにも送信されたり保存されたりしません。

PDF417 か Data Matrix か？

標準がそれを指定する場合（ライセンス、古い搭乗券）、または幅広いラベルとラインスキャナーが制約の場合は PDF417。狭いスペースでの新しい産業/医療マーキングには Data Matrix。

スマートフォンで PDF417 をスキャンできますか？

はい — 多くのスキャナーアプリと一部のカメラアプリが読みます（ライセンススキャンアプリの仕組みです）。ただし、長いシンボルはコード全体がフレーム内にある必要があります。
