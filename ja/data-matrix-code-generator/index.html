この Data Matrix について

Data Matrix (ISO/IEC 16022, ECC 200) は、産業と医療の 2D コードです：爪ほどの大きさの正方形（数ミリメートル四方）に実際のデータを保存し、Reed–Solomon 誤り訂正のおかげで、シンボルの最大で約 25% が損傷しても読み取れます。GS1 DataMatrix は、EU と米国全体で医薬品と医療機器に義務付けられたコード（UDI）であり、電子機器メーカーは部品に直接レーザー刻印します。

QR とは異なり、角に装飾的なファインダーの四角はありません — L 字型の実線の枠と、交互のモジュールのクロックトラックが、データがどこにあるかをスキャナーに伝えます。

最適な用途

  • 医薬品と医療機器のパック (GS1/UDI)
  • レーザー刻印された電子機器とエンジン部品
  • 航空宇宙部品の追跡
  • QR が収まらない小さなラベル

コードは、決定が行われる場所に正確に置いてください — テーブル、カウンター、パッケージ、招待状、画面 — そして人々に「Scan to open」や「Scan to pay」のような短い指示を一言与えてください。コードは、静かな白い枠線と強いコントラストを持たせ、少なくとも 2 cm の幅で印刷することで、古いスマートフォンのカメラでも素早く読み取れます。距離からスキャンされるポスターについては、1024 px のサイズを使い、大きく印刷してください：良い目安は、概ねスキャン距離の十分の一です。

仕組み

エンコードは、同梱の bwip-js ライブラリ（ラベルソフトウェアに信頼されるエンコーダー BWIPP のブラウザ移植版）で実行され、本物の ECC 200 シンボルを生成します。見た目だけが異なる QR ではありません。容量は、10×10 シンボルの数文字から、144×144 での約 2,335 英数字までです。

実例

PCBメーカーは、各基板に LOT-8841;EXP-2027-05 形式のトレーサビリティデータを 5 mm の Data Matrix で刻印します。十年後、技術者が基板をスキャンすると、完全な生産記録が開きます。

よくある質問

この Data Matrix 生成ツールは無料ですか？

はい。Loona の Data Matrix 生成ツールは完全に無料であり、登録不要、透かしなし、作成できるコードの数に制限はなく、個人利用と商用利用のいずれにも対応しています。

私の QRコードに有効期限はありますか？

いいえ。Loona は静的QRコードを作成します：あなたの情報は QR パターン自体に直接エンコードされ、サーバーに保存されたり、有料のリダイレクトの後ろに隠れたりしません。今日印刷したコードは、宛先自体が有効な限り機能し続けます。

この Data Matrix ページで私の情報はプライベートですか？

はい。生成は JavaScript を使用してブラウザ内で 100% 行われます。入力したものは、どのサーバーにも送信されたり保存されたりしません。

Data Matrix と QRコード — どちらですか？

サイズが極小の場合、表面が部品やパックの場合、または業界のルール（製薬 UDI、GS1 ヘルスケア）が指定する場合は Data Matrix。一般の人々がスキャンしなければならない場合は QR — すべてのスマートフォンカメラは QR をネイティブに読み取りますが、Data Matrix は適切なスキャナーアプリが必要なことが多いためです。

スマートフォンのカメラで Data Matrix をスキャンできますか？

多くの新しいスマートフォンと、ほとんどの専用スキャナーアプリは可能です。一部の標準カメラアプリはできません。消費者向けの用途には、QR を優先してください。
