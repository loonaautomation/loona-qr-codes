この Code 128 について

Code 128 (ISO/IEC 15417) は、世界で汎用の高密度バーコードです：あらゆる 1D シンボロジーの中で最も狭い幅に、文字、数字、句読点を詰め込みます。そのため、出荷ラベル（GS1-128 として）、倉庫のラック、資産タグ、図書館システムを支配しています。

三つの文字サブセットで動作します — A（大文字＋制御コード）、B（完全な大文字小文字混在 ASCII）、C（二倍密度の数字ペア）— 優れたエンコーダーは、シンボルを短く保つためにサブセットを自動的に切り替えます。すべての Code 128 シンボルは、組み込みのモジュロ 103 チェックサムを持ちます。そのため、スキャナーは推測する代わりに、損傷した読み取りを拒否します。

最適な用途

  • 倉庫と在庫のラベル
  • 出荷とパレットのラベル (GS1-128)
  • 資産および機器のタグ
  • 図書館とアーカイブのアイテム

コードは、決定が行われる場所に正確に置いてください — テーブル、カウンター、パッケージ、招待状、画面 — そして人々に「Scan to open」や「Scan to pay」のような短い指示を一言与えてください。コードは、静かな白い枠線と強いコントラストを持たせ、少なくとも 2 cm の幅で印刷することで、古いスマートフォンのカメラでも素早く読み取れます。距離からスキャンされるポスターについては、1024 px のサイズを使い、大きく印刷してください：良い目安は、概ねスキャン距離の十分の一です。

仕組み

入力すると、エンコーダーはサブセットの混合を自動的に選択します：長い数字の連続はサブセット C で圧縮されます（文字ごとに二桁）。そのため、20 桁のシリアルは驚くほど短いバーコードを生成します。

実例

修理店は、ジョブ番号をエンコードした Code 128 タグを、すべての顧客デバイスに付けます。受付時と発送時にタグがスキャンされ、入力も桁の入れ違いもなく、ジョブ履歴が即座に開きます。例：INV-2026-0042。

よくある質問

この Code 128 生成ツールは無料ですか？

はい。Loona の Code 128 生成ツールは完全に無料であり、登録不要、透かしなし、作成できるコードの数に制限はなく、個人利用と商用利用のいずれにも対応しています。

私の QRコードに有効期限はありますか？

いいえ。Loona は静的QRコードを作成します：あなたの情報は QR パターン自体に直接エンコードされ、サーバーに保存されたり、有料のリダイレクトの後ろに隠れたりしません。今日印刷したコードは、宛先自体が有効な限り機能し続けます。

この Code 128 ページで私の情報はプライベートですか？

はい。生成は JavaScript を使用してブラウザ内で 100% 行われます。入力したものは、どのサーバーにも送信されたり保存されたりしません。

Code 128 と Code 39 — どちらを使うべきですか？

Code 128 は、ほぼすべての現代的な用途に適しています：より高密度で、小文字と句読点をサポートし、必須のチェックサムがあります。Code 39 は主に、古いスキャナーや業界のルール（一部の自動車や防衛のラベル）が要求する場所で生き残っています。

Code 128 は小文字をエンコードできますか？

はい — サブセット B は、小文字を含む印刷可能な ASCII の全範囲をカバーし、このジェネレーターはサブセットを自動的に切り替えます。
