3つのステップでバーコードを作成する方法

  1. コンテンツを入力 そしてバーコードの種類を選んでください。EAN-13、UPC-A、ITF-14 については、番号を入力してください なし 最後のチェックデジット — ジェネレーターはそれを計算して追加するか、完全な番号を入力した場合はそれを検証します。
  2. ライブプレビューを確認 そしてバーの色、背景、高さを調整してください。強いコントラストを保ってください：明るい背景に暗いバーが最もよくスキャンできます。
  3. PNG または SVG をダウンロード、印刷し、大量に印刷する前にスマートフォンのアプリやスキャナーで一度テストスキャンしてください。SVG はどのサイズでも完璧に鮮明で、プロの印刷に最適です。

印刷前に確認してください： 生成した後、私たちの無料ツールでバーコードをスキャンし直してください QRコード＆バーコードスキャナー — 写真からバーコードも読み取るため、印刷されたプルーフが意図した番号を正確に読むことを確認できます。

バーコードと五つの種類について

バーコードは短いコードをバーのパターンに変え、スキャナーが一瞬で読み取ります。用途によって異なるバーコードの種類（シンボロジーと呼ばれます）が使われ、適切な選択が重要です。店舗のレジは EAN-13 や UPC-A を想定し、倉庫では Code 128 で十分であり、出荷用カートンは ITF-14 を使います。

  • Code 128 — 多目的の主力。文字、数字、句読点をほぼ任意の長さでエンコードし、コンパクトなままです。在庫ラベル、資産タグ、図書館カードと ID カード、あらゆる種類の内部追跡に最適です。
  • Code 39 — より古く、よりシンプルな標準。大文字、数字、そして記号 - . $ / + % とスペースのみ。古いスキャナーに非常に広くサポートされており、軍事、自動車、シンプルな資産ラベルに一般的です。
  • EAN-13 — 北米以外の小売標準。正確に 13 桁：あなたの 12 桁に計算されたチェックデジットを加えたもの。製品番号は、小売販売に使用するには GS1 に登録しなければなりません（下記の FAQ を参照）。
  • UPC-A — 米国とカナダの小売標準。正確に 12 桁：あなたの 11 桁にチェックデジットを加えたもの。これも小売用に GS1 を通じて発行されます。
  • ITF-14 — 出荷用段ボールの標準。正確に 14 桁（13 ＋ チェックデジット）、箱に大きく印刷され、カートン全体を開けずにスキャンできます。

小売タイプについて正直な警告が一つ：このジェネレーターは、 構造的に正しい どのスキャナーでも読めるバーコードであり、それが倉庫、棚、学校とオフィスの在庫、イベントパス、内部ラベルに必要なすべてです。しかし、バーコードが店舗のレジやオンラインマーケットプレイスでスキャンされる場合は、番号自体が公式にあなたのものでなければなりません — あなたの会社の下で GS1 に登録されたもの。小売番号を発明すると、別の会社の製品コードをあなたの商品に印刷するリスクがあります。

このバーコード生成ツールの最適な用途

  • 在庫と倉庫のラベル
  • 学校、オフィス、作業場の機器用資産タグ
  • 棚端と倉庫のロケーションラベル
  • 図書館の本、ID カード、会員カード
  • ITF-14 による出荷段ボールのマーキング

どの種類を選んでも、スキャンのルールは同じです：バーコードを妥当なサイズで印刷し（手持ちスキャナーでは少なくとも幅約 3 cm）、両側に明確な空白の余白 — クワイエットゾーン — を保ち、画像を決して引き伸ばしたり押しつぶしたりしないでください。スキャナーが測定するバーの幅が歪むためです。SVG ファイルは歪みなく拡大でき、印刷に最も安全な選択です。十分な高さの PNG は、画面やオフィスプリンターに適しています。

よくある質問

このバーコード生成ツールは無料ですか？

はい。Loona のバーコード生成ツールは完全に無料であり、登録不要、透かしなし、作成できるバーコードの数に制限はなく、個人利用と商用利用のいずれにも対応しています。

生成した EAN-13 や UPC バーコードを、店舗で販売する製品に使えますか？

バーコード画像は構造的に正しく、スキャンされますが、小売バーコードは登録されなければなりません：店舗とマーケットプレイスは、公式組織である GS1 によって、あなた自身の会社プレフィックスで発行された番号を要求します。ここで発明した番号は、他の誰かの製品と衝突する可能性があります。在庫、資産、棚、内部使用については、生成されたバーコードで問題ありません。小売販売については、まず GS1 に登録してください。

チェックデジットとは何ですか、そして自分で計算する必要がありますか？

EAN-13、UPC-A、ITF-14 は、他の桁から計算されたチェックデジットで終わります。そのため、スキャナーは読み取りミスを検出できます。計算する必要はありません：チェックデジットなしで番号を入力すると（EAN-13 は 12 桁、UPC-A は 11 桁、ITF-14 は 13 桁）、このジェネレーターが追加します。完全な番号を入力すると、ジェネレーターはチェックデジットを検証し、誤っている場合は知らせます。

このバーコード ページで私の情報はプライベートですか？

はい。バーコードは JavaScript を使用してブラウザ内で 100% 描画されます。入力したものは、どのサーバーにも送信されたり保存されたりしません。

仕組み

このジェネレーターは、完全にブラウザ内で実行される JsBarcode ライブラリを使用して、あなたのコンテンツを選んだ標準の正確なバーパターンに変換します。番号付きの小売タイプについては、まず GS1 チェックデジットルールを適用します：右から桁を読み、交互の桁に 3 と 1 を掛け、結果を合計し、チェックデジットは合計を十の倍数にするものです。その一桁が、レジがバーコードを正しく読んだことを知る方法です — バーが一つ損傷し、桁が誤読されると、合計が一致しなくなり、スキャナーは誤った価格を請求する代わりに、再スキャンのためにビープ音を鳴らします。

方法： 種類を選択 → コンテンツを入力（EAN-13、UPC-A、ITF-14 はチェックデジットなし） → プレビューを確認 → PNG または SVG をダウンロード → 印刷してテストスキャン。

実例

学校の司書は新しい本のラベルが欲しく、登録簿の受入番号で Code 128 を選びます — LIB-1001、LIB-1002 などです。各バーコードを生成し、線が鮮明に保たれるよう SVG をダウンロードして、シールシートにラベルを印刷します。学校の食堂の飲料カートンについては、代わりに ITF-14 を選び、仕入先カタログに印刷された 13 桁を入力します。ジェネレーターがチェックデジットを追加し、倉庫係は納品時に未開封のカートン全体をスキャンできるようになります。

よくある質問

バーコードと QRコードの違いは何ですか？

バーコードは一次元です。短いコード（通常は数字のみ、または短いID）を保存し、データベースがそれを検索します。QRコードは二次元で、はるかに多くを保存できます。完全なリンク、WiFiパスワード、連絡先カードなどです。そしてスマートフォンのカメラで読み取られます。スキャナーガンやレジが関係する場合はバーコードを使い、スマートフォンのカメラが関係する場合はQRコードの方が通常適しています。

なぜ私の EAN-13 番号は拒否されたのですか？

数字以外のものが含まれているか、長さが 12 桁または 13 桁でないか、13 桁目が計算されたチェックデジットと一致していません。プレビューの下のメッセージが、チェックデジットがどの数字であるべきかを示すため、入力ミスに気付けます。

バーコードの色を変更できますか？

はい — バーの色と背景はプレビューの上にあります。スキャナーは色自体ではなくコントラストを読むため、白や淡い背景に暗いバー（黒、濃い青、濃い緑）が最適です。赤いバーは避けてください：多くのレーザースキャナーは赤い光を使用し、見ることができません。

PNG か SVG か — どちらをダウンロードすべきですか？

プロとして印刷されたり拡大されたりするものには SVG を選択してください。ぼやけることなく任意のサイズに拡大できます。ドキュメント、スプレッドシート、スライド、簡単なオフィス印刷には PNG を選択してください。

一つのバーコードに長いメッセージやウェブリンクを入れられますか？

うまくいきません。バーコードは短いコード用に設計されています。長いリンクは、多くのスキャナーが苦労する極めて高密度な Code 128 を作ります。リンクや長いコンテンツについては、代わりに私たちの QRコード生成ツールのいずれかをご利用ください — それこそが QRコードが発明された目的です。
