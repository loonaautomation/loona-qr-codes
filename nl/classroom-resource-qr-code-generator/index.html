Gratis klaslokaalbron-QR-codegenerator

Op het werkblad, de muur of het bord: één scan opent de video, de quiz of de huiswerkpagina op het apparaat van elke leerling.

Je QR-code

Vul het formulier in en je QR-code verschijnt hier.

100% privé: deze QR-code wordt in je browser aangemaakt. Niets wat je typt, wordt naar een server geüpload en de code verloopt nooit.

Hoe je er een maakt in 3 stappen

  1. Voer je gegevens in in het formulier hierboven — alleen de velden voor dit type, niets extra.
  2. Controleer de live preview en pas de kleur, achtergrond en het formaat (256, 512 of 1024 px) aan je merk of druk aan.
  3. Klik op PNG downloaden, testscan de code één keer met je telefoon en print of deel hem daarna waar je publiek ook is.

Over deze klaslokaalbron

Leraren verliezen tien minuten van een lesuur van 40 minuten aan het typen van links. Een QR-code op het geprinte werkblad, de sticker in de marge van het leerboek of de klasmuur neemt het typen volledig weg: scan, en de uitlegvideo, oefenquiz of huiswerkpagina is op elk bureau tegelijk open.

Klasregels die het laten werken: één code per bron (niet een pagina van twaalf), een kort geprint label dat zegt wat hij opent (“Watch: Fractions in 3 minutes”) en een korte terugvallink voor het ene apparaat waarvan de camera faalt. Codes aan de muur — klassenpagina, rooster, bibliotheek — dienen het hele semester.

Beste toepassingen

  • Werkbladen en hand-outs
  • Huiswerkinstructies
  • Klasmuur: klassenpagina en rooster
  • Ouderinformatieavonden

Zet de code precies waar de beslissing wordt genomen — op de tafel, de toonbank, de verpakking, de uitnodiging of het scherm — en geef mensen één korte instructieregel zoals “Scan to open” of “Scan to pay”. Print codes minstens 2 cm breed met een stille witte rand en sterk contrast, zodat oudere telefooncamera's ze snel lezen; gebruik voor posters die vanaf een afstand worden gescand het formaat 1024 px en print groter — een goede richtlijn is ongeveer een tiende van de scanafstand.

Hoe het werkt

Een statische URL-QR naar de bronpagina — een video, een quiz, een document of je klassensite. Verander de bron op hetzelfde adres naarmate het semester vordert; het geprinte werkblad blijft werken.

Uitgewerkt voorbeeld

Een wiskundeleraar print een code in de hoek van elk werkblad: de video met het uitgewerkte voorbeeld voor precies dat onderwerp. Leerlingen die thuis vastzitten, scannen in plaats van op te geven en de volgende les begint waar hij moet beginnen.

Veelgestelde vragen

Is deze klaslokaalbrongenerator gratis?

Ja. Loona’s Classroom Resource-generator is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel codes je maakt, voor persoonlijk of commercieel gebruik.

Verloopt mijn QR-code?

Nee. Loona maakt statische QR-codes: je informatie wordt rechtstreeks in het QR-patroon zelf gecodeerd, niet opgeslagen op een server of verborgen achter een betaalde omleiding. Een code die je vandaag print, blijft werken zolang de bestemming zelf actief blijft.

Is mijn informatie privé op deze klaslokaalbronpagina?

Ja. Genereren gebeurt 100% in je browser met JavaScript. Niets wat je invoert, wordt verstuurd naar of opgeslagen op een server.

Eén code per werkblad — is dat niet veel printen?

De code print als onderdeel van het werkblad dat je al print. Het kost geen extra papier, alleen de minuut die het kost om hem eenmaal te genereren en in je sjabloon te plakken.

Wat als leerlingen de link naar de huiswerkantwoorden delen?

De code opent de bron die je koos — link naar de opdracht of de uitleg, nooit naar een antwoordsleutel die je niet in de klas zou uitdelen.
