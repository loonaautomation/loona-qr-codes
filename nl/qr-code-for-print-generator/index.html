  1. Voer je gegevens in in het formulier hierboven — alleen de velden voor dit type, niets extra.

Over deze printklare

Print straft slordige QR-codes op specifieke, voorspelbare manieren: inkt verspreidt zich (dot gain) en maakt modules dikker, rijke zwartmengsels registreren verkeerd en ontwerpers snijden de stille zone bij voor stijl. Een printklare workflow verdedigt tegen alle drie — bron in hoge resolutie (1024 px hier), puur zwart op wit voor enkelkleurig werk, de stille zone van 4 modules leeg gehouden en een persproef gescand vóór de oplage.

Als een merkkleur moet worden gebruikt, houd hem donker (marineblauw, diepgroen, bordeaux scannen; geel en pastels niet), houd de achtergrond met een ruime marge lichter dan de code en keer de code nooit om (licht patroon op donkere ondergrond faalt op veel scanners).

Beste toepassingen

  • Flyers en brochures
  • Verpakkingen en labels
  • Visitekaartjes en briefpapier
  • Bewegwijzering en tentoonstellingsgrafiek

Zet de code precies waar de beslissing wordt genomen — op de tafel, de toonbank, de verpakking, de uitnodiging of het scherm — en geef mensen één korte instructieregel zoals “Scan to open” of “Scan to pay”. Print codes minstens 2 cm breed met een stille witte rand en sterk contrast, zodat oudere telefooncamera's ze snel lezen; gebruik voor posters die vanaf een afstand worden gescand het formaat 1024 px en print groter — een goede richtlijn is ongeveer een tiende van de scanafstand.

Hoe het werkt

De generator rendert een statische QR op tot 1024 px PNG — de resolutie die drukkerijen vragen bij typische codeformaten — lokaal gegenereerd, zonder watermerk en zonder vervaldatum.

Uitgewerkt voorbeeld

De nieuwe flyer van een bakkerij draagt een menucode. De ontwerper proefdrukt hem op het echte papier, scant op armlengte in winkellicht en geeft pas daarna de oplage van 10,000 vrij — de code leest op elke flyer.

Veelgestelde vragen

Is deze printklare generator gratis?

Ja. Loona’s Print-Ready-generator is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel codes je maakt, voor persoonlijk of commercieel gebruik.

Verloopt mijn QR-code?

Nee. Loona maakt statische QR-codes: je informatie wordt rechtstreeks in het QR-patroon zelf gecodeerd, niet opgeslagen op een server of verborgen achter een betaalde omleiding. Een code die je vandaag print, blijft werken zolang de bestemming zelf actief blijft.

Is mijn informatie privé op deze printklare pagina?

Ja. Genereren gebeurt 100% in je browser met JavaScript. Niets wat je invoert, wordt verstuurd naar of opgeslagen op een server.

PNG of vector voor druk?

Bij 1024 px is PNG scherp voor codes tot ongeveer 15 cm. Laat de code voor groter werk opnieuw op formaat renderen in plaats van hem op te schalen en houd de verhoudingen en stille zone van deze pagina intact.

Kan ik de code in mijn merkkleur printen?

Een donkere merkkleur op wit scant meestal goed. Test de proef met meerdere telefoons, waaronder een oudere Android — dat is de strengste rechter.
