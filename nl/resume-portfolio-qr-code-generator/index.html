Over deze cv-/portfolio-QR-code

Een cv-QR koppelt je geprinte cv of visitekaartje aan je online cv, portfolio, LinkedIn of werkvoorbeelden, die te rijk zijn voor papier.

Een afgestudeerde print een cv-QR bovenaan haar cv; de interviewer scant en ziet direct haar volledige portfolio. Dat is het echte probleem dat een cv-/portfolio-QR-code oplost: hij neemt typen, zoeken en fouten weg en vervangt ze door één scan die ongeveer twee seconden duurt. Bij Loona wordt de code lokaal in je browser gegenereerd als statische QR, wat betekent dat de gegevens in het patroon zelf leven. Er zit geen Loona-server tussen, geen korte link die kan worden uitgeschakeld en geen proefperiode waarna je gedrukte materiaal stopt met werken — een veelvoorkomend en duur probleem bij veel zogenaamde gratis QR-websites.

Beste toepassingen van een cv-/portfolio-QR-code

  • Werkzoekenden en pas afgestudeerden
  • Ontwerpers, ontwikkelaars en schrijvers
  • Freelancers die klanten pitchen
  • Studenten en stagiairs

In elk geval is de regel dezelfde: zet de QR-code precies waar de beslissing wordt genomen — op de tafel, de toonbank, de verpakking, de uitnodiging of het scherm — en geef mensen één korte instructieregel zoals “Scan to connect” of “Scan to pay”. Codes moeten minstens 2 cm breed worden geprint, met een stille witte rand eromheen en sterk contrast tussen de QR-kleur en de achtergrond, zodat oudere telefooncamera's ze snel kunnen lezen. Gebruik voor posters die vanaf een afstand worden gescand het formaat 1024 px en print de code groter: een goede richtlijn is ongeveer een tiende van de scanafstand.

Je kunt Loona-QR-codes vrij gebruiken voor commercieel werk — menu's, visitekaartjes, klantprojecten, verpakkingen en bewegwijzering — zonder vereiste naamsvermelding. Omdat genereren privé en offline-capabel is zodra de pagina is geladen, verlaten gevoelige gegevens zoals WiFi-wachtwoorden en betaalnummers je apparaat nooit. Onthoud als je informatie later verandert dat een statische QR na het printen niet kan worden bewerkt, dus genereer een nieuwe code en vervang de oude print; het voordeel van die afweging is een code die nooit gegijzeld kan worden, kan verlopen of kan stoppen met werken omdat een bedrijf is gesloten.

Ja. Loona's Resume / Portfolio QR Code-generator is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel codes je maakt, voor persoonlijk of commercieel gebruik.

Is mijn informatie privé op deze cv-/portfolio-QR-codepagina?

Ja. Genereren gebeurt 100% in je browser met JavaScript. Niets wat je invoert — wachtwoorden, nummers of links — wordt verstuurd naar of opgeslagen op een server.

Hoe het werkt

Deze generator slaat één webadres op in het QR-patroon: de link naar je online cv of portfolio die je in het formulier typt. Als je het begin weglaat, voegt de tool https:// voor je toe, dus zowel “ayeshakhan.design” als “https://ayeshakhan.design” produceren dezelfde werkende code. Wanneer iemand hem scant, opent zijn telefoon eenvoudig dat adres in de browser — er zit geen Loona-pagina of omleiding tussen, dus wat er live is op die link is precies wat de bezoeker ziet.

Veelgestelde vragen

Welke soorten links kan ik in een cv-QR-code zetten?

Elk openbaar webadres werkt: een persoonlijke portfoliowebsite, een LinkedIn-profiel, een Behance- of GitHub-pagina of een online opgeslagen PDF-cv. Plak de volledige link die je een werkgever zou willen laten openen.

De link naar mijn PDF-cv is erg lang. Scant de code nog steeds?

Ja. Een lange link maakt het QR-patroon dichter, dus print hem iets groter (minstens 2.5–3 cm breed) en testscan het geprinte exemplaar eenmaal. Als je een korter persoonlijk domein of een kortere profiellink hebt, scant dat nog gemakkelijker.

Waarom vraagt mijn Google Drive-cv-link bezoekers om toegang aan te vragen?

Dat is een Drive-deelinstelling, geen QR-probleem. Stel het bestand in op “Anyone with the link can view” voordat je de code genereert, anders botst elke bezoeker tegen een toestemmingsmuur.

Kan ik dezelfde code gebruiken voor zowel mijn cv als mijn portfolio?

Eén code bevat één link. Een gangbare aanpak is om te linken naar één pagina — zoals je LinkedIn-profiel of een persoonlijke site — die zelf doorlinkt naar zowel je cv als je portfolio.

Ik heb mijn portfolio op een nieuw adres opnieuw gebouwd. Volgt de oude geprinte code?

Nee. Een statische QR opent altijd het adres dat erin was gecodeerd. Als het oude adres omleidt naar het nieuwe, blijft de code werken; als de oude pagina eenvoudig wordt verwijderd, genereer en print dan een nieuwe code.
