Hoe je QR-codes in bulk maakt in 3 stappen

  1. Bereid je lijst voor — één code per regel. Zet de inhoud eerst (een link of elke tekst); voeg een komma en een kort label toe als je een bijschrift onder die code geprint wilt, bijvoorbeeld voor tafelnummers, planknamen of leerlingnamen. Of upload een .csv-bestand met dezelfde indeling.
  2. Klik op Genereren en controleer het vel. Tot 100 codes worden tegelijk gemaakt, in je exacte volgorde, duplicaten inbegrepen. Kies een groter codeformaat voor labels die van verder weg worden gescand.
  3. Print het vel of sla het op als PDF met de printknop (labels en inhouden printen bij elke code), of download individuele codes als PNG-bestanden. Testscan een paar codes van het geprinte vel — idealiter met onze scannerpagina — voordat je in hoeveelheid print.

Over deze bulk-QR-codegenerator

Generators voor enkele codes zijn prima totdat je veertig tafelkaartjes nodig hebt, een klassenset logincodes, planklabels voor een hele winkel of een evenementpas voor elke gast. Die een voor een maken — typen, genereren, downloaden, hernoemen, herhalen — verspilt een uur en nodigt uit tot verwisselingen. Deze tool verandert de lijst die je al hebt (in een spreadsheet, een notitiebestand of een CSV-export) in één keer in een afgewerkt, gelabeld vel met codes, in dezelfde volgorde als je lijst, dus code nummer 17 op het vel is regel 17 van je bestand.

Elke code is een normale statische Loona-QR-code: de inhoud zit in het patroon zelf, zonder Loona-server, korte link of account ertussen. Daarom verlopen bulkcodes die hier zijn gemaakt nooit en kunnen ze later niet worden uitgeschakeld — en daarom blijft je lijst privé, omdat de generatie volledig in je browser gebeurt.

Beste toepassingen van bulk-QR-codes

  • Restaurant- en cafétafelkaartjes — één menucode per tafel, gelabeld op tafelnummer
  • Klassensets — één code per leerling die linkt naar hun werkblad, portfolio of inlogpagina
  • Plank-, voorraadkamer- en magazijnlabels die elke locatie of elk artikel aan zijn record linken
  • Evenementpassen, bezoekersbadges en conferentiehand-outs met een code per gast
  • Productreeksen — één code per model die linkt naar zijn handleiding, garantie of nabestelpagina
  • Postercampagnes waarbij elke locatie zijn eigen traceerbare link krijgt (voeg per regel een andere ?utm_source= toe)

Printregels zijn hetzelfde als voor elke QR-code: houd sterk contrast (donkere codes op een lichte achtergrond), laat de witte stille zone rond elke code wanneer je het vel uit elkaar knipt en print codes niet kleiner dan ongeveer 2 cm breed voor telefoonscannen. Controleer bij de compacte instelling van 128 px het geprinte formaat op papier in plaats van het scherm te vertrouwen — de printpreview toont het echte vel.

Veelgestelde vragen

Is deze bulk-QR-codegenerator gratis?

Ja. Loona's bulk-QR-codegenerator is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel batches je maakt, voor persoonlijk of commercieel gebruik.

Hoeveel QR-codes kan ik tegelijk maken?

Tot 100 codes in één batch. Die limiet houdt je browser snel en het printbare vel beheersbaar; voer voor meer codes eenvoudig een nieuwe batch uit. Lege regels worden overgeslagen en dubbele regels worden behouden, dus twee identieke regels geven je twee kopieën van dezelfde code.

In welk formaat moet mijn lijst of CSV zijn?

Eén code per regel. Elke regel is ofwel alleen de inhoud (een link of tekst) of inhoud,komma,label — bijvoorbeeld https://example.com/menu,Table 4 menu. Labels worden onder elke code op het vel geprint. Standaard CSV-quotering werkt: omhul een veld met dubbele aanhalingstekens als de inhoud of het label zelf een komma bevat. Je kunt de lijst plakken of een .csv- of .txt-bestand uploaden, dat alleen op je apparaat wordt gelezen.

Verlopen mijn bulk-QR-codes?

Nee. Loona maakt statische QR-codes: de inhoud van elke code wordt rechtstreeks in zijn patroon gecodeerd, niet opgeslagen op een server of verborgen achter een betaalde omleiding. Geprinte codes blijven werken zolang hun bestemmingen actief blijven.

Is mijn lijst privé op deze bulkpagina?

Ja. Genereren gebeurt 100% in je browser met JavaScript. Je lijst en elk CSV-bestand worden lokaal gelezen en worden nooit verstuurd naar of opgeslagen op een server.

Hoe het werkt

De pagina leest je lijst regel voor regel met een kleine CSV-parser die gequoteerde velden begrijpt, zodat een label zoals “Smith, John” intact blijft. Voor elke regel bouwt hij één statische QR-code met dezelfde generatorbibliotheek als Loona's pagina's voor enkele codes, legt de codes in een raster in lijstvolgorde en print elk label en elke inhoud onder zijn code, zodat een geprint vel in één oogopslag tegen de originele lijst kan worden gecontroleerd. Niets wordt weggeoptimaliseerd of ingekort: de exacte tekst van elke regel is wat wordt gecodeerd, wat je kunt bewijzen door elke code op het vel te scannen met de Loona-scanner.

De methode: bereid de lijst voor (inhoud of inhoud,label per regel) → genereer → controleer het gelabelde vel → print het of sla het op als PDF, of download enkele PNG's → testscan voordat je in hoeveelheid print.

Uitgewerkt voorbeeld

Een lerares heeft voor elk van haar 28 leerlingen een code nodig die linkt naar de leespagina van die leerling. Ze exporteert twee kolommen uit haar klassenspreadsheet — de link en de naam van de leerling — plakt ze in deze pagina en genereert het vel. Elke geprinte code draagt de naam van de leerling eronder, zodat ze het vel uit elkaar kan knippen en de juiste code aan het juiste kind kan geven, en wanneer één code verloren gaat, herprint ze alleen die regel als één PNG in plaats van de hele set opnieuw te doen.

Veelgestelde vragen

Kan ik WiFi-gegevens of contactkaarten in een bulklijst zetten?

Gewone eenregelige inhoud werkt het beste: links en korte teksten. Een WiFi-payload (WIFI:T:WPA;S:…;P:…;;) is één regel, dus hij kan in bulk worden gegenereerd — let op: hij bevat alleen komma's in het wachtwoord als je er een instelt; omhul in dat geval het hele veld met aanhalingstekens. Inhoud met meerdere regels zoals volledige vCards kan niet één per regel worden uitgedrukt; gebruik daarvoor de speciale vCard-generator, een voor een.

Mijn CSV heeft een kopregel. Wat gebeurt er?

De kopregel zou een code worden die de koptekst bevat, wat gemakkelijk te spotten is op het gelabelde vel. Verwijder de kopregel vóór het genereren — de eerste regel moet je eerste echte code zijn.

Waarom is er een limiet van 100 codes?

Elke code wordt in je browser getekend; boven ongeveer honderd beginnen langzamere telefoons en laptops te haperen en wordt één geprint vel moeilijk te controleren. Een grote taak opsplitsen in batches van 100 houdt de generatie direct en het proeflezen realistisch.

Kan ik alle codes tegelijk als aparte bestanden downloaden?

Elke code op het vel heeft zijn eigen PNG-downloadknop en de printknop slaat het volledige gelabelde vel op als één PDF — wat meestal het nuttigere artefact is voor labels en hand-outs, omdat de labels met de codes meereizen. Browsers beperken pagina's om stil veel bestanden tegelijk op te slaan, dus er is bewust geen knop “download 100 files” die halverwege zou falen.

Eén regel is mislukt of ziet er verkeerd uit. Doe ik de batch opnieuw?

Nee. Herstel de regel, regenereer — genereren duurt een seconde — of maak alleen die ene code met de bijpassende enkelvoudige-codegenerator en print hem apart. De volgorde op het vel komt altijd overeen met de volgorde van je lijst, dus de buren van de vervanger vinden is makkelijk.
