Gratis FaceTime-QR-codegenerator

Eén scan start een FaceTime-gesprek — de familiecontactkaart, de supportbalie, de grootouderbestendige belknop.

Je QR-code

Vul het formulier in en je QR-code verschijnt hier.

100% privé: deze QR-code wordt in je browser aangemaakt. Niets wat je typt, wordt naar een server geüpload en de code verloopt nooit.

Hoe je er een maakt in 3 stappen

  1. Voer je gegevens in in het formulier hierboven — alleen de velden voor dit type, niets extra.
  2. Controleer de live preview en pas de kleur, achtergrond en het formaat (256, 512 of 1024 px) aan je merk of druk aan.
  3. Klik op PNG downloaden, testscan de code één keer met je telefoon en print of deel hem daarna waar je publiek ook is.

Over deze FaceTime

FaceTime-links gebruiken het facetime:-schema: scan de code op een iPhone, iPad of Mac en het gesprek naar dat Apple ID-e-mailadres of -nummer start. De killertoepassing is de geprinte contactkaart — op de koelkast, in het zorgpakket, bij de supportbalie — waar de persoon die belt geen contacten hoeft te zoeken, namen hoeft te spellen of iets hoeft te onthouden.

De voor de hand liggende limiet is alleen Apple: Android- en Windows-apparaten hebben geen FaceTime-handler. Print voor gemengde publieken een WhatsApp-code ernaast — de twee samen dekken effectief iedereen.

Beste toepassingen

  • Familiecontactkaarten
  • Verzorgings- en ondersteuningspakketten
  • Helpdesks van het Apple-ecosysteem
  • Verkoop- en advieskaarten

Zet de code precies waar de beslissing wordt genomen — op de tafel, de toonbank, de verpakking, de uitnodiging of het scherm — en geef mensen één korte instructieregel zoals “Scan to open” of “Scan to pay”. Print codes minstens 2 cm breed met een stille witte rand en sterk contrast, zodat oudere telefooncamera's ze snel lezen; gebruik voor posters die vanaf een afstand worden gescand het formaat 1024 px en print groter — een goede richtlijn is ongeveer een tiende van de scanafstand.

Hoe het werkt

De payload is facetime:CONTACT — het geregistreerde schema dat Apple-apparaten native afhandelen. Niets anders is nodig; het ontvangende apparaat lost het contact op.

Uitgewerkt voorbeeld

Een dochter print een koelkastkaart voor haar vader in het buitenland: één grote code, “Scan to call Ayesha”. Zondagse telefoontjes hebben geen herinneringsberichtje meer nodig.

Veelgestelde vragen

Is deze FaceTime-generator gratis?

Ja. Loona’s FaceTime-generator is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel codes je maakt, voor persoonlijk of commercieel gebruik.

Verloopt mijn QR-code?

Nee. Loona maakt statische QR-codes: je informatie wordt rechtstreeks in het QR-patroon zelf gecodeerd, niet opgeslagen op een server of verborgen achter een betaalde omleiding. Een code die je vandaag print, blijft werken zolang de bestemming zelf actief blijft.

Is mijn informatie privé op deze FaceTime-pagina?

Ja. Genereren gebeurt 100% in je browser met JavaScript. Niets wat je invoert, wordt verstuurd naar of opgeslagen op een server.

Video of audio?

Het facetime:-schema start standaard een videogesprek. Voor alleen audio gebruikt Apple facetime-audio: — als dat is wat je nodig hebt, genereer een tekstcode met het audioschema of gebruik de telefoongenerator.

Kan ik in plaats daarvan een FaceTime-weblink gebruiken?

Apples deelbare FaceTime-links (uit de app) werken ook op het web — plak zo'n link in de URL-generator voor een code die hem opent.
