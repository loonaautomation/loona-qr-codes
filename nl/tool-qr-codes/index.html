Heb je een QR-code in een foto? Geen tweede telefoon nodig

Als iemand je een QR-code als afbeelding stuurt — op WhatsApp bijvoorbeeld — heb je geen tweede telefoon nodig om hem te scannen. Bewaar de afbeelding, open onze gratis QR-codescanner, kies “Scannen vanaf een afbeelding” en selecteer die foto: de link erin opent direct op dezelfde telefoon.

Hoe je in 3 stappen een QR-code voor elke Loona-tool krijgt

  1. Vind je tool — typ zijn naam in het zoekvak, of tik op een websitenaam om alleen de tools van die site te bladeren.
  2. Je QR-code verschijnt direct met de naam van de tool eronder geprint, precies zoals de kant-en-klare codes op onze homepage.
  3. Klik op PNG downloaden, testscan hem één keer met je telefoon en print hem daarna voor je bureau, toonbank, klaslokaal of winkel.

Waarom een QR-code op een tool zetten?

Sommige Loona-tools worden elke dag door dezelfde mensen gebruikt: bankiers openen de Leeftijdscalculator voor elke klant, leraren hergebruiken de les- en studietools, winkeliers controleren salaris-, belasting- en factuurtools keer op keer. Elke keer een lang webadres typen is traag en foutgevoelig. Een geprinte QR-code op het bureau of de muur neemt dat allemaal weg — één scan, ongeveer twee seconden, en de exacte tool is open en klaar. Daarom werd de Leeftijdscalculator-QR-code op onze homepage zo populair en daarom biedt deze pagina nu dezelfde kant-en-klare code voor elke tool in het netwerk: alle 959, van Zakat- en EMI-calculators tot PDF-converters, afbeeldingscompressors en gebedstijdtools.

Elke code hier is een statische QR-code: het eigen adres van de tool wordt rechtstreeks in het patroon geschreven. Er is geen korte link, geen omleiding via een server van derden en geen abonnement dat kan verlopen — dus een code die je vandaag print, kan morgen niet worden uitgeschakeld. Als een tool ooit naar een nieuw adres verhuist, kom dan gewoon terug naar deze pagina en download een nieuwe code.

Printtips

  • Print de code minstens 2 cm breed; groter voor posters die vanaf een afstand worden gescand (een goede richtlijn is een tiende van de scanafstand).
  • Houd de witte rand rond de code — telefooncamera's hebben die stille zone nodig om hem snel te lezen.
  • De gedownloade PNG is hoge resolutie (880 px breed), dus hij blijft scherp op papier, stickers en banners.
  • Testscan het geprinte exemplaar altijd één keer met je eigen telefoon voordat je in grote aantallen print.

Veelgestelde vragen

Is het gratis om een QR-code voor een Loona-tool te maken?

Ja. Elke QR-code op deze pagina is volledig gratis — geen registratie, geen watermerk en geen limiet, voor persoonlijk of commercieel gebruik.

Verlopen deze QR-codes?

Nee. Elke code is een statische QR-code die het eigen webadres van de tool rechtstreeks in het patroon codeert. Er is geen omleiding en geen server ertussen, dus een geprinte code blijft werken zolang de tool zelf online blijft.

Kan ik deze QR-codes printen?

Ja. De download is een PNG in hoge resolutie met de naam van de tool onder de code geprint, klaar voor bureaus, toonbanken, klaslokalen en winkelramen. Print hem minstens 2 cm breed en testscan hem eenmaal voordat je in hoeveelheid print.

Welke tools zijn inbegrepen?

Allemaal: elke primaire tool en app in het hele Loona-netwerk — calculators, salaris- en belastingtools, PDF-tools, afbeeldingstools, teksttools, ontwikkelaarstools, ontwerp- en studietools, islamitische tools, urentools en meer — 959 tools en apps in één lijst.
