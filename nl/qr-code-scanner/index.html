    Over deze QR-code- en barcodescanner
    

    De meeste QR-sites alleen maken codes. Deze pagina doet het tegenovergestelde werk: hij leest ze. Dat is wat je nodig hebt wanneer een geprinte code geen leesbaar label heeft, wanneer een collega je een screenshot van een code stuurt in plaats van de link erin, wanneer je wilt controleren wat een van je eigen geprinte codes echt bevat vóór een grote printoplage, of wanneer een productbarcodenummer van een foto moet worden afgelezen.
    

    Hij werkt op twee manieren. De cameramodus gebruikt de BarcodeDetector-interface die in moderne Chromium-browsers is ingebouwd — dezelfde snelle, hardwarevriendelijke detectie die het systeem van je telefoon gebruikt — en rapporteert QR-codes en de gangbare eendimensionale barcodes. De afbeeldingsmodus is volledig zelfstandig: de opensource jsQR-bibliotheek decodeert QR-codes uit de pixels van je afbeelding en de opensource ZXing-bibliotheek decodeert barcodes (en elke QR-code die jsQR miste) uit dezelfde pixels. Beide draaien volledig in je browser, en daarom blijft deze scanner werken met gevoelige codes — WiFi-wachtwoorden, betaalcodes, privélinks — die je nooit naar de server van een vreemde zou willen uploaden.
    

    Beste toepassingen van deze scanner
    • Je eigen geprinte QR-codes controleren voordat je in grote aantallen print
    • De link openen die verborgen zit in een QR-code in een screenshot of foto die iemand je stuurde
    • Een WiFi-netwerknaam en -wachtwoord herstellen uit een WiFi-QR-codeafbeelding
    • Een vCard-contact uit een visitekaartje-QR-code opslaan als .vcf-bestand
    • EAN-13-, UPC-A-, Code 128- en Code 39-barcodenummers lezen uit product- en labelfoto's
    • Verifiëren dat een barcode die je genereerde terugscant naar exact het nummer dat je bedoelde
    • Een heel geprint vel of een map met codefoto's in batch controleren, met een CSV-export van elk resultaat
    • De coördinaten achter een geo:-locatiecode zien, of het adres achter een Bitcoin- of Ethereum-betaalcode, voordat je erop handelt
    

    Eerlijke grenzen, zodat je niet verrast wordt: camerascannen hangt af van een browserfunctie die Safari en Firefox nog niet hebben uitgebracht, dus op die browsers is alleen de afbeeldingsmodus beschikbaar — de pagina detecteert dit en vertelt het je eerlijk in plaats van stil te falen. En geen decoder kan een code lezen die te klein, wazig, gescheurd of met te weinig contrast in de foto is geprint; de foto opnieuw maken van dichterbij, recht van voren en in goed licht lost de meeste mislukte scans op.
    

    Veelgestelde vragen
    Is deze QR-code- en barcodescanner gratis?
    Ja. Loona's scanner is volledig gratis zonder registratie, zonder watermerk en zonder limiet op hoeveel codes je scant, voor persoonlijk of commercieel gebruik.
    Is mijn cameravideo of mijn foto privé op deze scannerpagina?
    Ja. Alles wordt gedecodeerd op je eigen apparaat, in je browser. Cameraframes worden nooit ergens heen gestuurd en geüploade afbeeldingen worden nooit naar een server gestuurd — het bestand wordt lokaal gelezen, lokaal gedecodeerd en je scangeschiedenis wordt alleen in het geheugen van deze pagina bewaard en verdwijnt wanneer je het tabblad sluit.
    Waarom werkt camerascannen niet in mijn browser?
    Live camerascannen gebruikt de BarcodeDetector-technologie die in Chrome, Edge en de meeste Android-browsers is ingebouwd. Safari en Firefox bevatten het nog niet, dus op die browsers wordt de cameraknop vervangen door een bericht dat je vraagt om in plaats daarvan afbeeldingsupload te gebruiken — een foto of screenshot uploaden werkt in elke moderne browser.
    Kan deze scanner een barcode van een foto lezen?
    Ja. De uploadmodus decodeert QR-codes uit afbeeldingen met de jsQR-bibliotheek en barcodes uit afbeeldingen met de ZXing-bibliotheek — inclusief EAN-13, UPC-A, Code 128 en Code 39 — evenals QR-codes die ZXing vindt en jsQR heeft gemist. Zeer kleine, wazige, beschadigde of contrastarme codes in een foto kunnen nog steeds falen; een scherpere, dichtere foto lost het meestal op.
    Welke soorten codes kan deze scanner lezen?
    Camerascannen (waar ondersteund) leest QR-codes plus de barcodeformaten die de BarcodeDetector van je browser biedt, gewoonlijk EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar en ITF. Afbeeldingsupload leest QR-codes en EAN-13-, UPC-A-, Code 128- en Code 39-barcodes en toont je het gedecodeerde type, de ruwe inhoud en slimme acties zoals een link openen of een contact opslaan.

    Hoe het werkt
    

    Een QR-code of barcode is slechts een patroon dat tekst codeert als lichte en donkere modules. Decoderen is het omgekeerde van genereren: zoek het patroon in de afbeelding, meet de modules, corrigeer fouten met de ingebouwde redundantie van de code en zet de bits weer om in tekens. jsQR doet dit voor QR-codes door de drie zoekvierkanten te lokaliseren en het raster te bemonsteren; ZXing doet het voor barcodes door rijen pixels over de balken te scannen en de breedtes te vergelijken met de regels van EAN, UPC, Code 128 of Code 39, inclusief het controleren van het laatste controlecijfer van retailbarcodes. In de cameramodus doet de eigen BarcodeDetector van je browser hetzelfde werk continu op de live videoframes totdat er een code is gevonden. In de batchmodus draaien dezelfde twee afbeeldingsdecoders één keer per bestand en wordt elk resultaat — bestandsnaam, formaat, type en gedecodeerde tekst — verzameld in een tabel die je als CSV kunt exporteren.
    

    De methode: kies camera of afbeelding → laat de decoder op het apparaat het patroon lezen → controleer het type, formaat en de ruwe inhoud → gebruik de slimme actie (openen, kopiëren, contact opslaan) → vind de scan op elk moment terug in de sessiegeschiedenis.

    Veelgestelde vragen
    

    Kan ik een code scannen vanaf een screenshot op dezelfde telefoon?
    

    Ja. Sla de screenshot op of deel hem in je foto-app en gebruik vervolgens de afbeeldingsupload hier en kies die screenshot. Kopieer op een computer eenvoudig de afbeelding en plak hem in deze pagina met Ctrl+V (of Cmd+V op een Mac) — geen bestand opslaan nodig.
    

    Het resultaat ziet eruit als WIFI:T:WPA;S:… — wat betekent dat?
    

    Dat is het standaard ruwe formaat in een WiFi-QR-code: T is het beveiligingstype, S is de netwerknaam (SSID) en P is het wachtwoord. Deze pagina toont die drie waarden ook apart boven de ruwe inhoud, zodat je ze niet zelf hoeft uit te zoeken.
    

    Hoe voeg ik een gescand contact toe aan mijn telefoon?
    

    Wanneer een scan een vCard is, verschijnt een actie “Download contact (.vcf)”. Download het bestand en open het — telefoons en computers bieden aan het op te slaan als contact met de naam, organisatie, telefoon, e-mail en website al ingevuld.
    

    Waarom decodeerde mijn foto niet?
    

    De gebruikelijke oorzaken zijn een code die klein is in een grote foto, onscherpte, schittering, een gescheurde of contrastarme print, of een screenshot die te strak rond de code is bijgesneden (decoders hebben de witte stille zone rond een code nodig). Snijd ruim bij, neem de foto dichterbij en recht van voren opnieuw en probeer het opnieuw.
    

    Moet ik een QR-code vertrouwen die ik in het openbaar heb gevonden?
    

    Scan hem hier eerst in plaats van met een app die resultaten automatisch opent: deze pagina alleen toont je de gedecodeerde inhoud en opent nooit iets vanzelf. Controleer of een link echt leidt waar zijn label belooft voordat je op “Open link” tikt — die ene gewoonte verslaat de meeste sticker-over-een-echte-code-oplichtingen.
