O tomto kódu Code 39

Code 39 (USS Code 39, Code 3 of 9) je nejstarší alfanumerický čárový kód stále v každodenním použití — vyvinutý v roce 1974 a udržovaný při životě štítky v automobilovém, obranném, zdravotnickém a vládním sektoru, které ho stanovily před desítkami let. Každý znak je devět prvků široký (pět čar, čtyři mezery, tři z nich široké), což ho činí tolerantním ke špatnému tisku, ale dlouhým na data, která nese.

Jeho abeceda je malá: velká písmena A–Z, číslice a několik symbolů. Je samoopravný (jediný špatný znak se málokdy ověří) a volitelnou kontrolní číslici modulo-43 lze přidat tam, kde ji přijímací systém očekává.

Nejlepší využití

  • Starší štítky v automobilovém a obranném průmyslu
  • Jmenovky a průkazy
  • Knihy v knihovnách (starší systémy)
  • Průmyslové přihrádky a sklady nářadí

Umístěte kód přesně tam, kde se rozhoduje — na stůl, pult, obal, pozvánku nebo obrazovku — a dejte lidem jeden krátký řádek pokynů, například „Naskenujte pro otevření“ nebo „Naskenujte pro zaplacení“. Tiskněte kódy alespoň 2 cm široké s tichým bílým okrajem a silným kontrastem, aby je starší fotoaparáty telefonů rychle přečetly; u plakátů skenovaných z dálky použijte velikost 1024 px a tiskněte větší — dobrým vodítkem je zhruba jedna desetina skenovací vzdálenosti.

Jak to funguje

Generátor automaticky převádí váš text na velká písmena a odmítá znaky mimo abecedu Code 39, přičemž pravidlo pojmenuje místo toho, aby nechal kodér tiše selhat. Hvězdička je znak start/stop a přidává ji kodér — nikdy ji nepište sami.

Vypracovaný příklad

Tovární sklad nářadí stále běží na systému Code 39 z devadesátých let (1990s). Nové štítky na nástěnky se tisknou z této stránky — PART-8841-A a podobné kódy — a staré skenery je přečtou napoprvé.

Často kladené otázky

Je tento generátor pro Code 39 zdarma?

Ano. Generátor Code 39 od Loony je zcela zdarma, bez registrace, bez vodoznaku a bez omezení počtu kódů, které vytvoříte, pro osobní i komerční použití.

Vyprší můj QR kód?

Ne. Loona vytváří statické QR kódy: vaše informace jsou zakódovány přímo v samotném vzoru QR kódu, neukládají se na server ani se neskrývají za placeným přesměrováním. Kód, který vytisknete dnes, bude fungovat tak dlouho, dokud samotný cíl zůstává aktivní.

Jsou mé informace na této stránce pro Code 39 soukromé?

Ano. Generování probíhá 100% ve vašem prohlížeči pomocí JavaScriptu. Nic, co zadáte, se neposílá na žádný server ani se na něm neukládá.

Proč se můj text malými písmeny změnil?

Code 39 nemá ve své standardní abecedě malá písmena, takže kodéry převádějí na velká písmena. Pokud na velikosti písmen záleží, použijte místo toho Code 128.

Potřebuje Code 39 kontrolní číslici?

Ne — je podle návrhu samoopravný. Kontrolní číslice modulo-43 existuje pro systémy, které o ni žádají, ale většina štítků Code 39 se tiskne bez ní.
