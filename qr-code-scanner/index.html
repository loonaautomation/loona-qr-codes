    About this QR code and barcode scanner
    

    Most QR sites only make codes. This page does the opposite job: it reads them. That is what you need when a printed code has no readable label, when a colleague sends you a screenshot of a code instead of the link inside it, when you want to check what one of your own printed codes actually contains before a big print run, or when a product barcode number has to be read off a photo.
    

    It works in two ways. Camera mode uses the BarcodeDetector interface built into modern Chromium browsers — the same fast, hardware-friendly detection your phone's system uses — and reports QR codes and the common one-dimensional barcodes. Image mode is fully self-contained: the open-source jsQR library decodes QR codes from the pixels of your image, and the open-source ZXing library decodes barcodes (and any QR code jsQR missed) from the same pixels. Both run entirely in your browser, which is why this scanner keeps working with sensitive codes — WiFi passwords, payment codes, private links — that you would never want to upload to a stranger's server.

    How it works
    

    A QR code or barcode is just a pattern that encodes text as light and dark modules. Decoding is the reverse of generating: find the pattern in the image, measure the modules, correct errors using the code's built-in redundancy, and turn the bits back into characters. jsQR does this for QR codes by locating the three finder squares and sampling the grid; ZXing does it for barcodes by scanning rows of pixels across the bars and matching the widths to the EAN, UPC, Code 128 or Code 39 rules, including verifying the final check digit of retail barcodes. In camera mode, your browser's own BarcodeDetector performs the same job continuously on the live video frames until a code is found. In batch mode, the same two image decoders run once per file and every result — filename, format, type and decoded text — is collected into a table you can export as CSV.
    

    The method: choose camera or image → let the on-device decoder read the pattern → check the type, format and raw content → use the smart action (open, copy, save contact) → find the scan again any time in the session history.

    Frequently asked questions
    

    Can I scan a code from a screenshot on the same phone?
    

    Yes. Save or share the screenshot into your photo app, then use the image upload here and pick that screenshot. On a computer, simply copy the image and paste it into this page with Ctrl+V (or Cmd+V on a Mac) — no file saving needed.
    

    The result looks like WIFI:T:WPA;S:… — what does that mean?
    

    That is the standard raw format inside a WiFi QR code: T is the security type, S is the network name (SSID) and P is the password. This page also shows those three values separately above the raw content, so you do not have to pick them out yourself.
    

    How do I add a scanned contact to my phone?
    

    When a scan is a vCard, a “Download contact (.vcf)” action appears. Download the file and open it — phones and computers offer to save it as a contact with the name, organisation, phone, email and website already filled in.
    

    Why did my photo not decode?
    

    The usual causes are a code that is tiny in a large photo, blur, glare, a torn or low-contrast print, or a screenshot cropped too tightly around the code (decoders need the white quiet zone around a code). Crop loosely, retake the photo closer and straight-on, and try again.
    

    Should I trust a QR code I found in public?
    

    Scan it here first instead of with an app that opens results automatically: this page only shows you the decoded content and never opens anything by itself. Check that a link really leads where its label promises before you tap “Open link” — that one habit defeats most sticker-over-a-real-code scams.
