How to find your X profile link or handle

On the X app: tap your profile picture, then tap your profile. Your handle is the @name under your display name, and your profile link is https://x.com/ followed by that handle — for example, the handle @hira_writes means the profile link https://x.com/hira_writes.

On a computer: sign in at x.com, click Profile in the left menu, and copy the address in your browser bar. That address is your profile link; paste it into the form above exactly as copied, or type only the part after x.com/.

Not sure of the spelling? Handles are easy to misremember, and a QR code made from a misspelled handle opens the wrong profile or no profile at all. Always copy the handle from your own profile page instead of typing it from memory, and test-scan the finished code before you print it.

Download, print and share your X QR Code

Format: this tool downloads a PNG file — honest and simple. It does not offer SVG, JPG or PDF export, a centre logo, or shaped dots. If you need a vector file for very large print, generate the code at 1024 px and print a test copy first; for cards, posters and packaging, the 1024 px PNG is sharp in normal use.

Print size: print the code at least 2 cm (about 0.8 in) wide for close-up scanning such as a business card, and bigger for anything scanned from a distance — a useful guide is about one tenth of the scanning distance, so a poster read from 1 metre away needs a code roughly 10 cm wide. Keep the quiet white border around the code, keep strong contrast (a dark code on a light background scans most reliably), and do not stretch or crop the image.

Add a caption: a bare code gets fewer scans. Put one short line under it — “Scan to follow on X” plus your @handle written out, so people who cannot scan can still type it.

Always test first: scan the downloaded PNG with your own phone, and ideally with both an iPhone and an Android phone, and confirm your profile — not someone else’s — opens, before printing in quantity.

Static QR Code — what that honestly means

Loona makes a static QR code: your profile link is encoded directly in the pattern. That is why it never expires, has no scan limit, and needs no account or server to keep working. The trade-offs are equally clear: a static code cannot be edited after printing (if you change your handle, print a new code) and it does not count or track scans. Services that offer editable, trackable “dynamic” codes route scans through their own server and usually need an account — useful for some campaigns, but the code then depends on that service staying active. For a profile link you print on a card or poster, most people prefer the static code that simply keeps working.
