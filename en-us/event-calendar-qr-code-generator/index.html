How it works

You enter the event title, the start and end date and time, and optionally a location and a description. The generator packages them as a calendar entry in the standard VEVENT format — the same format calendar apps themselves use — and encodes that text in the QR. When a guest scans the code, their phone recognizes the calendar data and offers to save the event, with its title, times, place and notes, straight into their calendar app. The code does not send invitations and does not collect RSVPs; it simply hands the event details to the scanner’s calendar.

Worked example

A couple adds an event QR to their wedding invitation: title “Ayesha & Daniyal — Wedding Reception”, start December 19, 2026 at 7:00 pm, end 11:00 pm, location “Pearl Continental Hall, Lahore”, description “Please arrive by 7 pm”. Guests scan the invitation once, tap Add to Calendar, and the reception sits in their phones with the venue attached — nobody has to type the date in or try to remember it weeks later.

Frequently asked questions

Does the guest need a special app to save the event?

No. Modern iPhone and Android cameras recognize calendar QR data and offer to add the event to the built-in calendar; some phones show the event details first so the guest can confirm.

Will guests get a reminder before the event?

The reminder comes from the guest’s own calendar settings: once the event is saved, their calendar app applies its usual default alert. The QR itself does not send reminders to anyone.

Can people RSVP through this QR code?

No. The code only carries the event details. If you need replies, put a form link or messaging link on the same invitation alongside it.

What if the time or venue changes after I print the invitations?

The printed code holds the old details and cannot be updated, so generate a new code and reprint — and tell your guests, because anyone who already saved the event keeps the old entry until they edit it.

Which time zone are the times in?

Enter the event’s local clock times exactly as they will happen at the venue. The code stores the times as given, without a time-zone marker, so guests see precisely the times you entered.

Can I make a code for an all-day or multi-day event?

Yes — set the start at the beginning of the first day and the end at the end of the last day, and the saved event will span those days in the calendar.
