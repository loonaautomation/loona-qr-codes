About this Resume / Portfolio QR Code

A resume QR links your printed CV or visiting card to your online resume, portfolio, LinkedIn or work samples, which are too rich for paper.

A graduate prints a resume QR at the top of her CV; the interviewer scans and sees her full portfolio instantly. That is the real problem a Resume / Portfolio QR Code solves: it removes typing, searching and mistakes, and replaces them with a single scan that takes about two seconds. On Loona, the code is generated locally in your browser as a static QR, which means the data lives inside the pattern itself. There is no Loona server in the middle, no short link that can be switched off, and no trial period after which your printed material stops working — a common and expensive problem with many so-called free QR websites.

Best uses of a Resume / Portfolio QR Code

  • Job seekers and fresh graduates
  • Designers, developers and writers
  • Freelancers pitching clients
  • Students and interns

In every case the rule is the same: put the QR code exactly where the decision is made — on the table, the counter, the packaging, the invitation or the screen — and give people one short line of instruction such as “Scan to connect” or “Scan to pay”. Codes should be printed at least 2 cm wide, with a quiet white border around them and strong contrast between the QR color and the background, so older phone cameras can read them quickly. For posters that are scanned from a distance, use the 1024 px size and print the code bigger: a good guide is roughly one tenth of the scanning distance.

You can use Loona QR codes freely for commercial work — menus, business cards, client projects, packaging and signage — with no attribution required. Because generation is private and offline-capable once the page has loaded, sensitive details such as WiFi passwords and payment numbers never leave your device. If your information changes later, remember that a static QR cannot be edited after printing, so generate a fresh code and replace the old print; the benefit of that trade-off is a code that can never be held hostage, expire, or stop working because a company closed down.

Frequently asked questions

What kinds of links can I put in a resume QR code?

Any public web address works: a personal portfolio website, a LinkedIn profile, a Behance or GitHub page, or a PDF resume stored online. Paste the full link you would want an employer to open.

The link to my PDF resume is very long. Will the code still scan?

Yes. A long link makes the QR pattern denser, so print it a little larger (at least 2.5–3 cm wide) and test-scan the printed copy once. If you have a shorter personal domain or profile link, that scans even more easily.

Why does my Google Drive resume link ask visitors to request access?

That is a Drive sharing setting, not a QR problem. Set the file to “Anyone with the link can view” before generating the code, otherwise every visitor hits a permission wall.

Can I use the same code for both my resume and my portfolio?

One code holds one link. A common approach is to link to a single page — such as your LinkedIn profile or a personal site — that itself links onward to both your resume and your portfolio.

I rebuilt my portfolio at a new address. Does the old printed code follow?

No. A static QR always opens the address that was encoded in it. If the old address redirects to the new one, the code keeps working; if the old page is simply deleted, generate and print a fresh code.
