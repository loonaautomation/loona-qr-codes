বিনামূল্যে GitHub QR Code Generator

একটি GitHub প্রোফাইল বা রিপোজিটরি খুলতে স্ক্যান করুন। কোনো সাইনআপ নেই, কোনো ওয়াটারমার্ক নেই, এবং আপনার QR কোডের মেয়াদ কখনো শেষ হয় না।

আপনার QR কোড

ফর্মটি পূরণ করুন এবং আপনার QR কোড এখানে দেখা যাবে।

100% ব্যক্তিগত: এই QR কোডটি আপনার ব্রাউজারের ভেতরেই তৈরি হয়। আপনি যা লেখেন তার কিছুই কোনো সার্ভারে আপলোড হয় না, এবং কোডটির মেয়াদ কখনো শেষ হয় না।

3টি ধাপে একটি GitHub QR Code কীভাবে তৈরি করবেন

  1. আপনার বিবরণ লিখুন উপরের ফর্মে — শুধু এই QR ধরনের জন্য ক্ষেত্রগুলো, অতিরিক্ত কিছু নয়।
  2. লাইভ প্রিভিউ যাচাই করুন এবং আপনার ব্র্যান্ড বা ছাপার সঙ্গে মেলাতে QR রং, পটভূমির রং ও আকার (256, 512 বা 1024 px) কাস্টমাইজ করুন।
  3. Download PNG-তে ক্লিক করুন, ফোন দিয়ে কোডটি একবার টেস্ট-স্ক্যান করুন, তারপর ছাপান বা আপনার দর্শক যেখানে আছেন সেখানে শেয়ার করুন।

এই GitHub QR Code সম্পর্কে

একটি GitHub QR কোড এক স্ক্যানে একজন ডেভেলপারের প্রোফাইল বা রিপোজিটরি খোলে, ছাপা উপকরণ ও স্লাইডকে লাইভ কোডের সঙ্গে যুক্ত করে।

একটি GitHub QR Code আসলে যে সমস্যার সমাধান করে তা হলো এই: এটি লেখা, খোঁজা ও ভুল দূর করে, এবং তার বদলে একটি মাত্র স্ক্যান দেয় যা প্রায় দুই সেকেন্ড সময় নেয়। Loona-তে কোডটি স্ট্যাটিক QR হিসেবে আপনার ব্রাউজারে স্থানীয়ভাবে তৈরি হয়, যার অর্থ ডেটা প্যাটার্নটির ভেতরেই থাকে। মাঝখানে কোনো Loona সার্ভার নেই, বন্ধ হয়ে যেতে পারে এমন কোনো সংক্ষিপ্ত লিঙ্ক নেই, এবং এমন কোনো পরীক্ষামূলক সময়কাল নেই যার পরে আপনার ছাপা উপকরণ কাজ করা বন্ধ করে দেবে — তথাকথিত অনেক বিনামূল্যের QR ওয়েবসাইটের একটি সাধারণ ও ব্যয়বহুল সমস্যা।

একটি GitHub QR Code-এর সেরা ব্যবহার

  • ডেভেলপারদের রিজিউমে ও পোর্টফোলিও
  • সম্মেলনের আলোচনা ও স্লাইড
  • ওপেন-সোর্স প্রকল্পের স্টিকার ও README
  • হ্যাকাথন ও মিটআপ নেটওয়ার্কিং

প্রতিটি ক্ষেত্রে নিয়ম একই: QR কোডটি ঠিক যেখানে সিদ্ধান্ত নেওয়া হয় সেখানে রাখুন — টেবিলে, কাউন্টারে, প্যাকেজিংয়ে, আমন্ত্রণে বা পর্দায় — এবং মানুষকে একটি ছোট নির্দেশনার লাইন দিন যেমন “Scan to connect” বা “Scan to pay”। কোড কমপক্ষে 2 cm চওড়া ছাপানো উচিত, চারপাশে একটি নীরব সাদা সীমানা ও QR রং ও পটভূমির মধ্যে শক্তিশালী বৈপরীত্য সহ, যাতে পুরনো ফোন ক্যামেরা দ্রুত সেগুলো পড়তে পারে। দূর থেকে স্ক্যান করা পোস্টারের জন্য, 1024 px আকার ব্যবহার করুন এবং কোডটি বড় ছাপান: একটি ভালো নির্দেশিকা হলো স্ক্যানিং দূরত্বের প্রায় এক-দশমাংশ।

আপনি Loona QR কোড বাণিজ্যিক কাজের জন্য অবাধে ব্যবহার করতে পারেন — মেনু, ব্যবসা কার্ড, ক্লায়েন্ট প্রকল্প, প্যাকেজিং এবং সাইনেজ — কোনো কৃতিত্বের প্রয়োজন ছাড়া। তৈরি করা ব্যক্তিগত এবং পৃষ্ঠাটি লোড হওয়ার পরে অফলাইন-সক্ষম হওয়ায়, WiFi পাসওয়ার্ড ও পেমেন্ট নম্বরের মতো সংবেদনশীল বিবরণ কখনো আপনার ডিভাইস ছাড়ে না। আপনার তথ্য পরে বদলালে, মনে রাখবেন একটি স্ট্যাটিক QR ছাপার পরে সম্পাদনা করা যায় না, তাই একটি নতুন কোড তৈরি করুন এবং পুরনো ছাপাটি বদলে দিন; সেই আপসের সুবিধা হলো এমন একটি কোড যা কখনো জিম্মি হতে পারে না, মেয়াদ শেষ হতে পারে না, বা একটি কোম্পানি বন্ধ হয়ে যাওয়ায় কাজ করা বন্ধ করতে পারে না।

প্রায়শই জিজ্ঞাসিত প্রশ্নাবলি

এই GitHub QR Code জেনারেটর কি বিনামূল্যে?

হ্যাঁ। Loona-এর GitHub QR Code জেনারেটরটি সম্পূর্ণ বিনামূল্যে, কোনো সাইনআপ ছাড়া, কোনো ওয়াটারমার্ক ছাড়া এবং আপনি কত কোড তৈরি করেন তাতে কোনো সীমা ছাড়া, ব্যক্তিগত বা বাণিজ্যিক ব্যবহারের জন্য।

আমার GitHub QR Code-এর মেয়াদ কি শেষ হবে?

না। Loona স্ট্যাটিক QR কোড তৈরি করে: আপনার তথ্য সরাসরি QR প্যাটার্নটির ভেতরেই এনকোড করা হয়, একটি সার্ভারে সংরক্ষিত নয় বা একটি অর্থের বিনিময়ে পুনর্নির্দেশের পেছনে লুকানো নয়। আজ ছাপানো একটি কোড গন্তব্যটি নিজে (উদাহরণস্বরূপ আপনার ওয়েবসাইট বা নম্বর) সক্রিয় থাকা পর্যন্ত কাজ করতে থাকবে।

আমি তৈরি করা GitHub QR Code কীভাবে ব্যবহার করব?

ফর্মটি পূরণ করুন, লাইভ প্রিভিউ যাচাই করুন, আপনার রং ও আকার বেছে নিন, তারপর Download PNG-তে ক্লিক করুন। এটি ছাপান বা ডিজিটালি শেয়ার করুন, এবং বেশি পরিমাণে ছাপানোর আগে সবসময় আপনার নিজের ফোন দিয়ে একবার টেস্ট-স্ক্যান করুন।

এই GitHub QR Code পৃষ্ঠায় আমার তথ্য কি ব্যক্তিগত?

হ্যাঁ। তৈরি করা 100% আপনার ব্রাউজারে JavaScript ব্যবহার করে ঘটে। আপনি যা দেন \u2014 পাসওয়ার্ড, নম্বর বা লিঙ্ক \u2014 কিছুই কোনো সার্ভারে পাঠানো বা সংরক্ষণ করা হয় না।

এটি কীভাবে কাজ করে

এই জেনারেটরটি একটি GitHub ঠিকানা — প্রোফাইলের জন্য github.com/username, বা আপনার পেস্ট করা যেকোনো সম্পূর্ণ রিপোজিটরি লিঙ্ক — একটি স্ট্যান্ডার্ড QR কোডে এনকোড করে। স্ক্যান করলে প্রোফাইল বা রিপো GitHub অ্যাপ বা ব্রাউজারে খোলে, যেখানে দর্শনার্থীরা কোড পড়তে, প্রকল্পে তারকা দিতে বা ডেভেলপারকে অনুসরণ করতে পারেন।

পদ্ধতিটি: আপনার GitHub ব্যবহারকারীর নাম বা একটি রিপোজিটরির লিঙ্ক কপি করুন → জেনারেটরে পেস্ট করুন → QRটি PNG হিসেবে ডাউনলোড করুন → আপনার রিজিউম, স্লাইড, স্টিকার বা প্রকল্প পৃষ্ঠায় যোগ করুন।

কাজ করা উদাহরণ

একটি ডেভেলপার মিটআপে, একজন বক্তা একটি স্লাইড দিয়ে তার বক্তৃতা শেষ করেন: প্রকল্পের নাম এবং একটি GitHub QR কোড। দর্শকরা তাদের আসন থেকে স্ক্যান করেন, রিপোজিটরিটি তাদের ফোনে খুলে যায়, এবং প্রশ্ন শুরু হওয়ার আগেই প্রকল্পটি চল্লিশটি তারা পেয়ে যায় — মুখে বলা একটি "check out my GitHub" যা কখনো তৈরি করতে পারত তার চেয়ে অনেক বেশি।

প্রায়শই জিজ্ঞাসিত প্রশ্নাবলি

আমি কি সরাসরি একটি রিপোজিটরির সঙ্গে যুক্ত করতে পারি, আমার প্রোফাইলের নয়?

হ্যাঁ। একটি ব্যবহারকারীর নামের বদলে রিপোজিটরির সম্পূর্ণ লিঙ্ক (github.com/owner/repo) পেস্ট করুন এবং কোডটি সেই রিপো খোলে। একটি প্রকল্প সম্পর্কে আলোচনা স্লাইড ও স্টিকারের জন্য এটি সেরা পছন্দ।

কোডটি কি ব্যক্তিগত রিপোজিটরির জন্য কাজ করে?

কোডটি লিঙ্কটি খুলবে, কিন্তু শুধু যাদের একটি ব্যক্তিগত রিপোতে অ্যাক্সেস আছে তারাই সাইন ইন করার পরে তা দেখতে পাবেন। প্রকাশ্যে ছাপার জন্য, সর্বজনীন প্রোফাইল ও রিপোজিটরির লিঙ্ক দিন।

আমি কি এটি আমার রিজিউমেতে ব্যবহার করতে পারি?

হ্যাঁ — এটি একটি জনপ্রিয়, নিয়োগকারী-বান্ধব ছোঁয়া। আপনার প্রোফাইল ভালোভাবে রাখা থাকলে তার লিঙ্ক দিন, অথবা আপনার সেরা একক প্রকল্পের, এবং সবসময় প্রথমে নিজে ছাপানো রিজিউমটি পরীক্ষা-স্ক্যান করুন।
