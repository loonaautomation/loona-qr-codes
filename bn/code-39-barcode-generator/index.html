বিনামূল্যে Code 39 Barcode Generator

সেকেন্ডে একটি মান-সঠিক Code 39 বারকোড তৈরি করুন। বিনামূল্যে, কোনো সাইনআপ নেই, কোনো ওয়াটারমার্ক নেই — আপনার ব্রাউজারে ব্যক্তিগতভাবে তৈরি।

শুধু A-Z, 0-9, ফাঁকা জায়গা এবং - . $ / + %। ছোট হাতের অক্ষর বড় হাতের অক্ষরে রূপান্তরিত হয়।

আপনার বারকোড

100% ব্যক্তিগত: বারকোডটি আপনার ব্রাউজারের ভেতরেই আঁকা হয়। আপনি যা লেখেন তার কিছুই কোনো সার্ভারে আপলোড হয় না।

3টি ধাপে একটি কীভাবে তৈরি করবেন

  1. আপনার বিবরণ লিখুন উপরের ফর্মে — শুধু এই ধরনের জন্য ক্ষেত্রগুলো, অতিরিক্ত কিছু নয়।
  2. লাইভ প্রিভিউ যাচাই করুন এবং আপনার ব্র্যান্ড বা ছাপার সঙ্গে মেলাতে রং, পটভূমি ও আকার (256, 512 বা 1024 px) কাস্টমাইজ করুন।
  3. Download PNG-তে ক্লিক করুন, ফোন দিয়ে কোডটি একবার টেস্ট-স্ক্যান করুন, তারপর ছাপান বা আপনার দর্শক যেখানে আছেন সেখানে শেয়ার করুন।

এই Code 39 সম্পর্কে

Code 39 (USS Code 39, Code 3 of 9) হলো দৈনন্দিন ব্যবহারে থাকা সবচেয়ে পুরনো ইংরেজি-সংখ্যার বারকোড — 1974 সালে তৈরি এবং কয়েক দশক আগে এটি নির্দিষ্ট করা মোটরগাড়ি, প্রতিরক্ষা, স্বাস্থ্যসেবা ও সরকারি লেবেল দ্বারা জীবিত। প্রতিটি অক্ষর নয়টি উপাদান চওড়া (পাঁচটি দণ্ড, চারটি ফাঁক, তার তিনটি চওড়া), যা এটিকে খারাপ ছাপার প্রতি সহনশীল করে কিন্তু বহন করা ডেটার তুলনায় লম্বা করে।

এর বর্ণমালা ছোট: বড় হাতের অক্ষর A–Z, সংখ্যা এবং কয়েকটি প্রতীক। এটি স্ব-যাচাইকারী (একটি মাত্র খারাপ অক্ষর কদাচিৎ যাচাই হয়), এবং গ্রহণকারী সিস্টেম যেখানে একটি আশা করে সেখানে একটি ঐচ্ছিক মডুলো-43 যাচাই সংখ্যা যোগ করা যায়।

সেরা ব্যবহার

  • মোটরগাড়ি ও প্রতিরক্ষা ঐতিহ্যবাহী লেবেল
  • নাম ব্যাজ ও ID কার্ড
  • লাইব্রেরির বই (পুরনো সিস্টেম)
  • শিল্প বিন ও টুল ক্রিব

কোডটি ঠিক যেখানে সিদ্ধান্ত নেওয়া হয় সেখানে রাখুন — টেবিলে, কাউন্টারে, প্যাকেজিংয়ে, আমন্ত্রণে বা পর্দায় — এবং মানুষকে একটি ছোট নির্দেশনার লাইন দিন যেমন “Scan to open” বা “Scan to pay”। কোড কমপক্ষে 2 cm চওড়া একটি নীরব সাদা সীমানা ও শক্তিশালী বৈপরীত্য দিয়ে ছাপান যাতে পুরনো ফোন ক্যামেরা দ্রুত সেগুলো পড়ে; দূর থেকে স্ক্যান করা পোস্টারের জন্য, 1024 px আকার ব্যবহার করুন এবং বড় ছাপান — একটি ভালো নির্দেশিকা হলো স্ক্যানিং দূরত্বের প্রায় এক-দশমাংশ।

এটি কীভাবে কাজ করে

জেনারেটরটি আপনার পাঠ্যকে স্বয়ংক্রিয়ভাবে বড় হাতের অক্ষরে রূপান্তরিত করে এবং Code 39 বর্ণমালার বাইরের অক্ষর প্রত্যাখ্যান করে, এনকোডারকে নিঃশব্দে ব্যর্থ হতে দেওয়ার বদলে নিয়মটির নাম উল্লেখ করে। একটি তারকাচিহ্ন হলো শুরু/শেষ অক্ষর এবং তা এনকোডার যোগ করে — নিজে কখনো টাইপ করবেন না।

কাজ করা উদাহরণ

একটি কারখানার টুল ক্রিব এখনো 1990-এর দশকের Code 39 ব্যবস্থা চালায়। এই পৃষ্ঠা থেকে নতুন শ্যাডো-বোর্ড লেবেল ছাপানো হয় — PART-8841-A এবং একই ধরনের কোড — এবং পুরনো স্ক্যানারগুলো প্রথমবারেই সেগুলো পড়ে।

প্রায়শই জিজ্ঞাসিত প্রশ্নাবলি

এই Code 39 জেনারেটর কি বিনামূল্যে?

হ্যাঁ। Loona-এর Code 39 জেনারেটরটি সম্পূর্ণ বিনামূল্যে, কোনো সাইনআপ ছাড়া, কোনো ওয়াটারমার্ক ছাড়া এবং আপনি কত কোড তৈরি করেন তাতে কোনো সীমা ছাড়া, ব্যক্তিগত বা বাণিজ্যিক ব্যবহারের জন্য।

আমার QR কোডের মেয়াদ কি শেষ হবে?

না। Loona স্ট্যাটিক QR কোড তৈরি করে: আপনার তথ্য সরাসরি QR প্যাটার্নটির ভেতরেই এনকোড করা হয়, একটি সার্ভারে সংরক্ষিত নয় বা একটি অর্থের বিনিময়ে পুনর্নির্দেশের পেছনে লুকানো নয়। আজ ছাপানো একটি কোড গন্তব্যটি নিজে সক্রিয় থাকা পর্যন্ত কাজ করতে থাকবে।

এই Code 39 পৃষ্ঠায় আমার তথ্য কি ব্যক্তিগত?

হ্যাঁ। তৈরি করা 100% আপনার ব্রাউজারে JavaScript ব্যবহার করে ঘটে। আপনি যা দেন কিছুই কোনো সার্ভারে পাঠানো বা সংরক্ষণ করা হয় না।

আমার ছোট হাতের পাঠ্য কেন বদলে গেল?

Code 39-এর সাধারণ বর্ণমালায় ছোট হাতের অক্ষর নেই, তাই এনকোডারগুলো বড় হাতের অক্ষরে রূপান্তর করে। বড়-ছোট হাতের পার্থক্য গুরুত্বপূর্ণ হলে, তার বদলে Code 128 ব্যবহার করুন।

Code 39-এর কি একটি যাচাই সংখ্যা দরকার?

না — এটি নকশা অনুযায়ী স্ব-যাচাইকারী। যেসব সিস্টেম এটি চায় তাদের জন্য একটি মডুলো-43 যাচাই সংখ্যা আছে, কিন্তু বেশিরভাগ Code 39 লেবেল একটি ছাড়াই ছাপানো হয়।
