Leitor de Códigos QR & Códigos de Barras Grátis

Aponte a sua câmara a um código QR ou a um código de barras, ou largue uma fotografia ou captura de ecrã — o código é descodificado aqui mesmo, no seu dispositivo. Sem registo, sem aplicação para instalar e nada do que lê é alguma vez carregado. Também pode descodificar em lote muitas imagens de códigos de uma vez e exportar os resultados como um ficheiro CSV.

Ler com a sua câmara

A leitura por câmara em direto utiliza o rápido BarcodeDetector integrado no Chrome, no Edge e na maioria dos navegadores Android e lê códigos QR mais códigos de barras comuns (EAN-13, UPC-A, Code 128, Code 39 e muito mais, consoante o seu navegador).

Privacidade: as imagens da câmara são processadas apenas neste dispositivo e nunca saem do seu navegador. Nenhum vídeo é gravado, enviado ou guardado.

Carregue uma fotografia, largue um ficheiro de imagem aqui ou cole uma captura de ecrã (Ctrl+V / Cmd+V). Os códigos QR nas imagens são descodificados com jsQR e os códigos de barras nas imagens com ZXing — EAN-13, UPC-A, Code 128 e Code 39 incluídos.

    Acerca deste leitor de códigos QR e de códigos de barras
    

    A maioria dos sites de QR apenas make códigos. Esta página faz o trabalho oposto: lê-os. É disso que precisa quando um código impresso não tem etiqueta legível, quando um colega lhe envia uma captura de ecrã de um código em vez da ligação dentro dele, quando quer verificar o que um dos seus próprios códigos impressos contém realmente antes de uma grande tiragem, ou quando um número de código de barras de produto tem de ser lido a partir de uma fotografia.
    

    Funciona de duas formas. O modo de câmara utiliza a interface BarcodeDetector integrada nos navegadores Chromium modernos — a mesma deteção rápida e amiga do hardware que o sistema do seu telemóvel utiliza — e comunica códigos QR e os códigos de barras unidimensionais comuns. O modo de imagem é totalmente autónomo: a biblioteca de código aberto jsQR descodifica códigos QR a partir dos píxeis da sua imagem e a biblioteca de código aberto ZXing descodifica códigos de barras (e qualquer código QR que o jsQR tenha falhado) a partir dos mesmos píxeis. Ambos correm inteiramente no seu navegador, razão pela qual este leitor continua a funcionar com códigos sensíveis — palavras-passe Wi-Fi, códigos de pagamento, ligações privadas — que nunca quereria carregar para o servidor de um estranho.
    

    Melhores utilizações deste leitor
    • Verificar os seus próprios códigos QR impressos antes de imprimir em quantidade
    • Abrir a ligação escondida dentro de um código QR numa captura de ecrã ou numa fotografia que alguém lhe enviou
    • Recuperar um nome de rede WiFi e uma palavra-passe a partir de uma imagem de código QR WiFi
    • Guardar um contacto vCard a partir de um código QR de cartão de visita como um ficheiro .vcf
    • Ler números de códigos de barras EAN-13, UPC-A, Code 128 e Code 39 a partir de fotografias de produtos e rótulos
    • Verificar se um código de barras que gerou se lê de volta exatamente com o número que pretendia
    • Verificação em lote de uma folha impressa inteira ou de uma pasta de fotografias de códigos, com uma exportação CSV de cada resultado
    • Ver as coordenadas por trás de um código de localização geo:, ou o endereço por trás de um código de pagamento Bitcoin ou Ethereum, antes de agir sobre eles
    

    Limites honestos, para que não seja surpreendido: a leitura por câmara depende de uma funcionalidade do navegador que o Safari e o Firefox ainda não lançaram, pelo que nesses navegadores só está disponível o modo de imagem — a página deteta isto e diz-lhe claramente, em vez de falhar silenciosamente. E nenhum descodificador consegue ler um código demasiado pequeno, desfocado, rasgado ou impresso com contraste insuficiente na fotografia; voltar a tirar a fotografia mais perto, de frente e com boa luz resolve a maioria das leituras falhadas.
    

    Perguntas Frequentes
    Este leitor de códigos QR e de códigos de barras é grátis?
    Sim. O leitor da Loona é completamente gratuito, sem registo, sem marca de água e sem limite para o número de códigos que lê, para utilização pessoal ou comercial.
    O vídeo da minha câmara ou a minha fotografia é privado nesta página de leitor?
    Sim. Tudo é descodificado no seu próprio dispositivo, dentro do seu navegador. Os fotogramas da câmara nunca são enviados para lado nenhum e as imagens carregadas nunca são enviadas para um servidor — o ficheiro é lido localmente, descodificado localmente, e o seu histórico de leituras é mantido apenas na memória desta página e desaparece quando fecha o separador.
    Por que não funciona a leitura pela câmara no meu navegador?
    A leitura por câmara em direto utiliza a tecnologia BarcodeDetector integrada no Chrome, no Edge e na maioria dos navegadores Android. O Safari e o Firefox ainda não a incluem, pelo que nesses navegadores o botão da câmara é substituído por uma mensagem a pedir-lhe que utilize antes o carregamento de imagens — carregar uma fotografia ou captura de ecrã funciona em todos os navegadores modernos.
    Este leitor pode ler um código de barras a partir de uma fotografia?
    Sim. O modo de carregamento descodifica códigos QR a partir de imagens com a biblioteca jsQR e códigos de barras a partir de imagens com a biblioteca ZXing — incluindo EAN-13, UPC-A, Code 128 e Code 39 — bem como códigos QR que o ZXing encontra e que o jsQR falhou. Códigos muito pequenos, desfocados, danificados ou de baixo contraste numa fotografia podem ainda falhar; uma fotografia mais nítida e mais próxima resolve-o normalmente.
    Que tipos de códigos pode este leitor ler?
    A leitura por câmara (onde suportada) lê códigos QR mais os formatos de código de barras que o BarcodeDetector do seu navegador oferece, normalmente EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar e ITF. O carregamento de imagens lê códigos QR e códigos de barras EAN-13, UPC-A, Code 128 e Code 39 e mostra-lhe o tipo descodificado, o conteúdo bruto e ações inteligentes, como abrir uma ligação ou guardar um contacto.

    Como funciona
    

    Um código QR ou um código de barras é apenas um padrão que codifica texto em módulos claros e escuros. Descodificar é o inverso de gerar: encontrar o padrão na imagem, medir os módulos, corrigir erros utilizando a redundância integrada do código e voltar a transformar os bits em carateres. O jsQR faz isto para códigos QR, localizando os três quadrados de posicionamento e amostrando a grelha; o ZXing faz isto para códigos de barras, lendo linhas de píxeis ao longo das barras e comparando as larguras com as regras EAN, UPC, Code 128 ou Code 39, incluindo a verificação do dígito de controlo final dos códigos de barras de retalho. No modo de câmara, o BarcodeDetector do seu próprio navegador executa o mesmo trabalho continuamente sobre as imagens de vídeo em direto até ser encontrado um código. No modo em lote, os mesmos dois descodificadores de imagem executam uma vez por ficheiro e cada resultado — nome do ficheiro, formato, tipo e texto descodificado — é recolhido numa tabela que pode exportar como CSV.
    

    O método: escolha câmara ou imagem → deixe o descodificador no dispositivo ler o padrão → verifique o tipo, o formato e o conteúdo bruto → utilize a ação inteligente (abrir, copiar, guardar contacto) → encontre a leitura novamente a qualquer momento no histórico da sessão.

    Perguntas frequentes
    

    Posso ler um código a partir de uma captura de ecrã no mesmo telemóvel?
    

    Sim. Guarde ou partilhe a captura de ecrã na sua aplicação de fotografias e depois utilize aqui o carregamento de imagem e escolha essa captura de ecrã. Num computador, basta copiar a imagem e colá-la nesta página com Ctrl+V (ou Cmd+V num Mac) — não é preciso guardar nenhum ficheiro.
    

    O resultado tem o aspeto de WIFI:T:WPA;S:… — o que significa isso?
    

    Esse é o formato bruto padrão dentro de um código QR WiFi: T é o tipo de segurança, S é o nome da rede (SSID) e P é a palavra-passe. Esta página também mostra esses três valores separadamente acima do conteúdo bruto, para que não tenha de os extrair sozinho.
    

    Como adiciono um contacto lido ao meu telemóvel?
    

    Quando uma leitura é um vCard, aparece uma ação “Transferir contacto (.vcf)”. Transfira o ficheiro e abra-o — os telemóveis e computadores oferecem-se para o guardar como contacto com o nome, a organização, o telefone, o correio eletrónico e o site já preenchidos.
    

    Por que não foi a minha fotografia descodificada?
    

    As causas habituais são um código minúsculo numa fotografia grande, desfocagem, brilho, uma impressão rasgada ou de baixo contraste, ou uma captura de ecrã recortada demasiado justa à volta do código (os descodificadores precisam da zona de silêncio branca à volta de um código). Recorte com folga, volte a tirar a fotografia mais perto e de frente e tente novamente.
    

    Devo confiar num código QR que encontrei em público?
    

    Leia-o aqui primeiro, em vez de com uma aplicação que abre os resultados automaticamente: esta página apenas mostra o conteúdo descodificado e nunca abre nada por si só. Verifique se uma ligação conduz realmente para onde a sua etiqueta promete antes de tocar em “Abrir ligação” — esse único hábito derrota a maioria das burlas de autocolante sobre um código real.
