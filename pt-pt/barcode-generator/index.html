Como criar um código de barras em 3 passos

  1. Escreva o conteúdo e escolha o tipo de código de barras. Para EAN-13, UPC-A e ITF-14, introduza o número sem o seu último dígito de controlo — o gerador calcula-o e adiciona-o, ou verifica-o se escrever o número completo.
  2. Verifique a pré-visualização em direto e ajuste a cor das barras, o fundo e a altura. Mantenha um contraste forte: barras escuras sobre um fundo claro leem-se melhor.
  3. Transfira o PNG ou o SVG, imprima-o e faça uma leitura de teste com uma aplicação de telemóvel ou um leitor antes de imprimir em quantidade. O SVG mantém-se perfeitamente nítido em qualquer tamanho e é o melhor para impressão profissional.

Acerca dos códigos de barras e dos cinco tipos

Um código de barras transforma um código curto num padrão de barras que um leitor lê numa fração de segundo. Trabalhos diferentes utilizam tipos de código de barras diferentes (chamados simbologias) e escolher o certo é importante: a caixa de uma loja espera EAN-13 ou UPC-A, um armazém aceita bem o Code 128 e uma caixa de expedição utiliza ITF-14.

  • Code 128 — o cavalo de batalha de uso geral. Codifica letras, números e pontuação com quase qualquer comprimento e mantém-se compacto. Melhor para etiquetas de inventário, etiquetas de bens, cartões de biblioteca e de identificação e rastreio interno de qualquer tipo.
  • Code 39 — a norma mais antiga e mais simples. Apenas letras maiúsculas, dígitos e os símbolos - . $ / + % e espaço. Muito amplamente suportada por leitores mais antigos; comum para etiquetas militares, automóveis e de bens simples.
  • EAN-13 — a norma de retalho fora da América do Norte. Exatamente 13 dígitos: os seus 12 dígitos mais um dígito de controlo calculado. Os números de produto têm de estar registados na GS1 para serem utilizados na venda a retalho (consulte as FAQ abaixo).
  • UPC-A — a norma de retalho nos EUA e no Canadá. Exatamente 12 dígitos: os seus 11 dígitos mais um dígito de controlo, também emitidos através da GS1 para utilização no retalho.
  • ITF-14 — a norma das caixas de expedição. Exatamente 14 dígitos (13 mais o dígito de controlo), impressa em grande nas caixas, para que uma caixa inteira possa ser lida sem a abrir.

Um aviso honesto sobre os tipos de retalho: este gerador produz um estruturalmente correto código de barras que qualquer leitor pode ler, que é tudo o que precisa para armazéns de stock, prateleiras, inventários escolares e de escritório, passes de eventos e etiquetas internas. Mas se o código de barras for lido numa caixa de loja ou por um mercado online, o próprio número tem de ser oficialmente seu — registado na GS1 sob a sua empresa. Inventar um número de retalho arrisca imprimir o código de produto de outra empresa nos seus bens.

Melhores utilizações deste gerador de códigos de barras

  • Rótulos de inventário e de armazéns
  • Etiquetas de bens para equipamento escolar, de escritório e de oficina
  • Rótulos de localização de margens de prateleiras e armazéns
  • Livros de bibliotecas, cartões de identificação e cartões de membro
  • Marcação de caixas de expedição com ITF-14

Qualquer que seja o tipo que escolha, as regras de leitura são as mesmas: imprima o código de barras com um tamanho sensato (pelo menos cerca de 3 cm de largura para leitores manuais), mantenha uma margem em branco limpa — a zona de silêncio — de ambos os lados e nunca estique nem comprima a imagem, porque isso distorce as larguras das barras que o leitor mede. Os ficheiros SVG escalam sem distorção e são a escolha mais segura para impressão; o PNG com uma altura generosa serve bem para ecrãs e impressoras de escritório.

Perguntas Frequentes

Este gerador de códigos de barras é grátis?

Sim. O gerador de códigos de barras da Loona é completamente gratuito, sem registo, sem marca de água e sem limite para o número de códigos de barras que cria, para utilização pessoal ou comercial.

Posso utilizar um código de barras EAN-13 ou UPC gerado em produtos que vendo em lojas?

A imagem do código de barras é estruturalmente correta e ler-se-á, mas os códigos de barras de retalho têm de ser registados: lojas e mercados exigem números emitidos pela GS1, a organização oficial, sob o seu próprio prefixo de empresa. Um número que invente aqui pode colidir com o produto de outra pessoa. Para inventário, bens, prateleiras e uso interno, os códigos de barras gerados são aceitáveis; para venda a retalho, registe-se primeiro na GS1.

O que é um dígito de controlo e preciso de o calcular?

O EAN-13, o UPC-A e o ITF-14 terminam com um dígito de controlo calculado a partir dos outros dígitos, para que os leitores possam detetar leituras erradas. Não precisa de o calcular: introduza o número sem o dígito de controlo (12 dígitos para EAN-13, 11 para UPC-A, 13 para ITF-14) e este gerador adiciona-o. Se introduzir o número completo, o gerador verifica o dígito de controlo e diz-lhe se estiver errado.

Sim. O código de barras é desenhado 100% no seu navegador, utilizando JavaScript. Nada do que introduz é enviado para, ou guardado em, qualquer servidor.

Como funciona

Este gerador utiliza a biblioteca JsBarcode, a correr inteiramente no seu navegador, para traduzir o seu conteúdo no padrão de barras exato da norma escolhida. Para os tipos numerados de retalho, aplica primeiro a regra do dígito de controlo GS1: lendo os dígitos a partir da direita, dígitos alternados são multiplicados por 3 e por 1, os resultados são somados e o dígito de controlo é o que fizer o total um múltiplo de dez. Esse único dígito é a forma como uma caixa sabe que leu o seu código de barras corretamente — se uma barra estiver danificada e um dígito for mal lido, a soma deixa de corresponder e o leitor apita para uma nova leitura, em vez de cobrar o preço errado.

O método: escolha o tipo → escreva o conteúdo (sem o dígito de controlo para EAN-13, UPC-A e ITF-14) → verifique a pré-visualização → transfira o PNG ou o SVG → imprima e leia de teste.

Perguntas frequentes

Qual é a diferença entre um código de barras e um código QR?

Um código de barras é unidimensional: guarda um código curto (normalmente apenas números ou um ID breve) que uma base de dados consulta depois. Um código QR é bidimensional e pode guardar muito mais — uma ligação completa, uma palavra-passe Wi-Fi ou um cartão de contacto — e é lido pelas câmaras dos telemóveis. Se estiver envolvida uma pistola de leitura ou uma caixa, utilize um código de barras; se estiver envolvida a câmara de um telemóvel, um código QR é normalmente melhor.

Por que foi o meu número EAN-13 rejeitado?

Ou contém algo para além de dígitos, ou o seu comprimento não é de 12 ou 13 dígitos, ou o 13.º dígito não corresponde ao dígito de controlo calculado. A mensagem sob a pré-visualização diz-lhe qual deve ser o dígito de controlo, para que possa detetar uma gralha.

Posso alterar as cores do código de barras?

Sim — a cor das barras e o fundo estão acima da pré-visualização. Os leitores leem o contraste, não a própria cor, pelo que barras escuras (pretas, azul escuro, verde escuro) sobre branco ou um fundo claro funcionam melhor. Evite barras vermelhas: muitos leitores a laser utilizam luz vermelha e não as conseguem ver.

PNG ou SVG — qual devo transferir?

Escolha SVG para tudo o que for impresso profissionalmente ou ampliado, porque se dimensiona para qualquer tamanho sem ficar desfocado. Escolha PNG para documentos, folhas de cálculo, diapositivos e impressão rápida de escritório.

Um código de barras pode conter uma mensagem longa ou uma ligação Web?

Não bem. Os códigos de barras são concebidos para códigos curtos; uma ligação longa torna um Code 128 extremamente denso, com o qual muitos leitores têm dificuldade. Para ligações e conteúdos mais longos, utilize antes um dos nossos geradores de códigos QR — foi exatamente para isso que os códigos QR foram inventados.
