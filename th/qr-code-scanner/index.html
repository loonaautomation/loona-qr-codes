ชี้กล้องของคุณไปที่คิวอาร์โค้ดหรือบาร์โค้ด หรือวางรูปถ่ายหรือภาพหน้าจอ — โค้ดถูกถอดรหัสที่นี่บนอุปกรณ์ของคุณ ไม่ต้องสมัครสมาชิก ไม่ต้องติดตั้งแอป และสิ่งที่คุณสแกนไม่เคยถูกอัปโหลด คุณยังสามารถถอดรหัสแบบกลุ่มของรูปภาพโค้ดจำนวนมากในคราวเดียวและส่งออกผลลัพธ์เป็นไฟล์ CSV ได้

สแกนด้วยกล้องของคุณ

การสแกนด้วยกล้องสดใช้ BarcodeDetector ที่รวดเร็วซึ่งสร้างไว้ใน Chrome, Edge และเบราว์เซอร์ Android ส่วนใหญ่ และอ่านคิวอาร์โค้ดบวกกับบาร์โค้ดทั่วไป (EAN-13, UPC-A, Code 128, Code 39 และอื่น ๆ ขึ้นอยู่กับเบราว์เซอร์ของคุณ)

    ประวัติอยู่เพียงในหน่วยความจำของหน้านี้ — ปิดแท็บและมันก็หายไป ไม่มีสิ่งใดถูกบันทึกหรือส่งไปไหน
    

    


    การถอดรหัสแบบกลุ่ม — รูปภาพโค้ดจำนวนมากในคราวเดียว
    

    มีรูปภาพโค้ดทั้งชุดที่ต้องตรวจสอบ — แผ่นที่พิมพ์ โฟลเดอร์ภาพสินค้า ชุดภาพหน้าจอของชั้นเรียน? เลือกหรือวางรูปภาพหลายรูปในคราวเดียว: แต่ละรูปจะถูกถอดรหัสด้วยตัวถอดรหัส jsQR และ ZXing เดียวกันกับด้านบน ผลลัพธ์ถูกรวบรวมในตาราง และคุณสามารถส่งออกตารางเป็นไฟล์ CSV ได้ ไฟล์ที่ไม่มีโค้ดที่อ่านได้จะถูกระบุอย่างตรงไปตรงมาว่า “ถอดรหัสไม่ได้”
    

    

    วางรูปภาพหลายรูปที่นี่ หรือคลิกเพื่อเลือกหลายไฟล์

    เป็นส่วนตัว 100%: การถอดรหัสแบบกลุ่มก็เกิดขึ้นทั้งหมดภายในเบราว์เซอร์ของคุณเช่นกัน ไม่มีรูปภาพใดในชุดถูกอัปโหลด และไฟล์ CSV จะถูกสร้างบนอุปกรณ์ของคุณเมื่อคุณคลิกส่งออก
    

    


    

    วิธีสแกนคิวอาร์โค้ดหรือบาร์โค้ดใน 3 ขั้นตอน
    

    1. เลือกกล้องหรือรูปภาพ บน Chrome, Edge หรือ Android แตะ “เริ่มการสแกนด้วยกล้อง” อนุญาตการเข้าถึงกล้อง และถือโค้ดไว้ภายในกรอบ บนเบราว์เซอร์ใดก็ตาม — รวมถึง Safari และ Firefox — คุณสามารถอัปโหลดรูปถ่าย ลากรูปภาพเข้ามา หรือวางภาพหน้าจอแทนได้
      2. 

    2. รอสักครู่เพื่อถอดรหัส สแกนเนอร์อ่านลวดลายบนอุปกรณ์ของคุณและแสดงประเภท รูปแบบ และเนื้อหาดิบที่ถอดรหัส สำหรับรูปถ่าย รูปภาพของโค้ดที่คมชัด ใกล้ และมีแสงดีจะสแกนได้เร็วที่สุด
    3. ใช้การกระทำอัจฉริยะ เปิดลิงก์ที่ถอดรหัสได้ เปิดเผยชื่อเครือข่าย WiFi และรหัสผ่าน ดาวน์โหลดนามบัตรผู้ติดต่อ (.vcf) จากโค้ด vCard โทรไปยังหมายเลข หรือคัดลอกข้อความดิบด้วยการแตะเพียงครั้งเดียว ทุกการสแกนถูกเพิ่มลงในประวัติบนหน้าของคุณสำหรับเซสชันนี้
    

    เกี่ยวกับเครื่องสแกนคิวอาร์โค้ดและบาร์โค้ดนี้
    

    เว็บไซต์คิวอาร์โค้ดส่วนใหญ่เท่านั้น make โค้ด หน้านี้ทำงานตรงกันข้าม: มันอ่านพวกมัน นั่นคือสิ่งที่คุณต้องการเมื่อโค้ดที่พิมพ์ไม่มีป้ายที่อ่านได้ เมื่อเพื่อนร่วมงานส่งภาพหน้าจอของโค้ดมาให้คุณแทนที่จะเป็นลิงก์ภายในมัน เมื่อคุณต้องการตรวจสอบว่าโค้ดที่พิมพ์ของคุณเองบรรจุอะไรจริง ๆ ก่อนการพิมพ์จำนวนมาก หรือเมื่อหมายเลขบาร์โค้ดสินค้าต้องอ่านจากรูปถ่าย
    

    มันทำงานในสองวิธี โหมดกล้องใช้อินเทอร์เฟซ BarcodeDetector ที่สร้างไว้ในเบราว์เซอร์ Chromium สมัยใหม่ — การตรวจจับที่รวดเร็วและเป็นมิตรกับฮาร์ดแวร์แบบเดียวกันกับที่ระบบของโทรศัพท์ของคุณใช้ — และรายงานคิวอาร์โค้ดและบาร์โค้ดหนึ่งมิติทั่วไป โหมดรูปภาพบรรจุอยู่ในตัวมันเองอย่างสมบูรณ์: ไลบรารี jsQR แบบโอเพนซอร์สถอดรหัสคิวอาร์โค้ดจากพิกเซลของรูปภาพของคุณ และไลบรารี ZXing แบบโอเพนซอร์สถอดรหัสบาร์โค้ด (และคิวอาร์โค้ดใดก็ตามที่ jsQR พลาด) จากพิกเซลเดียวกัน ทั้งสองทำงานทั้งหมดในเบราว์เซอร์ของคุณ นั่นคือเหตุผลที่เครื่องสแกนนี้ยังคงใช้งานได้กับโค้ดที่ละเอียดอ่อน — รหัสผ่าน WiFi โค้ดชำระเงิน ลิงก์ส่วนตัว — ที่คุณไม่มีวันต้องการอัปโหลดไปยังเซิร์ฟเวอร์ของคนแปลกหน้า
    

    การใช้งานที่ดีที่สุดของเครื่องสแกนนี้
    • การตรวจสอบคิวอาร์โค้ดที่พิมพ์ของคุณเองก่อนพิมพ์จำนวนมาก
    • การเปิดลิงก์ที่ซ่อนอยู่ภายในคิวอาร์โค้ดในภาพหน้าจอหรือรูปถ่ายที่ใครบางคนส่งให้คุณ
    • การกู้คืนชื่อเครือข่าย WiFi และรหัสผ่านจากรูปภาพคิวอาร์โค้ด WiFi
    • การบันทึกผู้ติดต่อ vCard จากคิวอาร์โค้ดนามบัตรเป็นไฟล์ .vcf
    • การอ่านหมายเลขบาร์โค้ด EAN-13, UPC-A, Code 128 และ Code 39 จากรูปภาพผลิตภัณฑ์และป้าย
    • การตรวจสอบว่าบาร์โค้ดที่คุณสร้างสแกนกลับเป็นหมายเลขที่คุณตั้งใจไว้พอดี
    • การตรวจสอบทั้งแผ่นที่พิมพ์หรือทั้งโฟลเดอร์ของรูปภาพโค้ดแบบกลุ่ม พร้อมการส่งออก CSV ของทุกผลลัพธ์
    • การเห็นพิกัดเบื้องหลังโค้ดตำแหน่ง geo: หรือที่อยู่เบื้องหลังโค้ดการชำระเงิน Bitcoin หรือ Ethereum ก่อนดำเนินการใด ๆ กับพวกมัน
    

    ข้อจำกัดที่ซื่อสัตย์ เพื่อที่คุณจะไม่ประหลาดใจ: การสแกนด้วยกล้องขึ้นอยู่กับคุณสมบัติของเบราว์เซอร์ที่ Safari และ Firefox ยังไม่ได้นำมาใช้ ดังนั้นบนเบราว์เซอร์เหล่านั้นมีเพียงโหมดรูปภาพเท่านั้นที่ใช้งานได้ — หน้าจะตรวจจับสิ่งนี้และบอกคุณอย่างตรงไปตรงมาแทนที่จะล้มเหลวอย่างเงียบ ๆ และไม่มีตัวถอดรหัสใดที่สามารถอ่านโค้ดที่เล็กเกินไป เบลอ ขาด หรือพิมพ์ด้วยคอนทราสต์ต่ำเกินไปในรูปภาพ การถ่ายภาพใหม่ใกล้กว่า ตรงหน้า และในแสงที่ดีช่วยแก้ไขการสแกนที่ล้มเหลวส่วนใหญ่ได้
    

    คำถามที่พบบ่อย
    เครื่องสแกนคิวอาร์โค้ดและบาร์โค้ดนี้ฟรีไหม?
    ใช่ สแกนเนอร์ของ Loona ฟรีอย่างสมบูรณ์โดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดจำนวนโค้ดที่คุณสแกน สำหรับการใช้งานส่วนตัวหรือเชิงพาณิชย์
    วิดีโอจากกล้องหรือรูปถ่ายของฉันเป็นส่วนตัวในหน้าเครื่องสแกนนี้ไหม?
    ใช่ ทุกอย่างถอดรหัสบนอุปกรณ์ของคุณเอง ภายในเบราว์เซอร์ของคุณ เฟรมกล้องไม่เคยถูกส่งไปที่ใดและรูปภาพที่อัปโหลดไม่เคยถูกส่งไปยังเซิร์ฟเวอร์ — ไฟล์ถูกอ่านภายในเครื่อง ถอดรหัสภายในเครื่อง และประวัติการสแกนของคุณถูกเก็บเฉพาะในหน่วยความจำของหน้านี้และหายไปเมื่อคุณปิดแท็บ
    ทำไมการสแกนด้วยกล้องจึงไม่ทำงานในเบราว์เซอร์ของฉัน?
    การสแกนด้วยกล้องสดใช้เทคโนโลยี BarcodeDetector ที่สร้างไว้ใน Chrome, Edge และเบราว์เซอร์ Android ส่วนใหญ่ Safari และ Firefox ยังไม่รวมมันไว้ ดังนั้นบนเบราว์เซอร์เหล่านั้น ปุ่มกล้องจะถูกแทนที่ด้วยข้อความที่ขอให้คุณใช้อัปโหลดรูปภาพแทน — การอัปโหลดรูปถ่ายหรือภาพหน้าจอใช้ได้ในทุกเบราว์เซอร์สมัยใหม่
    เครื่องสแกนนี้สามารถอ่านบาร์โค้ดจากรูปถ่ายได้ไหม?
    ใช่ โหมดอัปโหลดถอดรหัสคิวอาร์โค้ดจากรูปภาพด้วยไลบรารี jsQR และบาร์โค้ดจากรูปภาพด้วยไลบรารี ZXing — รวมถึง EAN-13, UPC-A, Code 128 และ Code 39 — รวมถึงคิวอาร์โค้ดที่ ZXing พบที่ jsQR พลาด โค้ดที่เล็กมาก เบลอ เสียหาย หรือคอนทราสต์ต่ำในรูปถ่ายอาจยังคงล้มเหลว รูปถ่ายที่คมชัดและใกล้กว่ามักแก้มันได้
    สแกนเนอร์นี้อ่านโค้ดประเภทใดได้บ้าง?
    การสแกนด้วยกล้อง (ในที่ที่รองรับ) อ่านคิวอาร์โค้ดบวกรูปแบบบาร์โค้ดที่ BarcodeDetector ของเบราว์เซอร์ของคุณมีให้ โดยทั่วไปคือ EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar และ ITF การอัปโหลดรูปภาพอ่านคิวอาร์โค้ดและบาร์โค้ด EAN-13, UPC-A, Code 128 และ Code 39 และแสดงประเภทที่ถอดรหัสได้ เนื้อหาดิบ และการดำเนินการอัจฉริยะ เช่น การเปิดลิงก์หรือการบันทึกผู้ติดต่อ
    

    เครื่องสร้างคิวอาร์โค้ดที่เกี่ยวข้อง
    เครื่องสร้างบาร์โค้ด
    สร้างบาร์โค้ดผลิตภัณฑ์ — Code 128, EAN-13, UPC และอื่น ๆ จากนั้นสแกนกลับมาที่นี่เพื่อตรวจสอบ
    เครื่องสร้างคิวอาร์โค้ด URL / เว็บไซต์
    เปลี่ยนลิงก์เว็บไซต์ใดก็ได้เป็นคิวอาร์โค้ด
    เครื่องสร้างคิวอาร์โค้ดข้อความธรรมดา
    ใส่ข้อความ โค้ด หรือข้อความใด ๆ ลงในคิวอาร์โค้ด
    เครื่องสร้างคิวอาร์โค้ด WiFi
    แขกเชื่อมต่อ WiFi ด้วยการสแกนเพียงครั้งเดียว ไม่ต้องพิมพ์รหัสผ่าน
    เครื่องสร้างคิวอาร์โค้ดผู้ติดต่อ vCard
    สแกนเพื่อบันทึกการ์ดผู้ติดต่อฉบับเต็มของคุณลงในโทรศัพท์

    คิวอาร์โค้ดหรือบาร์โค้ดเป็นเพียงลวดลายที่เข้ารหัสข้อความในรูปแบบโมดูลสว่างและมืด การถอดรหัสคือกระบวนการย้อนกลับของการสร้าง: ค้นหาลวดลายในรูปภาพ วัดขนาดโมดูล แก้ไขข้อผิดพลาดโดยใช้ความซ้ำซ้อนในตัวของโค้ด และแปลงบิตกลับเป็นอักขระ jsQR ทำสิ่งนี้สำหรับคิวอาร์โค้ดโดยค้นหาสี่เหลี่ยมค้นหาทั้งสามและสุ่มตัวอย่างกริด ส่วน ZXing ทำสำหรับบาร์โค้ดโดยสแกนแถวพิกเซลข้ามแถบบาร์และจับคู่ความกว้างกับกฎของ EAN, UPC, Code 128 หรือ Code 39 รวมถึงการตรวจสอบเลขตรวจสอบตัวสุดท้ายของบาร์โค้ดสินค้าปลีก ในโหมดกล้อง BarcodeDetector ในตัวของเบราว์เซอร์ของคุณจะทำงานเดียวกันอย่างต่อเนื่องบนเฟรมวิดีโอสดจนกว่าจะพบโค้ด ในโหมดกลุ่ม ตัวถอดรหัสรูปภาพสองตัวเดียวกันจะทำงานหนึ่งครั้งต่อหนึ่งไฟล์ และทุกผลลัพธ์ — ชื่อไฟล์ รูปแบบ ประเภท และข้อความที่ถอดรหัสได้ — จะถูกรวบรวมลงในตารางที่คุณสามารถส่งออกเป็น CSV ได้
    

    วิธีการ: เลือกกล้องหรือรูปภาพ → ให้ตัวถอดรหัสบนอุปกรณ์อ่านลวดลาย → ตรวจสอบประเภท รูปแบบ และเนื้อหาดิบ → ใช้การกระทำอัจฉริยะ (เปิด คัดลอก บันทึกผู้ติดต่อ) → ค้นหาการสแกนอีกครั้งได้ทุกเมื่อในประวัติเซสชัน
    

    ตัวอย่างที่ทำแล้ว
    

    เจ้าของร้านสร้างบาร์โค้ด EAN-13 สำหรับสินค้าใหม่ด้วยเครื่องสร้างบาร์โค้ดของ Loona และพิมพ์งานพิสูจน์ ก่อนสั่งป้ายหนึ่งพันป้าย เธอถ่ายรูปงานพิสูจน์ด้วยโทรศัพท์ อัปโหลดรูปที่นี่ และเครื่องสแกนอ่านบาร์โค้ดกลับมาด้วย ZXing: รูปแบบ EAN-13 หมายเลขตรงกับที่เธอใส่พอดี มีเลขตรวจสอบรวมอยู่ด้วย เธอยังถ่ายภาพหน้าจอคิวอาร์โค้ด WiFi ของผู้จัดจำหน่ายจากแชต วางลงในหน้านี้ และ jsQR เปิดเผยชื่อเครือข่ายและรหัสผ่านเป็นข้อความธรรมดาที่เธอพิมพ์ลงในแล็ปท็อปที่ไม่มีกล้องได้
    

    คำถามที่พบบ่อย
    

    ฉันสามารถสแกนโค้ดจากภาพหน้าจอบนโทรศัพท์เครื่องเดียวกันได้ไหม?
    

    ใช่ บันทึกหรือแชร์ภาพหน้าจอลงในแอปรูปถ่ายของคุณ จากนั้นใช้การอัปโหลดรูปภาพที่นี่และเลือกภาพหน้าจอนั้น บนคอมพิวเตอร์ เพียงคัดลอกรูปภาพและวางลงในหน้านี้ด้วย Ctrl+V (หรือ Cmd+V บน Mac) — ไม่ต้องบันทึกไฟล์
    

    ผลลัพธ์ดูเหมือน WIFI:T:WPA;S:… — นั่นหมายความว่าอะไร?
    

    นั่นคือรูปแบบดิบมาตรฐานภายในคิวอาร์โค้ด WiFi: T คือประเภทความปลอดภัย S คือชื่อเครือข่าย (SSID) และ P คือรหัสผ่าน หน้านี้ยังแสดงค่าทั้งสามนั้นแยกกันเหนือเนื้อหาดิบด้วย ดังนั้นคุณไม่ต้องแยกมันออกมาเอง
    

    ฉันจะเพิ่มผู้ติดต่อที่สแกนลงในโทรศัพท์ของฉันได้อย่างไร?
    

    เมื่อการสแกนเป็น vCard การกระทำ “ดาวน์โหลดผู้ติดต่อ (.vcf)” จะปรากฏ ดาวน์โหลดไฟล์และเปิดมัน — โทรศัพท์และคอมพิวเตอร์จะเสนอให้บันทึกมันเป็นผู้ติดต่อพร้อมชื่อ องค์กร โทรศัพท์ อีเมล และเว็บไซต์กรอกไว้เรียบร้อย
    

    ทำไมรูปถ่ายของฉันจึงไม่ถอดรหัส?
    

    สาเหตุทั่วไปคือโค้ดที่เล็กมากในรูปภาพขนาดใหญ่ ภาพเบลอ แสงสะท้อน สื่อสิ่งพิมพ์ที่ฉีกขาดหรือคอนทราสต์ต่ำ หรือภาพหน้าจอที่ครอบตัดแน่นเกินไปรอบโค้ด (ตัวถอดรหัสต้องการพื้นที่เงียบสีขาวรอบโค้ด) ครอบตัดหลวม ๆ ถ่ายรูปใหม่ให้ใกล้และตรงมากขึ้น แล้วลองอีกครั้ง
    

    ฉันควรเชื่อถือคิวอาร์โค้ดที่พบในที่สาธารณะไหม?
    

    สแกนที่นี่ก่อนแทนที่จะใช้แอปที่เปิดผลลัพธ์โดยอัตโนมัติ: หน้านี้เท่านั้น แสดง เนื้อหาที่ถอดรหัสให้คุณและไม่เคยเปิดอะไรด้วยตัวเอง ตรวจสอบว่าลิงก์นำไปในที่ที่ป้ายของมันสัญญาไว้จริง ๆ ก่อนที่คุณจะแตะ “เปิดลิงก์” — นิสัยเดียวนั้นเอาชนะการหลอกลวงแบบสติกเกอร์ทับโค้ดจริงส่วนใหญ่ได้
    

    

    ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี
    

    เพิ่มเครื่องมือนี้ลงในเว็บไซต์หรือบล็อกของคุณเอง — มันฟรีอย่างสมบูรณ์ ไม่ต้องสมัครสมาชิก และแสดงเวอร์ชันล่าสุดเสมอ คัดลอกโค้ดด้านล่างและวางลงในหน้าของคุณในตำแหน่งที่คุณต้องการให้เครื่องมือปรากฏ การคงบรรทัดเครดิตเล็ก ๆ “Powered by Loona Automation” ไว้ใต้ตัวฝังช่วยรักษาเครื่องมือนี้ให้ฟรีต่อไป — แต่คุณมีอิสระที่จะจัดรูปแบบหรือลบออกได้ เครื่องมือทำงานได้ทั้งสองแบบ
