Loona คิวอาร์โค้ด
บ้านเครื่องมือทั้งหมดเกี่ยวกับติดต่อ

เครื่องสร้างบาร์โค้ดฟรี

สร้างบาร์โค้ด Code 128, Code 39, EAN-13, UPC-A และ ITF-14 ในไม่กี่วินาที เลขตรวจสอบถูกเพิ่มให้คุณ และคุณสามารถดาวน์โหลด PNG หรือ SVG ที่คมชัด ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ

บาร์โค้ดของคุณ

เป็นส่วนตัว 100%: บาร์โค้ดนี้ถูกสร้างภายในเบราว์เซอร์ของคุณ สิ่งที่คุณพิมพ์จะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ

วิธีสร้างบาร์โค้ดใน 3 ขั้นตอน

  1. พิมพ์เนื้อหา และเลือกประเภทบาร์โค้ด สำหรับ EAN-13, UPC-A และ ITF-14 ให้กรอกหมายเลข โดยไม่มี เลขตรวจสอบสุดท้ายของมัน — เครื่องสร้างคำนวณและเพิ่มมัน หรือตรวจสอบมันหากคุณพิมพ์หมายเลขเต็ม
  2. ตรวจสอบตัวอย่างสด และปรับสีแถบ พื้นหลัง และความสูง รักษาคอนทราสต์ที่ชัดเจน: แถบสีเข้มบนพื้นหลังสีอ่อนสแกนได้ดีที่สุด
  3. ดาวน์โหลด PNG หรือ SVG, พิมพ์ออกมา และสแกนทดสอบหนึ่งครั้งด้วยแอปในโทรศัพท์หรือเครื่องสแกนก่อนพิมพ์จำนวนมาก SVG จะคมชัดสมบูรณ์แบบในทุกขนาดและเหมาะที่สุดสำหรับการพิมพ์ระดับมืออาชีพ

ตรวจสอบก่อนที่คุณจะพิมพ์: หลังสร้าง ให้สแกนบาร์โค้ดของคุณกลับด้วยเครื่องมือฟรีของเรา เครื่องสแกนคิวอาร์โค้ด & บาร์โค้ด — มันอ่านบาร์โค้ดจากรูปถ่ายด้วย ดังนั้นคุณสามารถตรวจสอบว่าหลักฐานที่พิมพ์อ่านหมายเลขที่คุณตั้งใจไว้พอดี

เกี่ยวกับบาร์โค้ดและห้าประเภท

บาร์โค้ดเปลี่ยนโค้ดสั้น ๆ ให้กลายเป็นลวดลายของแถบที่เครื่องสแกนอ่านได้ในเสี้ยววินาที งานแต่ละประเภทใช้บาร์โค้ดต่างประเภทกัน (เรียกว่า symbology) และการเลือกให้ถูกต้องมีความสำคัญ: เครื่องคิดเงินของร้านค้าคาดหวัง EAN-13 หรือ UPC-A คลังสินค้าใช้ Code 128 ได้ดี และกล่องขนส่งใช้ ITF-14

  • Code 128 — ม้าทำงานอเนกประสงค์ เข้ารหัสตัวอักษร ตัวเลข และเครื่องหมายวรรคตอนที่เกือบทุกความยาว และยังคงกะทัดรัด ดีที่สุดสำหรับป้ายสินค้าคงคลัง ป้ายสินทรัพย์ บัตรห้องสมุดและบัตรประจำตัว และการติดตามภายในทุกชนิด
  • Code 39 — มาตรฐานที่เก่ากว่าและเรียบง่ายกว่า ตัวอักษรพิมพ์ใหญ่ ตัวเลข และสัญลักษณ์ - . $ / + % และช่องว่างเท่านั้น รองรับอย่างกว้างขวางมากโดยสแกนเนอร์รุ่นเก่า พบทั่วไปสำหรับป้ายทางทหาร ยานยนต์ และสินทรัพย์แบบง่าย
  • EAN-13 — มาตรฐานค้าปลีกนอกอเมริกาเหนือ พอดี 13 หลัก: 12 หลักของคุณบวกเลขตรวจสอบที่คำนวณ หมายเลขสินค้าต้องลงทะเบียนกับ GS1 จึงจะใช้สำหรับการขายปลีกได้ (ดู FAQ ข้างล่าง)
  • UPC-A — มาตรฐานค้าปลีกในสหรัฐอเมริกาและแคนาดา พอดี 12 หลัก: 11 หลักของคุณบวกเลขตรวจสอบ ออกผ่าน GS1 เช่นกันสำหรับการใช้ค้าปลีก
  • ITF-14 — มาตรฐานลังจัดส่ง พอดี 14 หลัก (13 บวกเลขตรวจสอบ) พิมพ์ใหญ่บนกล่องเพื่อให้ทั้งลังสามารถสแกนได้โดยไม่ต้องเปิดมัน

คำเตือนที่ซื่อสัตย์หนึ่งข้อเกี่ยวกับประเภทค้าปลีก: เครื่องสร้างนี้ผลิต ถูกต้องตามโครงสร้าง บาร์โค้ดที่สแกนเนอร์ใดก็อ่านได้ ซึ่งเป็นสิ่งที่คุณต้องการสำหรับห้องเก็บสินค้า ชั้นวาง สินค้าคงคลังของโรงเรียนและสำนักงาน บัตรเข้างาน และป้ายภายใน แต่หากบาร์โค้ดจะถูกสแกนที่เครื่องคิดเงินของร้านค้าหรือโดยมาร์เก็ตเพลสออนไลน์ หมายเลขเองต้องเป็นของคุณอย่างเป็นทางการ — ลงทะเบียนกับ GS1 ภายใต้บริษัทของคุณ การคิดหมายเลขค้าปลีกขึ้นเสี่ยงต่อการพิมพ์โค้ดสินค้าของบริษัทอื่นบนสินค้าของคุณ

การใช้งานที่ดีที่สุดของเครื่องสร้างบาร์โค้ดนี้

  • ป้ายคลังและห้องเก็บของ
  • ป้ายทรัพย์สินสำหรับอุปกรณ์โรงเรียน สำนักงาน และเวิร์กช็อป
  • ป้ายขอบชั้นวางและตำแหน่งคลังสินค้า
  • หนังสือห้องสมุด บัตรประจำตัว และบัตรสมาชิก
  • การทำเครื่องหมายลังจัดส่งด้วย ITF-14

ไม่ว่าคุณจะเลือกประเภทใด กฎการสแกนเหมือนกัน: พิมพ์บาร์โค้ดที่ขนาดที่เหมาะสม (กว้างอย่างน้อยประมาณ 3 cm สำหรับสแกนเนอร์มือถือ) รักษาขอบว่างที่ชัดเจน — พื้นที่เงียบ — ทั้งสองด้าน และอย่ายืดหรือบีบรูปภาพเด็ดขาด เพราะนั่นบิดเบือนความกว้างของแถบที่สแกนเนอร์วัด ไฟล์ SVG ปรับขนาดโดยไม่บิดเบือนและเป็นทางเลือกที่ปลอดภัยที่สุดสำหรับการพิมพ์ PNG ที่ความสูงมากพอใช้ได้ดีสำหรับหน้าจอและเครื่องพิมพ์สำนักงาน

คำถามที่พบบ่อย

เครื่องสร้างบาร์โค้ดนี้ฟรีไหม?

ใช่ เครื่องสร้างบาร์โค้ดของ Loona ฟรีอย่างสมบูรณ์โดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดจำนวนบาร์โค้ดที่คุณสร้าง สำหรับการใช้งานส่วนตัวหรือเชิงพาณิชย์

ฉันสามารถใช้บาร์โค้ด EAN-13 หรือ UPC ที่สร้างขึ้นบนผลิตภัณฑ์ที่ฉันขายในร้านค้าได้ไหม?

รูปภาพบาร์โค้ดถูกต้องตามโครงสร้างและจะสแกนได้ แต่บาร์โค้ดค้าปลีกต้องลงทะเบียน: ร้านค้าและมาร์เก็ตเพลสต้องการหมายเลขที่ออกโดย GS1 องค์กรอย่างเป็นทางการ ภายใต้คำนำหน้าบริษัทของคุณเอง หมายเลขที่คุณคิดขึ้นที่นี่อาจชนกับสินค้าของคนอื่น สำหรับสินค้าคงคลัง สินทรัพย์ ชั้นวาง และการใช้ภายใน บาร์โค้ดที่สร้างขึ้นใช้ได้ สำหรับการขายปลีก ให้ลงทะเบียนกับ GS1 ก่อน

เลขตรวจสอบคืออะไร และฉันต้องคำนวณมันไหม?

EAN-13, UPC-A และ ITF-14 ปิดท้ายด้วยเลขตรวจสอบที่คำนวณจากหลักอื่น ๆ เพื่อให้เครื่องสแกนตรวจจับการอ่านผิดได้ คุณไม่จำเป็นต้องคำนวณมัน: ใส่หมายเลขโดยไม่มีเลขตรวจสอบ (12 หลักสำหรับ EAN-13, 11 สำหรับ UPC-A, 13 สำหรับ ITF-14) และเครื่องสร้างนี้จะเพิ่มมัน หากคุณใส่หมายเลขแบบเต็ม เครื่องสร้างจะตรวจสอบเลขตรวจสอบและบอกคุณหากมันผิด

ข้อมูลของฉันเป็นส่วนตัวในหน้าบาร์โค้ดนี้ไหม?

ใช่ บาร์โค้ดถูกวาด 100% ในเบราว์เซอร์ของคุณโดยใช้ JavaScript ไม่มีอะไรที่คุณกรอกถูกส่งไปหรือเก็บบนเซิร์ฟเวอร์ใด ๆ

เปลี่ยนลิงก์เว็บไซต์ใดก็ได้เป็นคิวอาร์โค้ด

วิธีการทำงาน

เครื่องสร้างนี้ใช้ไลบรารี JsBarcode ทำงานทั้งหมดในเบราว์เซอร์ของคุณ เพื่อแปลเนื้อหาของคุณเป็นลวดลายแถบที่แน่นอนของมาตรฐานที่เลือก สำหรับประเภทค้าปลีกที่มีหมายเลข มันจะใช้กฎเลขตรวจสอบ GS1 ก่อน: อ่านตัวเลขจากขวา ตัวเลขสลับกันถูกคูณด้วย 3 และด้วย 1 ผลลัพธ์ถูกบวกกัน และเลขตรวจสอบคือสิ่งที่ทำให้ยอดรวมเป็นเท่าของสิบ หลักเดียวนั้นคือวิธีที่เครื่องคิดเงินรู้ว่ามันอ่านบาร์โค้ดของคุณถูกต้อง — หากแถบหนึ่งเสียหายและหลักหนึ่งถูกอ่านผิด ผลรวมจะไม่ตรงกันอีกต่อไปและสแกนเนอร์จะส่งเสียงให้สแกนใหม่แทนที่จะคิดราคาผิด

วิธีการ: เลือกประเภท → พิมพ์เนื้อหา (โดยไม่มีเลขตรวจสอบสำหรับ EAN-13, UPC-A และ ITF-14) → ตรวจสอบตัวอย่าง → ดาวน์โหลด PNG หรือ SVG → พิมพ์และสแกนทดสอบ

ตัวอย่างที่ทำแล้ว

บรรณารักษ์โรงเรียนต้องการป้ายสำหรับหนังสือใหม่และเลือก Code 128 พร้อมหมายเลขทะเบียนรับเข้าจากสมุดทะเบียนของเธอ — LIB-1001, LIB-1002 และอื่น ๆ เธอสร้างบาร์โค้ดแต่ละอัน ดาวน์โหลด SVG เพื่อให้เส้นยังคงคมชัด และพิมพ์ป้ายลงบนแผ่นสติกเกอร์ สำหรับลังเครื่องดื่มในโรงอาหารของโรงเรียน เธอเลือก ITF-14 แทนและใส่ตัวเลข 13 หลักที่พิมพ์ในแค็ตตาล็อกของผู้จัดจำหน่าย เครื่องสร้างเพิ่มเลขตรวจสอบ และตอนนี้ผู้ดูแลร้านสามารถสแกนทั้งลังที่ยังไม่เปิดได้เมื่อส่งมอบ

คำถามที่พบบ่อย

ความแตกต่างระหว่างบาร์โค้ดและคิวอาร์โค้ดคืออะไร?

บาร์โค้ดเป็นแบบหนึ่งมิติ: มันเก็บโค้ดสั้น ๆ (โดยปกติเป็นเพียงตัวเลขหรือ ID สั้น ๆ) ที่ฐานข้อมูลจะค้นหาต่อ ส่วนคิวอาร์โค้ดเป็นแบบสองมิติและเก็บข้อมูลได้มากกว่ามาก — ลิงก์แบบเต็ม รหัสผ่าน WiFi หรือนามบัตรผู้ติดต่อ — และอ่านด้วยกล้องโทรศัพท์ หากเกี่ยวข้องกับปืนสแกนเนอร์หรือเครื่องคิดเงิน ให้ใช้บาร์โค้ด หากเกี่ยวข้องกับกล้องโทรศัพท์ คิวอาร์โค้ดมักจะดีกว่า

ทำไมหมายเลข EAN-13 ของฉันจึงถูกปฏิเสธ?

ไม่ว่ามันจะมีสิ่งอื่นนอกเหนือจากตัวเลข ความยาวของมันไม่ใช่ 12 หรือ 13 หลัก หรือหลักที่ 13 ไม่ตรงกับเลขตรวจสอบที่คำนวณได้ ข้อความใต้ตัวอย่างจะบอกคุณว่าเลขตรวจสอบควรเป็นหลักใด เพื่อให้คุณสังเกตเห็นการพิมพ์พลาด

ฉันสามารถเปลี่ยนสีของบาร์โค้ดได้ไหม?

ใช่ — สีแถบและพื้นหลังอยู่เหนือตัวอย่าง สแกนเนอร์อ่านคอนทราสต์ ไม่ใช่สีเอง ดังนั้นแถบสีเข้ม (ดำ น้ำเงินเข้ม เขียวเข้ม) บนพื้นหลังสีขาวหรือสีอ่อนใช้ได้ดีที่สุด หลีกเลี่ยงแถบสีแดง: สแกนเนอร์เลเซอร์หลายตัวใช้แสงสีแดงและมองไม่เห็นมัน

PNG หรือ SVG — ฉันควรดาวน์โหลดอันไหน?

เลือก SVG สำหรับสิ่งใดก็ตามที่จะพิมพ์อย่างมืออาชีพหรือขยายขนาด เพราะมันปรับขนาดได้ทุกขนาดโดยไม่เบลอ เลือก PNG สำหรับเอกสาร สเปรดชีต สไลด์ และการพิมพ์ในสำนักงานอย่างรวดเร็ว

บาร์โค้ดหนึ่งอันสามารถบรรจุข้อความยาวหรือลิงก์เว็บได้ไหม?

ไม่ดีนัก บาร์โค้ดถูกออกแบบมาสำหรับโค้ดสั้น ๆ ลิงก์ยาวทำให้ Code 128 หนาแน่นอย่างมากที่เครื่องสแกนจำนวนมากประสบปัญหา สำหรับลิงก์และเนื้อหาที่ยาวกว่า ให้ใช้เครื่องสร้างคิวอาร์โค้ดของเราแทน — นั่นคือสิ่งที่คิวอาร์โค้ดถูกคิดค้นมาเพื่อการนี้พอดี

ฝังเครื่องมือนี้บนเว็บไซต์ของคุณ — ฟรี
