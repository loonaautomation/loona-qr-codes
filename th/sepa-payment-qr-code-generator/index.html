เครื่องสร้างคิวอาร์โค้ดชำระเงิน SEPA (EPC) ฟรี

โค้ดโอนเงินผ่านธนาคารของยุโรป: ลูกค้าสแกนด้วยแอปธนาคารของตน และการโอนก็ถูกกรอกไว้ — IBAN จำนวนเงิน เลขอ้างอิง — โดยไม่มีข้อผิดพลาด

คิวอาร์โค้ดของคุณ

กรอกแบบฟอร์มและคิวอาร์โค้ดของคุณจะปรากฏที่นี่

เป็นส่วนตัว 100%: คิวอาร์โค้ดนี้ถูกสร้างภายในเบราว์เซอร์ของคุณ สิ่งที่คุณพิมพ์จะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ และโค้ดไม่มีวันหมดอายุ

วิธีสร้างหนึ่งโค้ดใน 3 ขั้นตอน

  1. ใส่รายละเอียดของคุณ ในแบบฟอร์มข้างต้น — เฉพาะฟิลด์สำหรับประเภทนี้ ไม่มีอะไรเพิ่มเติม
  2. ตรวจสอบตัวอย่างสด และปรับแต่งสี พื้นหลัง และขนาด (256, 512 หรือ 1024 px) ให้ตรงกับแบรนด์หรือสื่อสิ่งพิมพ์ของคุณ
  3. คลิกดาวน์โหลด PNG, สแกนทดสอบโค้ดหนึ่งครั้งด้วยโทรศัพท์ของคุณ แล้วพิมพ์หรือแชร์ไปยังทุกที่ที่ผู้ชมของคุณอยู่

เกี่ยวกับการชำระเงิน SEPA (EPC) นี้

คิวอาร์โค้ด EPC (มาตรฐานเบื้องหลังโค้ด GiroCode และแบบ Paylib) คือวิธีที่ยุโรปส่วนใหญ่ตอนนี้ชำระใบแจ้งหนี้: แอปธนาคารสแกนโค้ดและกรอกการโอน SEPA ไว้ล่วงหน้า — ผู้รับเงิน IBAN จำนวนเงิน และเลขอ้างอิง — ดังนั้นความผิดพลาดคลาสสิกจากการพิมพ์ IBAN จึงหายไป และการชำระเงินมาถึงโดยจับคู่กับใบแจ้งหนี้ที่ถูกต้อง

รูปแบบถูกกำหนดโดย European Payments Council (EPC069-12): แท็กบริการ BCD เวอร์ชัน 002, UTF-8 การโอน SCT เครื่องสร้างนี้สร้างเพย์โหลดนั้นอย่างถูกต้อง รวมถึงทางเลือกระหว่างเลขอ้างอิงเจ้าหนี้ RF แบบมีโครงสร้างและข้อความการโอนเงินอิสระ — คุณมีทั้งสองอย่างไม่ได้ และแบบฟอร์มบังคับใช้ลำดับความสำคัญของมาตรฐาน

การใช้งานที่ดีที่สุด

  • ใบแจ้งหนี้ทั่วพื้นที่ยูโร
  • ค่าธรรมเนียมชมรมและสมาคม
  • การชำระค่าเช่าและค่าบริการ
  • การบริจาคในยุโรป

วางโค้ดไว้ตรงจุดที่การตัดสินใจเกิดขึ้นพอดี — บนโต๊ะ เคาน์เตอร์ บรรจุภัณฑ์ การ์ดเชิญ หรือหน้าจอ — และให้คำแนะนำสั้น ๆ หนึ่งบรรทัดแก่ผู้คน เช่น “สแกนเพื่อเปิด” หรือ “สแกนเพื่อจ่ายเงิน” พิมพ์โค้ดให้กว้างอย่างน้อย 2 cm โดยมีขอบสีขาวเงียบและคอนทราสต์ที่แข็งแกร่ง เพื่อให้กล้องโทรศัพท์รุ่นเก่าอ่านได้เร็ว สำหรับโปสเตอร์ที่สแกนจากระยะไกล ให้ใช้ขนาด 1024 px และพิมพ์ให้ใหญ่ขึ้น — หลักที่ดีคือประมาณหนึ่งในสิบของระยะการสแกน

วิธีการทำงาน

บรรทัดข้อมูล: BCD / 002 / 1 / SCT / BIC / ชื่อ / IBAN / จำนวนเงิน-EUR / (วัตถุประสงค์ว่าง) / เลขอ้างอิง-หรือ-ข้อความ — เชื่อมด้วยตัวแบ่งบรรทัด รูปแบบ EPC069-12 ที่แอปธนาคารแยกวิเคราะห์ จำนวนเงินถูกปรับให้เป็นทศนิยมสองตำแหน่งด้วยจุด และช่องว่างของ IBAN ถูกตัดออกโดยอัตโนมัติ

ตัวอย่างที่ทำแล้ว

ครูสอนดนตรีใน Utrecht พิมพ์โค้ดลงบนใบแจ้งหนี้ของแต่ละเทอมเป็นเงิน EUR 180 พร้อมเลขอ้างอิง RF ของนักเรียน ผู้ปกครองสแกนด้วยแอปธนาคารของตน การชำระเงินมาถึงพร้อมการจับคู่ล่วงหน้า และสเปรดชีตกระทบยอดของเธอเติมตัวเอง

คำถามที่พบบ่อย

เครื่องสร้างการชำระเงิน SEPA (EPC) นี้ฟรีไหม?

ใช่ เครื่องสร้างการชำระเงิน SEPA (EPC)ของ Loona ฟรีอย่างสมบูรณ์โดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดจำนวนโค้ดที่คุณสร้าง สำหรับการใช้งานส่วนตัวหรือเชิงพาณิชย์

คิวอาร์โค้ดของฉันจะหมดอายุไหม?

ไม่ Loona สร้างคิวอาร์โค้ดแบบคงที่: ข้อมูลของคุณถูกเข้ารหัสโดยตรงภายในลวดลายคิวอาร์โค้ดเอง ไม่ได้เก็บบนเซิร์ฟเวอร์หรือซ่อนอยู่หลังการเปลี่ยนเส้นทางแบบเสียเงิน โค้ดที่คุณพิมพ์วันนี้จะยังคงใช้งานได้ตราบเท่าที่ตัวปลายทางเองยังคงใช้งานอยู่

ข้อมูลของฉันเป็นส่วนตัวในหน้าการชำระเงิน SEPA (EPC) นี้ไหม?

ใช่ การสร้างเกิดขึ้น 100% ในเบราว์เซอร์ของคุณโดยใช้ JavaScript ไม่มีอะไรที่คุณกรอกถูกส่งไปหรือเก็บบนเซิร์ฟเวอร์ใด ๆ

BIC จำเป็นไหม?

ภายในพื้นที่ SEPA เวอร์ชัน 002 ของมาตรฐานทำให้ BIC เป็นทางเลือก — IBAN นำทางการชำระเงิน ฟิลด์อยู่ที่นั่นสำหรับธนาคารและช่องทางที่ยังคงขออยู่

ทำไมฉันให้ทั้งเลขอ้างอิงและข้อความไม่ได้?

มาตรฐาน EPC อนุญาตช่องการโอนเงินหนึ่งช่องต่อโค้ด: เลขอ้างอิง RF แบบมีโครงสร้างหรือข้อความไม่มีโครงสร้าง หากคุณให้เลขอ้างอิง RF มันจะใช้ช่องนั้น — ตรงตามที่แอปธนาคารคาดหวัง
