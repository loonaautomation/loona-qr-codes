เครื่องสร้างบาร์โค้ด Data Matrix ฟรี

สร้างบาร์โค้ด Data Matrix ที่ถูกต้องตามมาตรฐานได้ในไม่กี่วินาที ฟรี ไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ — สร้างแบบส่วนตัวในเบราว์เซอร์ของคุณ

ข้อความ ตัวเลข หรือ URL — สูงสุดประมาณ 2,300 ตัวอักษร

บาร์โค้ดของคุณ

เป็นส่วนตัว 100%: บาร์โค้ดถูกวาดภายในเบราว์เซอร์ของคุณ สิ่งที่คุณพิมพ์จะไม่ถูกอัปโหลดไปยังเซิร์ฟเวอร์ใด ๆ

วิธีสร้างหนึ่งโค้ดใน 3 ขั้นตอน

  1. ใส่รายละเอียดของคุณ ในแบบฟอร์มข้างต้น — เฉพาะฟิลด์สำหรับประเภทนี้ ไม่มีอะไรเพิ่มเติม
  2. ตรวจสอบตัวอย่างสด และปรับแต่งสี พื้นหลัง และขนาด (256, 512 หรือ 1024 px) ให้ตรงกับแบรนด์หรือสื่อสิ่งพิมพ์ของคุณ
  3. คลิกดาวน์โหลด PNG, สแกนทดสอบโค้ดหนึ่งครั้งด้วยโทรศัพท์ของคุณ แล้วพิมพ์หรือแชร์ไปยังทุกที่ที่ผู้ชมของคุณอยู่

เกี่ยวกับ Data Matrix นี้

Data Matrix (ISO/IEC 16022, ECC 200) คือโค้ด 2D ของอุตสาหกรรมและการแพทย์: มันเก็บข้อมูลจริงในสี่เหลี่ยมขนาดเท่าเล็บมือ — กว้างเพียงไม่กี่มิลลิเมตร — และยังอ่านได้แม้สัญลักษณ์เสียหายสูงสุดประมาณ 25% ด้วยการแก้ไขข้อผิดพลาดแบบ Reed–Solomon GS1 DataMatrix เป็นโค้ดที่กำหนดสำหรับยาและอุปกรณ์การแพทย์ทั่วทั้งสหภาพยุโรปและสหรัฐอเมริกา (UDI) และผู้ผลิตอิเล็กทรอนิกส์สลักมันด้วยเลเซอร์ลงบนชิ้นส่วนโดยตรง

ต่างจาก QR มันไม่มีสี่เหลี่ยมค้นหาแบบตกแต่งที่มุม — กรอบทึบรูปตัว L พร้อมรางนาฬิกาของโมดูลสลับกันบอกสแกนเนอร์ว่าข้อมูลอยู่ที่ไหน

การใช้งานที่ดีที่สุด

  • แพ็กยาและอุปกรณ์การแพทย์ (GS1/UDI)
  • อิเล็กทรอนิกส์ที่สลักด้วยเลเซอร์และชิ้นส่วนเครื่องยนต์
  • การติดตามชิ้นส่วนอากาศยาน
  • ป้ายขนาดเล็กที่ QR ไม่พอดี

วางโค้ดไว้ตรงจุดที่การตัดสินใจเกิดขึ้นพอดี — บนโต๊ะ เคาน์เตอร์ บรรจุภัณฑ์ การ์ดเชิญ หรือหน้าจอ — และให้คำแนะนำสั้น ๆ หนึ่งบรรทัดแก่ผู้คน เช่น “สแกนเพื่อเปิด” หรือ “สแกนเพื่อจ่ายเงิน” พิมพ์โค้ดให้กว้างอย่างน้อย 2 cm โดยมีขอบสีขาวเงียบและคอนทราสต์ที่แข็งแกร่ง เพื่อให้กล้องโทรศัพท์รุ่นเก่าอ่านได้เร็ว สำหรับโปสเตอร์ที่สแกนจากระยะไกล ให้ใช้ขนาด 1024 px และพิมพ์ให้ใหญ่ขึ้น — หลักที่ดีคือประมาณหนึ่งในสิบของระยะการสแกน

วิธีการทำงาน

การเข้ารหัสทำงานบนไลบรารี bwip-js ที่มาพร้อมกัน (เวอร์ชันเบราว์เซอร์ของ BWIPP ตัวเข้ารหัสที่ซอฟต์แวร์ป้ายไว้วางใจ) สร้างสัญลักษณ์ ECC 200 ที่แท้จริง — ไม่ใช่คิวอาร์โค้ดในรูปลักษณ์อื่น ความจุเริ่มจากอักขระไม่กี่ตัวในสัญลักษณ์ 10×10 ไปจนถึงอักขระตัวอักษรและตัวเลขประมาณ 2,335 ตัวที่ 144×144

ตัวอย่างที่ทำแล้ว

ผู้ผลิต PCB สลักแผงวงจรแต่ละแผ่นด้วย Data Matrix ที่บรรจุข้อมูลการตรวจสอบย้อนกลับในรูปแบบ LOT-8841;EXP-2027-05 ขนาด 5 mm สิบปีต่อมา ช่างเทคนิคสแกนแผงวงจรและบันทึกการผลิตฉบับเต็มก็เปิดขึ้น

คำถามที่พบบ่อย

เครื่องสร้าง Data Matrix นี้ฟรีไหม?

ใช่ เครื่องสร้างData Matrixของ Loona ฟรีอย่างสมบูรณ์โดยไม่ต้องสมัครสมาชิก ไม่มีลายน้ำ และไม่มีขีดจำกัดจำนวนโค้ดที่คุณสร้าง สำหรับการใช้งานส่วนตัวหรือเชิงพาณิชย์

คิวอาร์โค้ดของฉันจะหมดอายุไหม?

ไม่ Loona สร้างคิวอาร์โค้ดแบบคงที่: ข้อมูลของคุณถูกเข้ารหัสโดยตรงภายในลวดลายคิวอาร์โค้ดเอง ไม่ได้เก็บบนเซิร์ฟเวอร์หรือซ่อนอยู่หลังการเปลี่ยนเส้นทางแบบเสียเงิน โค้ดที่คุณพิมพ์วันนี้จะยังคงใช้งานได้ตราบเท่าที่ตัวปลายทางเองยังคงใช้งานอยู่

ข้อมูลของฉันเป็นส่วนตัวในหน้า Data Matrix นี้ไหม?

ใช่ การสร้างเกิดขึ้น 100% ในเบราว์เซอร์ของคุณโดยใช้ JavaScript ไม่มีอะไรที่คุณกรอกถูกส่งไปหรือเก็บบนเซิร์ฟเวอร์ใด ๆ

Data Matrix หรือคิวอาร์โค้ด — อันไหน?

Data Matrix เมื่อขนาดเล็กมาก พื้นผิวเป็นชิ้นส่วนหรือแพ็ก หรือกฎอุตสาหกรรม (UDI ของยา GS1 สำหรับการแพทย์) ระบุชื่อมัน คิวอาร์โค้ดเมื่อประชาชนทั่วไปต้องสแกนมัน — กล้องโทรศัพท์ทุกเครื่องอ่านคิวอาร์โค้ดได้ในตัว ในขณะที่ Data Matrix มักต้องการแอปสแกนที่เหมาะสม

กล้องโทรศัพท์สามารถสแกน Data Matrix ได้ไหม?

โทรศัพท์รุ่นใหม่จำนวนมากและแอปสแกนเฉพาะส่วนใหญ่ทำได้ กล้องมาตรฐานบางตัวทำไม่ได้ สำหรับการใช้งานที่เผชิญผู้บริโภค ควรเลือกคิวอาร์โค้ด
