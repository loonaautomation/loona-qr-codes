मुफ़्त Code 128 बारकोड जनरेटर

सेकंडों में एक मानक-सही Code 128 बारकोड बनाएँ। मुफ़्त, कोई साइन-अप नहीं, कोई वॉटरमार्क नहीं — आपके ब्राउज़र में निजी रूप से बनाया गया।

अक्षर, संख्याएँ और विराम चिह्न — लगभग कोई भी लंबाई।

आपका बारकोड

100% निजी: बारकोड आपके ब्राउज़र के अंदर बनाया जाता है। आप जो लिखते हैं वह किसी भी सर्वर पर अपलोड नहीं होता।

3 चरणों में एक कैसे बनाएँ

  1. अपना विवरण लिखें ऊपर के फ़ॉर्म में — केवल इस प्रकार के फ़ील्ड, कुछ अतिरिक्त नहीं।
  2. लाइव पूर्वावलोकन जाँचें और रंग, पृष्ठभूमि और आकार (256, 512 या 1024 px) को अपने ब्रांड या प्रिंट से मेल खाने के लिए अनुकूलित करें।
  3. Download PNG पर क्लिक करें, कोड को अपने फ़ोन से एक बार टेस्ट-स्कैन करें, फिर इसे प्रिंट करें या जहाँ आपके दर्शक हों वहाँ साझा करें।

इस Code 128 के बारे में

Code 128 (ISO/IEC 15417) दुनिया का सामान्य-उद्देश्य उच्च-घनत्व बारकोड है: यह अक्षरों, संख्याओं और विराम चिह्नों को किसी भी 1D सिम्बोलॉजी की सबसे संकीर्ण चौड़ाई में पैक करता है, इसीलिए यह शिपिंग लेबल (GS1-128 के रूप में), गोदाम रैकिंग, परिसंपत्ति टैग और पुस्तकालय प्रणालियों पर हावी है।

यह तीन वर्ण उपसमूहों में काम करता है — A (बड़े अक्षर + नियंत्रण कोड), B (पूरा मिश्रित-अक्षर ASCII) और C (दोहरे-घनत्व अंक जोड़े) — और एक अच्छा एनकोडर प्रतीक को छोटा रखने के लिए उपसमूहों को अपने आप बदलता है। हर Code 128 प्रतीक एक अंतर्निहित modulo-103 चेकसम रखता है, इसलिए स्कैनर अनुमान लगाने के बजाय क्षतिग्रस्त पढ़ने को अस्वीकार करते हैं।

सर्वोत्तम उपयोग

  • गोदाम और इन्वेंटरी लेबल
  • शिपिंग और पैलेट लेबल (GS1-128)
  • परिसंपत्ति और उपकरण टैग
  • पुस्तकालय और संग्रह वस्तुएँ

कोड ठीक वहाँ लगाएँ जहाँ निर्णय लिया जाता है — मेज़, काउंटर, पैकेजिंग, निमंत्रण या स्क्रीन पर — और लोगों को एक छोटी पंक्ति का निर्देश दें जैसे “Scan to open” या “Scan to pay”। कोड कम से कम 2 cm चौड़े एक शांत सफ़ेद बॉर्डर और मज़बूत कंट्रास्ट के साथ प्रिंट करें ताकि पुराने फ़ोन कैमरे उन्हें जल्दी पढ़ें; दूरी से स्कैन किए जाने वाले पोस्टरों के लिए, 1024 px आकार का उपयोग करें और बड़ा प्रिंट करें — एक अच्छा मार्गदर्शक स्कैनिंग दूरी का लगभग दसवाँ हिस्सा है।

यह कैसे काम करता है

जब आप टाइप करते हैं, तो एन्कोडर उपसमूह मिश्रण अपने आप चुनता है: लंबे अंक रन उपसमूह C से संपीड़ित होते हैं (प्रति वर्ण दो अंक), इसीलिए एक 20-अंकों का सीरियल आश्चर्यजनक रूप से छोटा बारकोड बनाता है।

कार्यित उदाहरण

एक मरम्मत दुकान हर ग्राहक डिवाइस पर Code 128 टैग लगाती है जो कार्य संख्या एनकोड करते हैं, उदाहरण के लिए INV-2026-0042। चेक-इन और प्रेषण पर टैग स्कैन किया जाता है — कोई टाइपिंग नहीं, कोई अंक उलट-पुलट नहीं — और कार्य इतिहास तुरंत खुलता है।

अक्सर पूछे जाने वाले प्रश्न

क्या यह Code 128 जनरेटर मुफ़्त है?

हाँ। Loona का Code 128 जनरेटर पूरी तरह मुफ़्त है बिना साइनअप, बिना वॉटरमार्क और आपके द्वारा बनाए जाने वाले कोडों की संख्या पर बिना किसी सीमा के, व्यक्तिगत या व्यावसायिक उपयोग के लिए।

क्या मेरा QR कोड समाप्त होगा?

नहीं। Loona स्थिर QR कोड बनाता है: आपकी जानकारी सीधे QR पैटर्न के अंदर ही एन्कोड होती है, किसी सर्वर पर संग्रहीत नहीं होती या किसी सशुल्क पुनर्निर्देशन के पीछे छिपी नहीं होती। आज प्रिंट किया गया कोड तब तक काम करता रहेगा जब तक गंतव्य स्वयं सक्रिय रहता है।

क्या इस Code 128 पेज पर मेरी जानकारी निजी है?

हाँ। निर्माण JavaScript का उपयोग करके 100% आपके ब्राउज़र में होता है। आप जो कुछ भी दर्ज करते हैं वह किसी सर्वर पर भेजा या संग्रहीत नहीं किया जाता।

Code 128 बनाम Code 39 — मुझे किसका उपयोग करना चाहिए?

लगभग हर आधुनिक चीज़ के लिए Code 128: यह सघन है, छोटे अक्षरों और विराम चिह्नों का समर्थन करता है, और इसमें एक अनिवार्य चेकसम होता है। Code 39 मुख्यतः वहाँ बचता है जहाँ पुराने स्कैनर या एक उद्योग नियम (कुछ ऑटोमोटिव और रक्षा लेबल) इसकी माँग करते हैं।

क्या Code 128 छोटे अक्षरों को एनकोड कर सकता है?

हाँ — उपसमूह B छोटे अक्षरों समेत पूर्ण मुद्रण योग्य ASCII सीमा को कवर करता है, और यह जनरेटर उपसमूहों को अपने आप बदलता है।
