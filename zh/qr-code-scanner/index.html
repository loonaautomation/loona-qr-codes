    工作原理
    

    二维码或条形码只是一个将文本编码为浅色和深色模块的图案。解码是生成的逆过程：在图片中找到图案，测量模块，使用条码内置的冗余纠正错误，并将比特转化回字符。jsQR 通过定位三个定位方块并采样网格来为二维码做这件事；ZXing 通过扫描条纹上的像素行并将宽度与 EAN、UPC、Code 128 或 Code 39 规则匹配来为条形码做这件事，包括验证零售条形码的最后校验位。在摄像头模式下，您的浏览器自己的 BarcodeDetector 在实时视频帧上持续执行相同的工作，直到找到条码。在批量模式下，相同的两个图片解码器对每个文件运行一次，每个结果 — 文件名、格式、类型和解码文本 — 都被收集到一个您可以导出为 CSV 的表中。
    

    方法： 选择摄像头或图片 → 让设备上的解码器读取图案 → 检查类型、格式和原始内容 → 使用智能操作（打开、复制、保存联系人）→ 随时在会话历史中找到该扫描。

    常见问题
    

    我可以从同一手机上的截图扫描二维码吗？
    

    是的。将截图保存或分享到您的照片应用，然后使用此处的图片上传并选择该截图。在计算机上，只需复制图片并用 Ctrl+V（或 Mac 上的 Cmd+V）粘贴到此页面 — 无需保存文件。
    

    结果看起来像 WIFI:T:WPA;S:… — 那是什么意思？
    

    那是 WiFi 二维码内部的标准原始格式：T 是安全类型，S 是网络名称 (SSID)，P 是密码。此页面还在原始内容上方单独显示这三个值，因此您不必自己挑选它们。
    

    我如何将扫描的联系人添加到我的手机？
    

    当扫描是 vCard 时，出现“下载联系人 (.vcf)”操作。下载文件并打开它 — 手机和电脑提供将其保存为联系人，姓名、组织、电话、电子邮件和网站已填写。
    

    为什么我的照片没有解码？
    

    通常的原因是二维码在一张大照片中很小、模糊、眩光、撕裂或低对比度的打印件，或截图在二维码周围裁剪得太紧（解码器需要二维码周围的白色静区）。宽松裁剪，近距离、正面重新拍照，然后再试一次。
    

    我应该信任在公共场合找到的二维码吗？
    

    先在这里扫描，而不是用自动打开结果的应用：此页面只 显示 向您展示解码的内容，从不自己打开任何东西。在点击“打开链接”之前，检查链接是否真的指向其标签承诺的地方 — 这一个习惯可以击败大多数贴纸覆盖真实二维码的诈骗。
