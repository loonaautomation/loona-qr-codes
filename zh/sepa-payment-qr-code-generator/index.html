关于此 SEPA (EPC) 付款

EPC 二维码（GiroCode 和 Paylib 样式代码背后的标准）是现在欧洲大部分地区支付发票的方式：银行应用扫描二维码并预先填写 SEPA 转账 — 受益人、IBAN、金额和参考 — 因此经典的 IBAN 输入错误消失，付款与正确的发票匹配到达。

该格式由欧洲支付委员会固定 (EPC069-12)：BCD 服务标签、版本 002、UTF-8、SCT 转账。此生成器完全按此构建该载荷，包括在结构化 RF 债权人参考和自由汇款文本之间选择 — 您不能两者兼得，表单强制执行标准的优先级。

BIC 是必填的吗？

在 SEPA 区域内，标准的 002 版本使 BIC 可选 — IBAN 路由付款。该字段为仍然要求它的银行和通道存在。
