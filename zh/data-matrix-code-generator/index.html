关于此 Data Matrix

Data Matrix (ISO/IEC 16022, ECC 200) 是工业和医疗的 2D 码：它将真实数据存储在指甲大小的正方形中 — 几毫米宽 — 由于 Reed–Solomon 纠错，即使符号损坏高达约 25%，仍可读取。GS1 DataMatrix 是欧盟和美国药品和医疗器械（UDI）上强制使用的条码，电子产品制造商将其直接激光蚀刻到零件上。

与二维码不同，它在角落没有装饰性的定位方块 — L 形的实心边框加上交替模块的时钟轨道告诉扫描仪数据所在的位置。

最佳用途

  • 药品和医疗器械包装 (GS1/UDI)
  • 激光蚀刻的电子产品和发动机零件
  • 航空航天零部件跟踪
  • 二维码放不下的小标签

工作原理

编码在内置的 bwip-js 库（BWIPP 的浏览器移植版，标签软件信任的编码器）上运行，产生真正的 ECC 200 符号 — 而不是换了皮肤的二维码。容量从 10×10 符号中的几个字符，到 144×144 时约 2,335 个字母数字字符。
