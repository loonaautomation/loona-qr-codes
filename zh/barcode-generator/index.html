关于条形码和五种类型

条形码将短代码转化为扫描仪在几分之一秒内读取的条纹图案。不同的工作使用不同的条形码类型（称为符号系统），选择正确的很重要：商店收银台期望 EAN-13 或 UPC-A，仓库对 Code 128 满意，运输纸箱使用 ITF-14。

  • Code 128 — 通用主力。编码字母、数字和标点，几乎任何长度，并保持紧凑。最适合库存标签、资产标签、图书馆和身份证，以及任何类型的内部跟踪。
  • Code 39 — 较旧、更简单的标准。仅大写字母、数字和符号 - . $ / + % 和空格。得到较旧扫描仪的广泛支持；常用于军事、汽车和简单资产标签。
  • EAN-13 — 北美以外的零售标准。恰好 13 位数字：您的 12 位数字加上计算的校验位。产品号码必须向 GS1 注册才能用于零售销售（请参阅下面的常见问题）。
  • UPC-A — 美国和加拿大的零售标准。恰好 12 位数字：您的 11 位数字加上校验位，也通过 GS1 颁发用于零售。
  • ITF-14 — 运输纸箱标准。恰好 14 位数字（13 加校验位），大尺寸打印在箱子上，因此整个纸箱无需打开即可扫描。

关于零售类型的一个诚实警告：此生成器产生一个 结构正确 任何扫描仪都可以读取的条形码，这正是库房、货架、学校和办公室库存、活动通行证和内部标签所需要的。但如果条形码将在商店收银台或在线市场被扫描，号码本身必须正式属于您 — 在您的公司下向 GS1 注册。在零售号码上发明的风险是将另一家公司的产品代码打印在您的商品上。

常见问题

条形码和二维码有什么区别？

条形码是一维的：它存储一个短代码（通常只是数字或简短的 ID），数据库然后查找它。二维码是二维的，可以存储更多 — 完整的链接、WiFi 密码或联系人卡片 — 并由手机摄像头读取。如果涉及扫描枪或收银台，请使用条形码；如果涉及手机摄像头，二维码通常更好。

为什么我的 EAN-13 号码被拒绝？

要么它包含数字以外的内容，要么其长度不是 12 或 13 位数字，要么第 13 位数字与计算的校验位不匹配。预览下方的消息会告诉您校验位应该是哪个数字，以便您发现输入错误。

我可以更改条形码的颜色吗？

是的 — 条纹颜色和背景在预览上方。扫描仪读取对比度，而不是颜色本身，因此深色条纹（黑色、深蓝色、深绿色）在白色或浅色背景上效果最好。避免红色条纹：许多激光扫描仪使用红光，无法看到它们。

PNG 还是 SVG — 我应该下载哪个？

对于任何将专业打印或放大的内容，请选择 SVG，因为它可以缩放到任何尺寸而不会模糊。对于文档、电子表格、幻灯片和快速办公打印，请选择 PNG。

一个条形码可以保存长消息或网页链接吗？

不太好。条形码是为短代码设计的；长链接会使 Code 128 极其密集，许多扫描仪难以处理。对于链接和更长的内容，请改用我们的二维码生成器之一 — 这正是二维码被发明的原因。
