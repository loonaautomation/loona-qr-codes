Acerca de este FaceTime

Los enlaces de FaceTime usan el esquema facetime:: escanea el código en un iPhone, iPad o Mac y la llamada a ese correo o número de ID de Apple se inicia. El uso estrella es la tarjeta de contacto impresa — en la nevera, en el paquete de cuidados, en el mostrador de asistencia — donde la persona que llama no debería tener que buscar contactos, deletrear nombres ni recordar nada.

El límite obvio es solo Apple: los dispositivos Android y Windows no tienen un gestor de FaceTime. Para públicos mixtos, imprime un código de WhatsApp junto a él — juntos cubren efectivamente a todos.

Mejores usos

  • Tarjetas de contacto familiares
  • Paquetes de cuidados y asistencia
  • Servicios de asistencia del ecosistema Apple
  • Tarjetas de ventas y consultas

Pon el código exactamente donde se toma la decisión — en la mesa, el mostrador, el envase, la invitación o la pantalla — y da a la gente una frase corta de instrucción como «Escanea para abrir» o «Escanea para pagar». Imprime los códigos al menos a 2 cm de ancho con un borde blanco tranquilo y un contraste fuerte para que las cámaras de teléfonos más antiguos los lean rápidamente; para pósteres escaneados desde lejos, usa el tamaño de 1024 px e imprime más grande — una buena referencia es aproximadamente una décima parte de la distancia de escaneo.

Cómo funciona

La carga es facetime:CONTACT — el esquema registrado que los dispositivos Apple gestionan de forma nativa. No se necesita nada más; el dispositivo receptor resuelve el contacto.

Ejemplo resuelto

Una hija imprime una tarjeta para la nevera de su padre en el extranjero: un código grande, «Escanea para llamar a Ayesha». Las llamadas de los domingos dejan de necesitar primero un mensaje recordatorio.

Preguntas frecuentes

¿Es gratuito este generador de FaceTime?

Sí. El generador de FaceTime de Loona es completamente gratuito, sin registro, sin marca de agua y sin límite de cuántos códigos creas, para uso personal o comercial.

¿Caducará mi código QR?

No. Loona crea códigos QR estáticos: tu información se codifica directamente dentro del propio patrón QR, no se almacena en un servidor ni se oculta tras una redirección de pago. Un código que imprimes hoy seguirá funcionando mientras el propio destino se mantenga activo.

¿Mi información es privada en esta página de FaceTime?

Sí. La generación ocurre al 100% en tu navegador usando JavaScript. Nada de lo que introduces se envía a ningún servidor ni se almacena en él.

¿Vídeo o audio?

El esquema facetime: inicia una videollamada por defecto. Solo para audio, Apple usa facetime-audio: — si eso es lo que necesitas, genera un código de texto con el esquema de audio o usa el generador de teléfono.

¿Puedo usar un enlace web de FaceTime en su lugar?

Los enlaces de FaceTime compartibles de Apple (desde la aplicación) también funcionan en la web — pega uno de esos enlaces en el generador de URL para obtener un código que lo abra.
