Acerca de este MSI Plessey

MSI (Modified Plessey) es un código de barras numérico nacido en el comercio minorista de la década de 1970 y que ahora vive sobre todo en almacenes, bibliotecas y control de inventario — las etiquetas de borde de estantería, los contenedores de stock y los sistemas bibliotecarios más antiguos siguen funcionando con él. Cada dígito son cuatro barras y cuatro espacios, lo que lo hace fácil de imprimir pero imposible de usar para letras.

MSI se combina normalmente con un dígito de control módulo 10 (a veces dos, o módulo 11), y un sistema que espere el dígito de control rechazará los números sin él — comprueba la configuración de tu escáner antes de imprimir un lote.

Mejores usos

  • Etiquetas de estanterías y contenedores de almacenes
  • Inventario de biblioteca (sistemas heredados)
  • Etiquetas de control de stock
  • Numeración de socios e identificaciones

Pon el código exactamente donde se toma la decisión — en la mesa, el mostrador, el envase, la invitación o la pantalla — y da a la gente una frase corta de instrucción como «Escanea para abrir» o «Escanea para pagar». Imprime los códigos al menos a 2 cm de ancho con un borde blanco tranquilo y un contraste fuerte para que las cámaras de teléfonos más antiguos los lean rápidamente; para pósteres escaneados desde lejos, usa el tamaño de 1024 px e imprime más grande — una buena referencia es aproximadamente una décima parte de la distancia de escaneo.

Cómo funciona

Este generador codifica los dígitos que das; si tu sistema espera un dígito de control Mod 10, inclúyelo como el dígito final — el ejemplo de la página muestra la forma simple que la mayoría de las herramientas de etiquetas aceptan.

Una tienda de repuestos imprime etiquetas MSI para 400 estanterías. Los números de estantería se escanean en el lector de cuña más antiguo del mostrador, que se configuró para MSI hace décadas y sigue funcionando a diario.

Preguntas frecuentes

¿Es gratuito este generador de MSI Plessey?

Sí. El generador de MSI Plessey de Loona es completamente gratuito, sin registro, sin marca de agua y sin límite de cuántos códigos creas, para uso personal o comercial.

¿Caducará mi código QR?

No. Loona crea códigos QR estáticos: tu información se codifica directamente dentro del propio patrón QR, no se almacena en un servidor ni se oculta tras una redirección de pago. Un código que imprimes hoy seguirá funcionando mientras el propio destino se mantenga activo.

¿Mi información es privada en esta página de MSI Plessey?

Sí. La generación ocurre al 100% en tu navegador usando JavaScript. Nada de lo que introduces se envía a ningún servidor ni se almacena en él.

¿Por qué mi escáner no leerá MSI?

Muchos escáneres modernos se envían con MSI desactivado porque es raro en el comercio minorista. Activa MSI (y el modo de dígito de control correcto) en los ajustes del escáner.

¿MSI o Code 128 para un sistema nuevo?

Code 128 — MSI es una opción de mantener lo heredado. Los sistemas nuevos no ganan nada con las limitaciones de MSI.
