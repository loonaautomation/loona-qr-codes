Acerca de este pago SEPA (EPC)

El código QR EPC (el estándar detrás de GiroCode y los códigos de estilo Paylib) es como gran parte de Europa paga ahora las facturas: la aplicación bancaria escanea el código y rellena previamente la transferencia SEPA — beneficiario, IBAN, importe y referencia — así que desaparece el clásico error al escribir el IBAN y los pagos llegan relacionados con la factura correcta.

El formato lo fija el Consejo Europeo de Pagos (EPC069-12): etiqueta de servicio BCD, versión 002, UTF-8, transferencia SCT. Este generador construye esa carga exactamente, incluida la elección entre una referencia RF estructurada del acreedor y texto libre de remesa — no puedes tener ambos, y el formulario impone la prioridad del estándar.

Mejores usos

  • Facturas en toda la zona euro
  • Cuotas de clubes y asociaciones
  • Pagos de alquiler y servicios

Pon el código exactamente donde se toma la decisión — en la mesa, el mostrador, el envase, la invitación o la pantalla — y da a la gente una frase corta de instrucción como «Escanea para abrir» o «Escanea para pagar». Imprime los códigos al menos a 2 cm de ancho con un borde blanco tranquilo y un contraste fuerte para que las cámaras de teléfonos más antiguos los lean rápidamente; para pósteres escaneados desde lejos, usa el tamaño de 1024 px e imprime más grande — una buena referencia es aproximadamente una décima parte de la distancia de escaneo.

Cómo funciona

Líneas de la carga: BCD / 002 / 1 / SCT / BIC / nombre / IBAN / importe en EUR / (concepto vacío) / referencia o texto — unidas por saltos de línea, el diseño EPC069-12 que analizan las aplicaciones bancarias. Los importes se normalizan a dos decimales con un punto, y los espacios del IBAN se eliminan automáticamente.

Preguntas frecuentes

¿Es gratuito este generador de pago SEPA (EPC)?

Sí. El generador de pago SEPA (EPC) de Loona es completamente gratuito, sin registro, sin marca de agua y sin límite de cuántos códigos creas, para uso personal o comercial.

¿Caducará mi código QR?

No. Loona crea códigos QR estáticos: tu información se codifica directamente dentro del propio patrón QR, no se almacena en un servidor ni se oculta tras una redirección de pago. Un código que imprimes hoy seguirá funcionando mientras el propio destino se mantenga activo.

¿Mi información es privada en esta página de pago SEPA (EPC)?

Sí. La generación ocurre al 100% en tu navegador usando JavaScript. Nada de lo que introduces se envía a ningún servidor ni se almacena en él.

¿Es obligatorio el BIC?

Dentro del área SEPA, la versión 002 del estándar hace el BIC opcional — el IBAN dirige el pago. El campo está ahí para los bancos y corredores que aún lo piden.

¿Por qué no puedo dar tanto una referencia como un texto?

El estándar EPC permite un espacio de remesa por código: o una referencia RF estructurada o texto no estructurado. Si proporcionas una referencia RF, esta ocupa el espacio — exactamente como esperan las aplicaciones bancarias.
