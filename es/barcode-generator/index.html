Cómo crear un código de barras en 3 pasos

  1. Escribe el contenido y elige el tipo de código de barras. Para EAN-13, UPC-A e ITF-14, introduce el número sin su último dígito de control — el generador lo calcula y lo añade, o lo verifica si escribes el número completo.

Acerca de los códigos de barras y los cinco tipos

Un código de barras convierte un código corto en un patrón de barras que un escáner lee en una fracción de segundo. Los distintos trabajos usan distintos tipos de código de barras (llamados simbologías), y elegir el correcto importa: la caja de una tienda espera EAN-13 o UPC-A, un almacén está contento con Code 128, y una caja de envío usa ITF-14.

  • Code 128 — el caballo de batalla de uso general. Codifica letras, números y signos de puntuación en casi cualquier longitud, y se mantiene compacto. El mejor para etiquetas de inventario, etiquetas de activos, tarjetas de biblioteca y de identificación, y seguimiento interno de cualquier tipo.
  • Code 39 — el estándar más antiguo y sencillo. Solo letras mayúsculas, dígitos y los símbolos - . $ / + % y el espacio. Muy ampliamente compatible con escáneres antiguos; común para etiquetas militares, de automoción y de activos sencillos.
  • EAN-13 — el estándar de venta al por menor fuera de Norteamérica. Exactamente 13 dígitos: tus 12 dígitos más un dígito de control calculado. Los números de producto deben registrarse en GS1 para usarse en la venta al por menor (consulta la FAQ de abajo).
  • UPC-A — el estándar de venta al por menor en EE. UU. y Canadá. Exactamente 12 dígitos: tus 11 dígitos más un dígito de control, también emitido a través de GS1 para uso en venta al por menor.
  • ITF-14 — el estándar de cajas de envío. Exactamente 14 dígitos (13 más el dígito de control), impreso en grande en las cajas para que una caja entera pueda escanearse sin abrirla.

Una advertencia honesta sobre los tipos minoristas: este generador produce un estructuralmente correcto código de barras que cualquier escáner puede leer, que es todo lo que necesitas para almacenes, estanterías, inventarios de escuelas y oficinas, pases de eventos y etiquetas internas. Pero si el código de barras se escaneará en una caja de tienda o por un marketplace en línea, el número en sí debe ser oficialmente tuyo — registrado en GS1 a nombre de tu empresa. Inventar un número de venta al por menor arriesga imprimir el código de producto de otra empresa en tus artículos.

Mejores usos de este generador de códigos de barras

  • Etiquetas de inventario y almacenes
  • Etiquetas de activos para equipos de escuela, oficina y taller
  • Etiquetas de ubicación de bordes de estantería y almacenes
  • Libros de biblioteca, tarjetas de identificación y tarjetas de socio
  • Marcado de cajas de envío con ITF-14

Sea cual sea el tipo que elijas, las reglas de escaneo son las mismas: imprime el código de barras a un tamaño razonable (al menos unos 3 cm de ancho para escáneres de mano), mantén un margen en blanco despejado — la zona de silencio — en ambos lados, y nunca estires ni aplastes la imagen, porque eso distorsiona los anchos de las barras que el escáner mide. Los archivos SVG se escalan sin distorsión y son la opción más segura para imprimir; PNG con una altura generosa está bien para pantallas e impresoras de oficina.

Preguntas frecuentes

¿Es gratuito este generador de códigos de barras?

Sí. El generador de barcode de Loona es completamente gratuito, sin registro, sin marca de agua y sin límite de cuántos códigos de barras creas, para uso personal o comercial.

¿Puedo usar un código de barras EAN-13 o UPC generado en productos que vendo en tiendas?

La imagen del código de barras es estructuralmente correcta y se escaneará, pero los códigos de barras minoristas deben registrarse: las tiendas y los mercados exigen números emitidos por GS1, la organización oficial, bajo tu propio prefijo de empresa. Un número que inventes aquí puede colisionar con el producto de otra persona. Para inventario, activos, estanterías y uso interno, los códigos de barras generados están bien; para la venta minorista, regístrate primero en GS1.

¿Qué es un dígito de control, y tengo que calcularlo yo?

EAN-13, UPC-A e ITF-14 terminan con un dígito de control calculado a partir de los demás dígitos, para que los escáneres puedan detectar lecturas erróneas. No necesitas calcularlo: introduce el número sin el dígito de control (12 dígitos para EAN-13, 11 para UPC-A, 13 para ITF-14) y este generador lo añade. Si introduces el número completo, el generador verifica el dígito de control y te dice si está mal.

Cómo funciona

Este generador usa la biblioteca JsBarcode, ejecutándose por completo en tu navegador, para traducir tu contenido al patrón de barras exacto del estándar elegido. Para los tipos minoristas numerados aplica primero la regla del dígito de control GS1: leyendo los dígitos desde la derecha, los dígitos alternos se multiplican por 3 y por 1, los resultados se suman, y el dígito de control es lo que haga que el total sea múltiplo de diez. Ese único dígito es como una caja sabe que leyó tu código de barras correctamente — si una barra está dañada y un dígito se lee mal, la suma ya no coincide y el escáner pita para un nuevo escaneo en lugar de cobrar el precio equivocado.

El método: elige el tipo → escribe el contenido (sin el dígito de control para EAN-13, UPC-A e ITF-14) → revisa la vista previa → descarga el PNG o SVG → imprime y escanea a modo de prueba.

Una bibliotecaria escolar quiere etiquetas para libros nuevos y elige Code 128 con los números de registro de su catálogo — LIB-1001, LIB-1002 y así sucesivamente. Preguntas frecuentes

¿Cuál es la diferencia entre un código de barras y un código QR?

Un código de barras es unidimensional: almacena un código corto (normalmente solo números o un ID breve) que una base de datos consulta después. Un código QR es bidimensional y puede almacenar mucho más — un enlace completo, la contraseña del WiFi o una tarjeta de contacto — y lo leen las cámaras de los teléfonos. Si interviene una pistola escáner o una caja registradora, usa un código de barras; si interviene la cámara de un teléfono, un código QR suele ser mejor.

¿Por qué se rechazó mi número EAN-13?

O contiene algo distinto de dígitos, o su longitud no es de 12 o 13 dígitos, o el dígito 13 no coincide con el dígito de control calculado. El mensaje bajo la vista previa te dice cuál debería ser el dígito de control, para que puedas detectar un error de escritura.

¿Puedo cambiar los colores del código de barras?

Sí — el color de las barras y el fondo están encima de la vista previa. Los escáneres leen el contraste, no el color en sí, así que barras oscuras (negro, azul oscuro, verde oscuro) sobre blanco o un fondo pálido funcionan mejor. Evita las barras rojas: muchos escáneres láser usan luz roja y no pueden verlas.

¿PNG o SVG — cuál debería descargar?

Elige SVG para cualquier cosa que se vaya a imprimir profesionalmente o ampliar, porque se escala a cualquier tamaño sin volverse borroso. Elige PNG para documentos, hojas de cálculo, diapositivas e impresión rápida de oficina.

¿Puede un código de barras contener un mensaje largo o un enlace web?

No muy bien. Los códigos de barras están diseñados para códigos cortos; un enlace largo crea un Code 128 extremadamente denso con el que muchos escáneres tienen dificultades. Para enlaces y contenido más largo, usa en su lugar uno de nuestros generadores de códigos QR — para eso exactamente se inventaron los códigos QR.
