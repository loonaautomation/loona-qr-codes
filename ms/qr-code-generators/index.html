Benamkan alat ini di laman web anda — percuma

Tambahkan alat ini ke laman web atau blog anda sendiri — ia percuma sepenuhnya, tidak memerlukan pendaftaran, dan sentiasa menunjukkan versi terkini. Salin kod di bawah dan tampalkannya ke halaman anda di tempat anda mahu alat itu muncul. Mengekalkan baris kredit kecil “Dikuasakan oleh Loona Automation” di bawah benam membantu mengekalkan alat ini percuma — tetapi anda bebas menggaya atau membuangnya; alat berfungsi dalam apa jua keadaan.
