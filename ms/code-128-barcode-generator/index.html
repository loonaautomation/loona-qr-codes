Tentang Code 128 Ini

Code 128 (ISO/IEC 15417) ialah kod bar berketumpatan tinggi kegunaan am dunia: ia membungkus huruf, nombor dan tanda baca ke dalam lebar paling sempit antara mana-mana simbologi 1D, sebab itulah ia menguasai label penghantaran (sebagai GS1-128), rak gudang, tag aset dan sistem perpustakaan.

Ia berfungsi dalam tiga subset aksara — A (huruf besar + kod kawalan), B (ASCII huruf bercampur penuh) dan C (pasangan digit berketumpatan berganda) — dan pengekod yang baik menukar subset secara automatik untuk mengekalkan simbol pendek. Setiap simbol Code 128 membawa jumlah semak modulo-103 terbina dalam, jadi pengimbas menolak bacaan rosak dan bukan meneka.

Kegunaan terbaik

  • Label gudang dan inventori
  • Penghantaran dan label palet (GS1-128)
  • Tag aset dan peralatan
  • Item perpustakaan dan arkib

Letakkan kod tepat di tempat keputusan dibuat — di atas meja, di kaunter, pada pembungkusan, pada jemputan atau pada skrin — dan berikan orang satu baris arahan pendek seperti “Imbas untuk buka” atau “Imbas untuk bayar”. Cetak kod sekurang-kurangnya 2 cm lebar dengan sempadan putih yang senyap dan kontras yang kuat supaya kamera telefon lama membacanya dengan cepat; untuk poster yang diimbas dari jauh, gunakan saiz 1024 px dan cetak lebih besar — panduan yang baik ialah kira-kira satu persepuluh daripada jarak imbasan.

Cara ia berfungsi

Apabila anda menaip, pengekod memilih campuran subset secara automatik: larian digit panjang dimampatkan dengan subset C (dua digit bagi setiap aksara), itulah sebabnya siri 20 digit menghasilkan kod bar yang menghairankan pendek.

Contoh yang diselesaikan

Kedai pembaikan melabelkan setiap peranti pelanggan dengan tag Code 128 yang mengekod nombor kerja, cth. INV-2026-0042. Semasa daftar masuk dan penghantaran tag diimbas — tiada penaipan, tiada digit tertukar — dan sejarah kerja terbuka serta-merta.

Soalan Lazim

Adakah penjana Code 128 ini percuma?

Ya. Penjana Code 128 Loona’s adalah percuma sepenuhnya tanpa pendaftaran, tanpa tera air dan tanpa had bilangan kod yang anda cipta, untuk kegunaan peribadi atau komersial.

Adakah kod QR saya akan luput?

Tidak. Loona mencipta kod QR statik: maklumat anda dikodkan terus di dalam corak QR itu sendiri, tidak disimpan pada pelayar atau disembunyikan di sebalik lencongan berbayar. Kod yang anda cetak hari ini akan terus berfungsi selagi destinasi itu sendiri kekal aktif.

Adakah maklumat saya peribadi di halaman Code 128 ini?

Ya. Penjanaan berlaku 100% dalam pelayar anda menggunakan JavaScript. Tiada apa yang anda masukkan dihantar atau disimpan pada mana-mana pelayan.

Code 128 vs Code 39 — yang mana patut saya gunakan?

Code 128 untuk hampir semua yang moden: ia lebih padat, menyokong huruf kecil dan tanda baca, dan mempunyai jumlah semak wajib. Code 39 kekal terutamanya di mana pengimbas lama atau peraturan industri (sesetengah label automotif dan pertahanan) menuntutnya.

Bolehkah Code 128 mengekod huruf kecil?

Ya — subset B meliputi julat ASCII boleh cetak penuh termasuk huruf kecil, dan penjana ini menukar subset secara automatik.
