מחולל ברקוד Code 39 חינמי

צרו ברקוד Code 39 תקני נכון בתוך שניות. חינם, ללא הרשמה, ללא סימן מים — נוצר באופן פרטי בדפדפן שלכם.

A-Z, 0-9, רווח ו- - . $ / + % בלבד. אותיות קטנות מומרות לאותיות גדולות.

הברקוד שלכם

פרטיות של 100%: הברקוד מצויר בתוך הדפדפן שלך. שום דבר שאתה מקליד אינו מועלה לשום שרת.

איך יוצרים אחד ב-3 שלבים

  1. הזינו את הפרטים שלכם בטופס שלמעלה — רק השדות לסוג זה, שום דבר נוסף.
  2. בדקו את התצוגה המקדימה החיה והתאימו אישית את הצבע, הרקע והגודל (256, 512 או 1024 px) כדי להתאים למותג או להדפסה שלכם.
  3. לחצו על הורד PNG, סרקו את הקוד פעם אחת לבדיקה עם הטלפון שלכם, ואז הדפיסו אותו או שתפו אותו בכל מקום שבו נמצא הקהל שלכם.

אודות Code 39 זה

Code 39 (USS Code 39, Code 3 of 9) הוא הברקוד האלפאנומרי הוותיק ביותר שעדיין בשימוש יומיומי — פותח ב-1974 ונשמר בחיים על ידי תוויות רכב, ביטחון, בריאות וממשלה שציינו אותו לפני עשרות שנים. כל תו הוא ברוחב תשעה אלמנטים (חמישה פסים, ארבעה רווחים, שלושה מהם רחבים), מה שהופך אותו לסובלני להדפסה גרועה אבל ארוך יחסית לנתונים שהוא נושא.

האלפבית שלו קטן: אותיות גדולות A–Z, ספרות וכמה סמלים. הוא בודק את עצמו (תו שגוי יחיד כמעט אף פעם אינו מתאמת), ואפשר להוסיף ספרת ביקורת אופציונלית במודולו-43 היכן שהמערכת המקבלת מצפה לאחת.

השימושים הטובים ביותר

  • תוויות ישנות של רכב וביטחון
  • תגי שם ותעודות זהות
  • ספרי ספרייה (מערכות ישנות)
  • פחי תעשייה ומחסני כלים

שימו את הקוד בדיוק במקום שבו מתקבלת ההחלטה — על השולחן, הדלפק, האריזה, ההזמנה או המסך — ותנו לאנשים שורת הוראה קצרה אחת כמו “Scan to open” או “Scan to pay”. הדפיסו קודים ברוחב של לפחות 2 cm עם גבול לבן שקט וניגודיות חזקה כדי שמצלמות טלפון ישנות יקראו אותם במהירות; לכרזות שנסרקות מרחוק, השתמשו בגודל 1024 px והדפיסו גדול יותר — כלל טוב הוא כעשירית ממרחק הסריקה.

איך זה עובד

המחולל ממיר את הטקסט שלכם לאותיות גדולות אוטומטית ודוחה תווים מחוץ לאלפבית Code 39, נוקב בשם הכלל במקום לתת למקודד להיכשל בשקט. כוכבית היא תו ההתחלה/עצירה ומתווספת על ידי המקודד — לעולם אל תקלידו אותה בעצמכם.

דוגמה מעובדת

מחסן הכלים של מפעל עדיין מריץ מערכת Code 39 משנות ה-1990. תוויות לוחות צל חדשות מודפסות מדף זה — PART-8841-A וקודים דומים — והסורקים הישנים קוראים אותן בפעם הראשונה.

שאלות נפוצות

האם מחולל Code 39 זה הוא בחינם?

כן. מחולל Code 39 של Loona’s הוא לגמרי בחינם ללא הרשמה, ללא סימן מים וללא מגבלה על כמה קודים תיצרו, לשימוש אישי או מסחרי.

האם קוד ה-QR שלי יפוג?

לא. Loona יוצר קודי QR סטטיים: המידע שלכם מקודד ישירות בתוך תבנית ה-QR עצמה, לא נשמר בשרת ולא מוסתר מאחורי הפניה בתשלום. קוד שתדפיסו היום ימשיך לעבוד כל עוד היעד עצמו נשאר פעיל.

האם המידע שלי פרטי בעמוד Code 39 זה?

כן. היצירה מתבצעת 100% בדפדפן שלכם באמצעות JavaScript. שום דבר שתזינו לא נשלח או נשמר בשום שרת.

למה הטקסט באותיות הקטנות שלי השתנה?

ל-Code 39 אין אותיות קטנות באלפבית התקני שלו, כך שמקודדים ממירים לאותיות גדולות. אם הרישיות חשובה, השתמשו ב-Code 128 במקום זאת.

האם Code 39 צריך ספרת ביקורת?

לא — הוא בודק את עצמו בתכנון. ספרת ביקורת במודולו-43 קיימת למערכות שמבקשות אותה, אבל רוב תוויות Code 39 מודפסות בלעדיה.
