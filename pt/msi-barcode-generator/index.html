Acerca deste MSI Plessey

O MSI (Modified Plessey) é um código de barras numérico nascido no retalho dos anos 1970 e que hoje vive sobretudo em armazéns, bibliotecas e controlo de inventário — rótulos de margem de prateleiras, contentores de stock e sistemas de bibliotecas mais antigos ainda funcionam com ele. Cada dígito tem quatro barras e quatro espaços, o que o torna fácil de imprimir, mas impossível de utilizar para letras.

O MSI é normalmente combinado com um dígito de controlo módulo-10 (por vezes dois, ou mod-11) e um sistema que espera o dígito de controlo rejeitará números simples — verifique a configuração do seu leitor antes de imprimir um lote.

Melhores utilizações

  • Rótulos de prateleiras e contentores de armazéns
  • Inventário de bibliotecas (sistemas antigos)
  • Etiquetas de controlo de stock
  • Numeração de membros e de identificação

Coloque o código exatamente onde a decisão é tomada — na mesa, no balcão, na embalagem, no convite ou no ecrã — e dê às pessoas uma frase curta de instrução, como “Leia para abrir” ou “Leia para pagar”. Imprima os códigos com pelo menos 2 cm de largura, com uma margem branca silenciosa e um contraste forte, para que as câmaras de telemóveis mais antigas os leiam rapidamente; para cartazes lidos à distância, utilize o tamanho de 1024 px e imprima maior — uma boa referência é cerca de um décimo da distância de leitura.

Como funciona

Este gerador codifica os dígitos que dá; se o seu sistema espera um dígito de controlo Mod 10, inclua-o como dígito final — o exemplo da página mostra a forma simples que a maioria das ferramentas de rótulos aceita.

Exemplo resolvido

Uma loja de peças imprime rótulos MSI para 400 prateleiras. Os números dos contentores leem-se no leitor de cunha mais antigo do balcão, configurado para MSI há décadas e ainda em uso diário.

Perguntas Frequentes

Este gerador MSI Plessey é grátis?

Sim. O gerador MSI Plessey da Loona é completamente gratuito, sem registo, sem marca de água e sem limite para o número de códigos que cria, para utilização pessoal ou comercial.

O meu código QR vai expirar?

Não. A Loona cria códigos QR estáticos: a sua informação é codificada diretamente dentro do próprio padrão QR, não guardada num servidor nem escondida atrás de um redirecionamento pago. Um código que imprima hoje continuará a funcionar enquanto o próprio destino se mantiver ativo.

A minha informação é privada nesta página do MSI Plessey?

Sim. A geração acontece 100% no seu navegador, utilizando JavaScript. Nada do que introduz é enviado para, ou guardado em, qualquer servidor.

Por que não lê o meu leitor o MSI?

Muitos leitores modernos vêm com o MSI desativado, porque é raro no retalho. Ative o MSI (e o modo de dígito de controlo certo) nas definições do leitor.

MSI ou Code 128 para um sistema novo?

Code 128 — o MSI é uma escolha de manter o legado. Os sistemas novos nada ganham com as limitações do MSI.
