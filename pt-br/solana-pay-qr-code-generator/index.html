Sobre deste Solana Pay

O Solana Pay é uma especificação formal (não apenas um hábito de carteiras): um URL solana: cujos parâmetros de consulta — montante, etiqueta, mensagem, memorando e uma referência para rastreio de encomendas — dizem à carteira exatamente o que apresentar. As lojas utilizam-no para códigos de ponto de venda em que o memorando ou a referência liga o pagamento a uma encomenda no seu sistema.

Este gerador compõe os parâmetros centrais. Se o sistema da sua loja reconciliar por chaves de referência, gere antes os códigos a partir do seu sistema — um código estático impresso adequa-se melhor a artigos de preço fixo e donativos.

Melhores utilizações

  • Artigos de preço fixo no ponto de venda
  • Donativos com um memorando
  • Bilhetes de eventos e merchandising
  • Pagamentos a criadores

Coloque o código exatamente onde a decisão é tomada — na mesa, no balcão, na embalagem, no convite ou no tela — e dê às pessoas uma frase curta de instrução, como “Leia para abrir” ou “Leia para pagar”. Imprima os códigos com pelo menos 2 cm de largura, com uma margem branca silenciosa e um contraste forte, para que as câmeras de celulares mais antigas os leiam rapidamente; para cartazes lidos à distância, utilize o tamanho de 1024 px e imprima maior — uma boa referência é cerca de um décimo da distância de leitura.

Como funciona

Carga: solana:RECIPIENT?amount=…&label=…&message=…&memo=…, codificada em URL segundo a especificação Solana Pay, para que as carteiras conformes apresentem a etiqueta e a mensagem na confirmação.

Exemplo resolvido

Uma banca de merchandising vende um cartaz por 1.5 SOL. O memorando do código diz “POSTER-STD”, pelo que o vendedor associa o pagamento on-chain ao produto sem perguntar nada a ninguém.

Perguntas Frequentes

Este gerador Solana Pay é grátis?

Sim. O gerador Solana Pay da Loona é completamente gratuito, sem registro, sem marca de água e sem limite para o número de códigos que cria, para utilização pessoal ou comercial.

O meu código QR vai expirar?

Não. A Loona cria códigos QR estáticos: a sua informação é codificada diretamente dentro do próprio padrão QR, não salva num servidor nem escondida atrás de um redirecionamento pago. Um código que imprima hoje continuará a funcionar enquanto o próprio destino se mantiver ativo.

A minha informação é privada nesta página do Solana Pay?

Sim. A geração acontece 100% no seu navegador, utilizando JavaScript. Nada do que insere é enviado para, ou salvo em, qualquer servidor.

Qual é a diferença entre mensagem e memorando?

A mensagem é mostrada a quem paga apenas na carteira. O memorando é escrito na transação on-chain — visível permanentemente, pelo que o mantenha factual e livre de dados pessoais.

Posso aceitar USDC na Solana com isto?

Os pagamentos com tokens adicionam um parâmetro spl-token que nomeia o mint. Esta página constrói pedidos SOL nativos; para USDC, gere o código a partir do seu processador de pagamentos, para que o endereço mint seja exato.
