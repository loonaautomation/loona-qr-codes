Sobre deste Code 39

O Code 39 (USS Code 39, Code 3 of 9) é o código de barras alfanumérico mais antigo ainda em uso diário — desenvolvido em 1974 e mantido vivo por rótulos do setor automóvel, da defesa, da saúde e do governo que o especificaram há décadas. Cada caráter tem nove elementos de largura (cinco barras, quatro espaços, três deles largos), o que o torna tolerante a má impressão, mas longo para os dados que contém.

O seu alfabeto é pequeno: maiúsculas A–Z, dígitos e alguns símbolos. É autoverificável (um único caráter errado raramente valida) e pode ser adicionado um dígito de controlo módulo-43 opcional onde o sistema recetor o espera.

Melhores utilizações

  • Rótulos antigos do setor automóvel e da defesa
  • Crachás e cartões de identificação
  • Livros de bibliotecas (sistemas mais antigos)
  • Contentores industriais e armazéns de ferramentas

Coloque o código exatamente onde a decisão é tomada — na mesa, no balcão, na embalagem, no convite ou no tela — e dê às pessoas uma frase curta de instrução, como “Leia para abrir” ou “Leia para pagar”. Imprima os códigos com pelo menos 2 cm de largura, com uma margem branca silenciosa e um contraste forte, para que as câmeras de celulares mais antigas os leiam rapidamente; para cartazes lidos à distância, utilize o tamanho de 1024 px e imprima maior — uma boa referência é cerca de um décimo da distância de leitura.

Como funciona

O gerador coloca o seu texto em maiúsculas automaticamente e rejeita carateres fora do alfabeto Code 39, nomeando a regra em vez de deixar o codificador falhar silenciosamente. Um asterisco é o caráter de início/fim e é adicionado pelo codificador — nunca o escreva você mesmo.

Exemplo resolvido

O armazém de ferramentas de uma fábrica ainda funciona com um sistema Code 39 dos anos 1990. As novas etiquetas de quadros-sombra são impressas a partir desta página — PART-8841-A e códigos semelhantes — e os leitores antigos leem-nas à primeira.

Perguntas Frequentes

Este gerador Code 39 é grátis?

Sim. O gerador Code 39 da Loona é completamente gratuito, sem registro, sem marca de água e sem limite para o número de códigos que cria, para utilização pessoal ou comercial.

O meu código QR vai expirar?

Não. A Loona cria códigos QR estáticos: a sua informação é codificada diretamente dentro do próprio padrão QR, não salva num servidor nem escondida atrás de um redirecionamento pago. Um código que imprima hoje continuará a funcionar enquanto o próprio destino se mantiver ativo.

A minha informação é privada nesta página do Code 39?

Sim. A geração acontece 100% no seu navegador, utilizando JavaScript. Nada do que insere é enviado para, ou salvo em, qualquer servidor.

Por que foi o meu texto em minúsculas alterado?

O Code 39 não tem letras minúsculas no seu alfabeto padrão, pelo que os codificadores convertem para maiúsculas. Se a caixa importar, utilize antes o Code 128.

O Code 39 precisa de um dígito de controlo?

Não — é autoverificável por concepção. Existe um dígito de controlo módulo-43 para sistemas que o pedem, mas a maioria dos rótulos Code 39 é impressa sem um.
