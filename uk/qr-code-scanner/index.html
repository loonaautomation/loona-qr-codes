Безкоштовний сканер QR-кодів і штрих-кодів

Наведіть камеру на QR-код або штрих-код, або киньте фото чи знімок екрана — код декодується просто тут, на вашому пристрої. Без реєстрації, без застосунку для встановлення, і ніщо, що ви скануєте, ніколи не завантажується. Ви також можете пакетно декодувати багато зображень кодів одразу й експортувати результати як файл CSV.

Сканувати камерою

Сканування камерою наживо використовує швидкий BarcodeDetector, вбудований у Chrome, Edge і більшість браузерів Android, і читає QR-коди плюс поширені штрих-коди (EAN-13, UPC-A, Code 128, Code 39 та більше, залежно від вашого браузера).

Конфіденційність: кадри камери обробляються лише на цьому пристрої й ніколи не залишають ваш браузер. Жодне відео не записується, не надсилається й не зберігається.

Сканувати із зображення

Передайте фото, перетягніть файл зображення сюди або вставте знімок екрана (Ctrl+V / Cmd+V). QR-коди на зображеннях розкодовуються за допомогою jsQR, а штрих-коди на зображеннях — за допомогою ZXing, включно з EAN-13, UPC-A, Code 128 і Code 39.

    Про цей сканер QR-кодів і штрих-кодів
    

    Більшість QR-сайтів лише make коди. Ця сторінка робить протилежну роботу: вона їх читає. Це те, що вам потрібно, коли друкований код не має читабельної мітки, коли колега надсилає вам знімок екрана коду замість посилання всередині нього, коли ви хочете перевірити, що один із ваших власних друкованих кодів насправді містить, перед великим тиражем, або коли номер штрих-коду товару треба прочитати з фото.
    

    Він працює двома способами. Режим камери використовує інтерфейс BarcodeDetector, вбудований у сучасні браузери Chromium, — те саме швидке, дружнє до апаратури виявлення, яке використовує система вашого телефона, — і повідомляє QR-коди та поширені одновимірні штрих-коди. Режим зображення повністю автономний: бібліотека jsQR із відкритим кодом декодує QR-коди з пікселів вашого зображення, а бібліотека ZXing із відкритим кодом декодує штрих-коди (і будь-який QR-код, який jsQR пропустив) із тих самих пікселів. Обидва працюють повністю у вашому браузері, тому цей сканер продовжує працювати з чутливими кодами — паролями WiFi, платіжними кодами, приватними посиланнями, — які ви ніколи не захотіли б завантажувати на чужий сервер.
    

    Найкраще використання цього сканера
    • Перевірка власних надрукованих QR-кодів перед друком великої кількості
    • Відкривання посилання, схованого всередині QR-коду на знімку екрана або фото, яке вам хтось надіслав
    • Відновлення назви мережі WiFi й пароля із зображення QR-коду WiFi
    • Збереження контакту vCard із QR-коду візитки як файлу .vcf
    • Читання номерів штрих-кодів EAN-13, UPC-A, Code 128 і Code 39 із фото товарів і етикеток
    • Перевірка того, що згенерований вами штрих-код сканується назад саме до того числа, яке ви задумали
    • Пакетна перевірка цілого надрукованого аркуша або папки фотографій кодів, з експортом кожного результату у CSV
    • Перегляд координат за кодом розташування geo: або адреси за платіжним кодом Bitcoin чи Ethereum, перш ніж діяти на них
    

    Чесні обмеження, щоб ви не здивувалися: сканування камерою залежить від функції браузера, яку Safari й Firefox ще не випустили, тож у цих браузерах доступний лише режим зображення — сторінка виявляє це й каже вам прямо, замість того щоб тихо зазнати невдачі. І жоден декодер не прочитає код, який у фотографії занадто маленький, розмитий, розірваний або надрукований із замалим контрастом; повторне фотографування ближче, прямо й при доброму освітленні виправляє більшість невдалих сканувань.
    

    Часті питання
    Чи безкоштовний цей сканер QR-кодів і штрих-кодів?
    Так. Сканер від Loona повністю безкоштовний, без реєстрації, без водяних знаків і без обмеження кількості кодів, які ви скануєте, для особистого або комерційного використання.
    Чи відео моєї камери або моє фото приватні на цій сторінці сканера?
    Так. Усе розкодується на вашому власному пристрої, усередині вашого браузера. Кадри камери ніколи нікуди не надсилаються, а передані зображення ніколи не надсилаються на сервер — файл читається локально, розкодується локально, а ваша історія сканувань зберігається лише в пам’яті цієї сторінки й зникає, коли ви закриваєте вкладку.
    Чому сканування камерою не працює в моєму браузері?
    Сканування камерою наживо використовує технологію BarcodeDetector, вбудовану в Chrome, Edge і більшість браузерів Android. Safari та Firefox ще її не містять, тож у цих браузерах кнопку камери замінює повідомлення з проханням натомість використати завантаження зображення — завантаження фото або знімка екрана працює в кожному сучасному браузері.
    Чи може цей сканер зчитати штрих-код із фотографії?
    Так. Режим передавання розкодує QR-коди із зображень за допомогою бібліотеки jsQR, а штрих-коди із зображень — за допомогою бібліотеки ZXing, включно з EAN-13, UPC-A, Code 128 і Code 39, а також QR-коди, які ZXing знаходить, а jsQR пропустив. Дуже малі, розмиті, пошкоджені або низькоконтрастні коди на фото можуть і далі не розкодовуватися; чіткіше, ближче фото зазвичай це виправляє.
    Які типи кодів може читати цей сканер?
    Сканування камерою (де підтримується) читає QR-коди плюс формати штрих-кодів, які пропонує BarcodeDetector вашого браузера, зазвичай EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, Codabar та ITF. Завантаження зображення читає QR-коди і штрих-коди EAN-13, UPC-A, Code 128 та Code 39 і показує вам декодований тип, сирий вміст і розумні дії, як-от відкрити посилання або зберегти контакт.

    Як це працює
    

    QR-код або штрих-код — це просто візерунок, який кодує текст світлими й темними модулями. Декодування — зворотний процес до створення: знайти візерунок на зображенні, виміряти модулі, виправити помилки завдяки вбудованій надлишковості коду й перетворити біти назад на символи. jsQR робить це для QR-кодів, знаходячи три пошукові квадрати й зчитуючи сітку; ZXing робить це для штрих-кодів, скануючи рядки пікселів упоперек смуг і зіставляючи ширину з правилами EAN, UPC, Code 128 або Code 39, зокрема перевіряючи останню контрольну цифру роздрібних штрих-кодів. У режимі камери власний BarcodeDetector вашого браузера виконує ту саму роботу безперервно на живих кадрах відео, доки код не буде знайдено. У пакетному режимі ті самі два декодери зображень працюють один раз для кожного файлу, а кожен результат — назва файлу, формат, тип і декодований текст — збирається в таблицю, яку можна експортувати як CSV.
    

    Метод: виберіть камеру або зображення → дайте вбудованому розкодувальнику прочитати візерунок → перевірте тип, формат і необроблений вміст → скористайтеся розумною дією (відкрити, копіювати, зберегти контакт) → знайдіть сканування знову будь-коли в історії сеансу.

    Часті питання
    

    Чи можу я відсканувати код зі знімка екрана на тому самому телефоні?
    

    Так. Збережіть або поділіться знімком екрана у ваш застосунок фото, потім скористайтеся передаванням зображення тут і виберіть цей знімок екрана. На комп’ютері просто скопіюйте зображення й вставте його на цю сторінку за допомогою Ctrl+V (або Cmd+V на Mac) — зберігати файл не потрібно.
    

    Результат виглядає як WIFI:T:WPA;S:… — що це означає?
    

    Це стандартний необроблений формат усередині QR-коду WiFi: T — тип безпеки, S — назва мережі (SSID), а P — пароль. Ця сторінка також показує ці три значення окремо над необробленим вмістом, тож вам не доведеться вибирати їх самостійно.
    

    Як додати відсканований контакт у телефон?
    

    Коли сканування є vCard, з’являється дія «Завантажити контакт (.vcf)». Завантажте файл і відкрийте його — телефони й комп’ютери пропонують зберегти його як контакт із уже заповненими іменем, організацією, телефоном, електронною поштою й вебсайтом.
    

    Чому моє фото не розкодувалося?
    

    Звичайні причини — код, крихітний на великому фото, розмиття, відблиск, порваний або низькоконтрастний друк, або знімок екрана, обрізаний занадто щільно навколо коду (декодерам потрібна біла тиха зона навколо коду). Обрізайте вільно, перефотографуйте ближче й прямо та спробуйте знову.
    

    Чи варто довіряти QR-коду, який я знайшов у громадському місці?
    

    Скануйте тут спершу замість застосунку, який відкриває результати автоматично: ця сторінка лише shows вам розкодований вміст і ніколи нічого не відкриває сам. Перевірте, що посилання справді веде туди, куди обіцяє його мітка, перш ніж торкнутися «Відкрити посилання», — ця одна звичка перемагає більшість шахрайств із наліпкою поверх справжнього коду.
