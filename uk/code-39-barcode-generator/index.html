Про цей Code 39

Code 39 (USS Code 39, Code 3 of 9) — найстаріший алфавітно-цифровий штрих-код, який досі в щоденному вжитку; розроблений 1974 року, його тримають живим автомобільні, оборонні, медичні й державні етикетки, що вказали його десятиліття тому. Кожен символ має ширину дев’ять елементів (п’ять смуг, чотири пробіли, три з них широкі), що робить його толерантним до поганого друку, але довгим для даних, які він містить.

Його алфавіт малий: великі літери A–Z, цифри й кілька символів. Він самоперевірюваний (один поганий символ рідко проходить перевірку), а необов’язкову контрольну цифру за модулем 43 можна додати там, де система отримання її очікує.

Як це працює

Генератор автоматично переводить ваш текст у верхній регістр і відхиляє символи поза алфавітом Code 39, називаючи правило замість того, щоб дозволити кодувальнику мовчки зазнати невдачі. Зірочка — це символ початку/зупинки, який додає кодувальник, — ніколи не вводьте її самостійно.

Розібраний приклад

Інструментальна комора заводу досі працює на системі Code 39 1990-х років. Нові етикетки для тіньових дощок друкують із цієї сторінки — PART-8841-A і подібні коди — і старі сканери зчитують їх із першого разу.

Часті питання

Чи безкоштовний цей генератор Code 39?

Так. Генератор Code 39 від Loona повністю безкоштовний, без реєстрації, без водяних знаків і без обмеження кількості кодів, які ви створюєте, для особистого або комерційного використання.

Чи мине строк дії мого QR-коду?

Ні. Loona створює статичні QR-коди: ваша інформація закодована напряму всередині самого візерунка QR-коду, не збережена на сервері й не схована за платним перенаправленням. Код, який ви друкуєте сьогодні, продовжить працювати, доки саме призначення залишається активним.

Чи моя інформація приватна на цій сторінці Code 39?

Так. Генерування відбувається на 100% у вашому браузері за допомогою JavaScript. Ніщо з того, що ви вводите, не надсилається й не зберігається на жодному сервері.

Чому мій текст у нижньому регістрі змінився?

Code 39 не має малих літер у своєму стандартному алфавіті, тож кодувальники перетворюють їх на великі. Якщо регістр важливий, використовуйте натомість Code 128.

Чи потрібна Code 39 контрольна цифра?

Ні — він самоперевірюваний за дизайном. Контрольна цифра за модулем 43 існує для систем, які її просять, але більшість етикеток Code 39 друкуються без неї.
