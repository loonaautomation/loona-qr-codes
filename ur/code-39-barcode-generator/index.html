اس Code 39 کے بارے میں

Code 39 (USS Code 39, Code 3 of 9) روزانہ استعمال میں سب سے پرانا حروف عددی بارکوڈ ہے — 1974 میں تیار ہوا اور آٹوموٹو، دفاع کی طرف سے زندہ رکھا گیا

اس کا حروف تہجی چھوٹا ہے: بڑے حروف A–Z، ہندسے اور چند علامات۔ یہ خود جانچنے والا ہے (ایک خراب حرف شاذ و نادر ہی تصدیق ہوتا ہے)، اور جہاں وصول کنندہ سسٹم توقع کرے وہاں اختیاری modulo-43 چیک ہندسہ شامل کیا جا سکتا ہے۔

بہترین استعمالات

  • آٹوموٹو اور دفاعی پرانے لیبلز
  • نام بیجز اور ID کارڈز
  • لائبریری کتابیں (پرانے سسٹم)
  • صنعتی بنز اور ٹول کربز

کوڈ بالکل وہیں رکھیں جہاں فیصلہ ہوتا ہے — میز پر، کاؤنٹر پر، پیکجنگ پر، دعوت پر یا اسکرین پر — اور لوگوں کو ایک مختصر ہدایت کی سطر دیں جیسے “کھولنے کے لیے اسکین کریں” یا “ادائیگی کے لیے اسکین کریں”۔ کوڈز کم از کم 2 cm چوڑے پرنٹ کریں خاموش سفید کنارے اور مضبوط کنٹراسٹ کے ساتھ تاکہ پرانے فون کیمرے انہیں جلدی پڑھیں؛ فاصلے سے اسکین ہونے والے پوسٹرز کے لیے 1024 px سائز استعمال کریں اور بڑا پرنٹ کریں — اچھی رہنمائی اسکیننگ فاصلے کا تقریباً دسواں حصہ ہے۔
